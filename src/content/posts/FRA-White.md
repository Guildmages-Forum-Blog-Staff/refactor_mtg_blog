現實碎片（FRA）將於2026年9月25日舉行售前賽活動，而於隔一週2026年10月2日正式發行，想更了解在限制賽的單卡評分與建議嗎？那就來看看這一系列的FRA限制賽介紹吧！

- 機制介紹請看這篇：[現實碎片機制解析](https://guildmagesforum.tw/FRA-Mechanism/)

## 評分標準

5.0：無條件必拿，能帶來幾近勝利的優勢
4.5：色組正確無條件必拿，能帶來大幅的優勢
4.0：有首選價值，與色組主題的相性極佳，能成為混色／轉色或進入色組的決定性牌張
3.5：系列頂 U、C 與其他強度夠的單卡，與色組主題相性佳，能成為進入色組的關鍵牌張
3.0：色組主題的重要單卡，以及其他高於平均值的單卡，會希望進到最終牌組
2.5：平均水準，通常是不錯的曲線填充物
2.0～1.0：低於平均，基本傾向不放，必要時可用來填充，但不宜過多。2.0分也可以作為強力備牌的分數。
0.5～0.0：不可用，基本上別放，放了只會幫你輸

{% mtgpick "fra" 4 %}

評語：偏進攻取向的生物，死了後還能從墳場放逐聚能傑斯2稍微濾一下牌。

{% mtgpick "fra" 5 %}
分數：2.0 / 3.5
評語：在白綠色組中是很強的賺牌引擎，有補過血就能刺探，補的血夠多還能把刺探丟下去的牌撿上手。在其他色組就是個2/1繫命而已，想觸發自己的異能通常只能靠自己的繫命，不過身材很爛，打出去通常就回不來了。這邊要注意一下它的異能一定要這回合有補過血，才會做刺探，沒補到血就什麼都不會發生。

{% mtgpick "fra" 6 %}
分數：2.5
評語：能撿傳奇回手，這系列傳奇生物很多，應該不會沒東西撿，能撿回鵬洛客更是賺爛。另一個選項能放豆，還有給警戒和不滅讓生物打過去。

{% mtgpick "fra" 7 %}

評語：身材實在太爛，評分是給異能的，搭配ETB生物可以賺得很開心，也可以雲移自己這回合進攻過的生物，讓它們站著回來，達成類似警戒的效果。

{% mtgpick "fra" 8 %}
分數：2.5

評語：強力的二費單體生物去除，可以等對手的重要生物攻擊了再殺，就不會讓對手抽牌了。某些情況也可以殺自己的生物來抽牌。

評語：雖說是有限制範圍的去除，但第二項可以在沒有目標時拿去抽牌回血，至少不會卡在手上變死牌。

評語：白綠色組的回報單卡，只要回血就會放豆變大。本身帶有守護1也令對手必須要多花費用才能去除它。

{% mtgpick "fra" 24 %}
分數：3.0
評語：比較麻煩的威脅都在它的射程範圍內，無論是生物或鵬洛客都能去除非常強，還多送個刺探1。

{% mtgpick "fra" 195 %}

評語：搭配白綠色組的強力單卡，能回血、叫出阻擋者、強化場面壓力。在其他色組就幾乎只有回血的功能，要做[-4]叫出阻擋者太慢，大招更是不可能開出來。

{% mtgpick "fra" 196 %}

評語：有先攻使得對手很難透過生物把它交換掉，施放武具或是指自己生物的戰鬥詭計就能抽牌（對手回合也會觸發），在快攻套牌中是優秀的補牌手段。

{% mtgpick "fra" 197 %}
分數：3.0
評語：只要不要慘到生物通通被對手解光，在第五、六回合應該能順利把它叫出來。身材好到對手幾乎必須交一張殺才能把它解掉，對一般的生物來說，它就是一堵無法跨越的高牆。

{% mtgpick "fra" 198 %}
分數：2.5
評語：用途很多，在 token 多的套牌能給 token 生物加攻擊力和給警戒；作為鵬洛客套牌的加速兼調色手段；再不濟也勉強能作為有條件的去除來使用。

{% mtgpick "fra" 199 %}

評語：地落就能回血，如果進場的是平原還能放豆，很厲害的曲線生物。放進任何沾白的色組都不錯，唯獨要注意，若是使用在三色以上的套牌中，可能會比較難觸發放豆的異能。

{% mtgpick "fra" 200 %}
分數：3.0
評語：生物或鵬洛客進場都能觸發回血，對白綠色組相當重要。棄一張牌就能保住其他的生物或是鵬洛客，對手要先解掉它才能去除我們的其他威脅。

{% mtgpick "fra" 201 %}
分數：3.5
評語：白綠色組的回報單卡，每次回血都能讓所有Angel放豆變大，只要灌大個幾次它本身也能成為致命威脅。

{% mtgpick "fra" 202 %}
分數：2.5
評語：需要配合有強力ETB異能的永久物才比較有用，搭配 [Way of the ……系列的結界](https://scryfall.com/search?as=grid&order=name&q=Way+of+%28game%3Apaper%29+set%3Afra+prefer%3Abest)就能每回合放一堆忠誠指示物在 Jace token 上。

{% mtgpick "fra" 203 %}
分數：4.0
評語：白藍色組的重要回報單卡，對手解不掉就能生出一地1/1振翼機衝破對手防線。這系列由於 Jace token 也會讓你刺探，在任何沾白的色組也都適合投入使用。

{% mtgpick "fra" 204 %}
分數：3.0
評語：ETB異能可以保護任何永久物，如果是生物還會放豆、鵬洛客還會放忠誠指示物，很厲害。

{% mtgpick "fra" 205 %}
分數：3.0
評語：身材很好還有繫命，異能可以拖慢對手的節奏，不論是去除、掃場、鵬洛客都會被卡到。

{% mtgpick "fra" 206 %}
分數：3.0
評語：大幅增加鵬洛客的生存能力，除非你沒生物可以擋，不然鵬洛客幾乎不會被對手生物踢死。本身是個二費2/1飛行，在進攻上也能給對手很大的壓力，異能還能讓其他有豆的生物起飛進攻或做阻擋。

{% mtgpick "fra" 207 %}
分數：2.5
評語：讓 Jace token 多了[-2]能叫出2/2 Cadet跟刺探1，下回合可以再叫一隻或是乾脆[-3]直接抽一張牌。如果後續有其他聚能傑斯的牌可以搭配，就能源源不絕生出阻擋者，但若是四費空場做這件事，則在節奏上略顯遜色。

{% mtgpick "fra" 208 %}
分數：2.5
評語：在白綠色組內才有機會重複觸發放忠誠指示物的異能讓 Jace token 留在場上做後續的抽濾，也能加速其他鵬洛客開出大招。不會回血的話就只是個三費抽1、刺探1、再刺探1而已（還要分三回合做）。

{% mtgpick "fra" 209 %}
分數：3.0
評語：放豆可以多放一顆，還有六費就能靠自己的異能來放豆，是紅白色組的重要回報單卡。

{% mtgpick "fra" 210 %}
分數：3.0
評語：戰階雖然雙方都不能做事，但會給我方單獨進攻的生物連擊，也算是彌補了不能做招的缺點。

## 結語
這系列的白色沒有什麼強度爆表的炸彈，有些牌更是明顯限制用來搭配某個色組的，但大部分的牌張在限制賽的構築中都有著一戰之力，很期待這系列限制賽的多元性。
