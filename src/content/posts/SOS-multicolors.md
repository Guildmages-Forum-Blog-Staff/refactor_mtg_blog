斯翠海文的祕密（Secrets of Strixhaven, SOS）將於2026年4月17日舉行售前賽活動，而於隔一週2026年4月24日正式發行，想更了解在限制賽的單卡評分與建議嗎？那就來看看這一系列的SOS限制賽介紹吧！

## 色組主題

### <span style="color:#C3B270">白</span><span style="color:#808080">黑</span>銀毫（Silverquill）學院

![](https://i.meee.com.tw/hTURnE7.jpg)

代表機制：**連辭（Repartee）** 

連辭機制會在你以生物為目標施放瞬間或巫術時觸發，因此限制賽中至少會有兩個觸發情境：
1. 你用去除 / 橫置目標生物**指定對手操控的生物時**，具有連辭異能的生物會觸發效果；
2. 你用增益性咒語**指定你操控的生物時**，具有連辭異能的生物會觸發效果。

因此，我們的遊戲計畫將非常明確。利用 {% mtglink "Abigale, Poet Laureate" %} 施放生物後的「已備法」（Prepared）狀態，產生可放置指示物的複製品咒語，進而達成擴大場面、增強體格並頻繁觸發連辭的多重收益。而在單卡搭配上，白黑 C 卡的 {% mtglink "Inkling Mascot" %} 透過連辭獲得飛行穿透並附帶刺探一，能讓後續抽牌變得更好；U 卡 {% mtglink "Killian's Confidence" %} 則能放大這套體系的滾雪球效益，且具備重複利用的潛力。若需穩定的且低稀有度的觸發源，白色的 {% mtglink "Dig Site Inventory" %} 的返照異能可當兩張咒語使用，而黑色的 {% mtglink "Scathing Shadelock" %} 則能穩定產出複製品，確保連辭異能每回合都能發揮到極致。

以上情境提到的都是針對我方增益的連辭模式。另一方面，你也可以手握大量去除，同時靠強力的連辭效果的生物來把你的對手反駁到啞口無言！

![](https://i.meee.com.tw/ztFbYJZ.jpg)

### <span style="color:#006DB3">藍</span><span style="color:#AF2321">紅</span>粹麗（Prismari）學院

![](https://i.meee.com.tw/xIE0YZO.jpg)

代表機制：**炫示（Opus）**

那麼，我們要如何穩定的從炫示機制中獲取最大的回報呢？首先，從雙色U卡傳奇上來找些線索。 {% mtglink "Sanar, Unfinished Genius" %} 本身在你炫示時可以橫置派出珍寶，這將有助於你施放高費的瞬間/巫術。同時他已備法的咒語複製品是五費，這也有助於你完全解鎖炫示回報牌。找出來的瞬間/巫術又能持續炫示 + 派出珍寶的循環。C卡 {% mtglink "Elemental Mascot" %} 的炫示回報除了攻擊力增加外，若以五費施放咒語觸發炫示，則會有額外的回報。而另一張 {% mtglink "Abstract Paintmage" %} 則提供了額外的兩點法力，讓你更容易施放高費瞬間/巫術。而像Sanar一樣具有備法效果的生物也不少，像 {% mtglink "Campus Composer" %} 這樣自帶五費咒語的已備法生物，先做曲線生物登場，若有餘裕，則可再施放備法咒語的複製品。最後，像是 {% mtglink "Fractalize" %} 這類帶有X費用的咒語，也可作為伸縮自如的炫示觸發源，在構築藍紅色組的套牌時別忘了及早拿下它們。

但別忘了，具有定式（Paradigm）的五張單色課程巫術牌在第一次施放後，下一次免費施放的複製品，僅會觸發炫示異能的基礎效果，並不滿足以五費或更多施放的額外條件。

### <span style="color:#808080">黑</span><span style="color:#4A8A3D">綠</span>靡華（Witherbloom）學院 

![](https://i.meee.com.tw/pwgSDbM.jpg)

代表機制：**輸注（Infusion），即本回合獲得生命**

{% mtglink "Lluwen, Exchange Student" %} 是來自洛溫時空的交換生，除了可以反覆放逐你墳場中生物牌來讓自己反覆備法，派出的1/1害蟲衍生物除了鋪場，進攻帶來的補血回報也讓後續的輸注牌能發揮完整的效益。C卡這邊選用 {% mtglink "Bogwater Lumaret" %} 而不是 {% mtglink "Pest Mascot" %} ，原因是這張牌在黑綠中實在太重要了，不只他自己，只要有生物進場就能補血，有/沒有他的黑綠套牌，能讓輸注牌發揮的上下限差距極大！而另一張 {% mtglink "Essenceknit Scholar" %} 進場能派出害蟲，而害蟲們進攻後死去還可以額外抽一張牌。輸注牌中，像 {% mtglink "Poisoner's Apprentice" %} 單純進場只是三費叫隻2/2，但進場時若是已輸注的狀態，那就能化身為高效的去除。這邊體現了補血在黑綠色組中的重要性。而像是 {% mtglink "Thornfist Striker" %} 只要是輸注的狀態，你的生物的戰力將大不相同，而這甚至在阻擋時也有機會發生！

> 輸注機制是一個檢查效果，只會看有無滿足這回合有補過血，有的會輸注牌的效果就會是已輸注的狀態結算，不會有額外的觸發或使用堆疊。因此，像 {% mtglink "Pest Mascot" %} 這樣的牌，就仍維持一般補血效果的規則敘述。

### <span style="color:#AF2321">紅</span><span style="color:#C3B270">白</span>衡鑑（Lorehold）學院

![](https://i.meee.com.tw/cwHfRyX.jpg)

代表機制：**返照（Flashback）**

{% mtglink "Kirol, History Buff" %} 本身在有牌離墳時會成為已備法的狀態，備法咒語複製品可以讓你磨牌 + 強化你的生物。C卡的 {% mtglink "Spirit Mascot" %} 則是有牌離墳就會長大，簡單暴力。而另一張返照咒語 {% mtglink "Molten Note" %} 本身是一張可靠的去除，返照能觸發離墳，也讓你在大後期可以用墳場中的返照牌賺取額外的資源，一魚二吃很棒。紅白色組的C卡中，紅色的 {% mtglink "Rubble Rouser" %} 、與白色的 {% mtglink "Stone Docent" %} 都具有主動離墳的能力，帶上幾張可以讓你的紅白套牌運作得更順暢！

> 為了方便描述，集會所這邊統一用「**離墳**」來代指 "When/Whenever one or more cards leave your graveyard……"）的效果。請注意這並非官方使用的關鍵字異能。
> 
> 以下這些狀況，都會觸發「離墳」的效果：
> - 移墳：將目標牌從目標/你的墳墓場放逐。
> - 撿墳：將目標牌從目標/你的墳墓場移回手上。
> - 挖墳：將目標生物/永久物牌從目標/你的墳墓場移回場上。
> - 若 {% mtglink "Ark of Hunger" %} 在場，當我們橫置它磨了一張牌，若這回合有使用那張牌，那也會觸發離墳。
> 
> 看來老威為了讓衡鑑學院的學生有古可考也是煞費苦心，但如果可以把這麼長的句子整合成一個關鍵字，那就更好了。

### <span style="color:#4A8A3D">綠</span><span style="color:#006DB3">藍</span>量析（Quandrix）學院

![](https://i.meee.com.tw/xK2zar3.jpg)

代表機制：**遞增（Increment）**

想要更深入了解藍綠色組在玩什麼，還是得回到雙色傳奇U卡 {% mtglink "Tam, Observant Sequencer" %} 來看。效果很簡單，下地觸發地落（Landfall）來成為已備法的狀態、施放備法複製品來抽牌（補血是附帶的）。這邊隱含著另外兩件訊息：加速、與抽牌將帶來新的終端。而另一張 {% mtglink "Paradox Surveyor" %} 主要是支援加速這邊，不論是拿地繼續加速，或地夠了拿X費用的咒語如 {% mtglink "Pterafractyl" %} 來終結比賽。

在說明抽牌的出口前，讓我們看往另一個面向 — 指示物（最常見是+1/+1指示物，集會所常以「豆」來稱呼），不只遞增會放豆，像 {% mtglink "Growth Curve" %} 這樣的牌也能大量放豆，而 {% mtglink "Fractal Tender" %} 這樣的牌則兩者兼備，你可以施放高費咒語觸發他的遞增效應、或主動在他身上放豆、甚至邪門一點，用 {% mtglink "Fractal Mascot" %} 這類牌讓他放暈眩指示物（Stun counter）也行！而當你可以持續放豆在他身上，很快地你的分靈（Fractal）衍生物們就能壓垮對手。

最後，抽牌很厲害沒錯，但抽了一堆牌除了用大量牌差讓對手不戰自潰外，還有其他結束比賽的方式嗎？

{% mtgcard "Fractal Anomaly" %}

就是這張，你抽越多張，這張牌的效果就越好。當然，要小心別把你牌庫先抽乾了！這系列可是沒有把墳場洗回牌庫的效果呢！

### 現開賽的救星 — 聚輝（Converge）

你是否有過在限制賽時，拿<span style="color:#808080">黑</span><span style="color:#4A8A3D">綠</span>售前盒卻其他包都開<span style="color:#AF2321">紅</span><span style="color:#C3B270">白</span>的料呢？在其他系列，你可能就得被逼著打三色甚至更多，並用相當不穩的調色基礎開始求神拜佛，希望給你一個曲線正常能運作的開局。在SOS的限制賽中，上述的狀況雖然仍會發生，但聚輝牌的存在，讓你即使顏色不對，也能有中庸偏上的一戰之力。

![](https://i.meee.com.tw/DGMWGqB.jpg)

在雙色套牌中，聚輝牌僅能發揮基礎下限，強度大概是填充物等級或更差；但在三色以上的套牌中，聚輝咒語施放時每多一個顏色，強度將有感提升！

![](https://i.meee.com.tw/iqOWpwv.jpg)

若算上這次秘典（SOA），有色瞬間/巫術總共有5張聚輝牌。當你的現開牌池破爛不堪時，別忘了把目光移向它們，也許你會找出新的可能性！

## 評分標準

5.0：無條件必拿，能帶來幾近勝利的優勢
4.5：色組正確無條件必拿，能帶來大幅的優勢
4.0：有首選價值，與色組主題的相性極佳，能成為混色／轉色或進入色組的決定性牌張
3.5：系列頂 U、C 與其他強度夠的單卡，與色組主題相性佳，能成為進入色組的關鍵牌張
3.0：色組主題的重要單卡，以及其他高於平均值的單卡，會希望進到最終牌組
2.5：平均水準，通常是不錯的曲線填充物
2.0～1.0：低於平均，基本傾向不放，必要時可用來填充，但不宜過多
0.5～0.0：不可用，基本上別放，放了只會幫你輸

## 結語

輪抽鎖定在五色越來越常見了，希望這不會是老威限制賽偷懶的徵兆XD 重回斯翠海文，我深刻地有感牌張強度在這四五年有著爆炸性的成長，這是個好現象嗎？我不確定。但即使如此，限制賽的變化仍是很有趣的，每個雙色主題，一定都還有許多未被破解的戰術與遊戲計畫，讓我們持續體驗吧！
