## 2025系列回顧

大家好，我是達爾，一位新竹的小小玩家，平常主要玩的是標準/先驅/近代等構築賽制。原本這些文章是在我自己的粉專 [**未央P也想玩mtg**](https://www.facebook.com/profile.php?id=61578588956001) 寫給自己的一些心得, 感謝豬鼻子的mtg世界邀稿，稍作整理後合為一篇，希望讓大家在閒暇之餘可以看看笑一笑。

![](https://i.meee.com.tw/pTtIjK6.jpg)

> 在2025年12月的現在，我們已經知道UUB是指[降世神通](#%E9%99%8D%E4%B8%96%E7%A5%9E%E9%80%9A-%E6%9C%80%E5%BE%8C%E7%9A%84%E6%B0%A3%E5%AE%97-Avatar-The-Last-Airbender)了。

## 乙太飄移 （Aetherdrift, [DFT](https://scryfall.com/sets/dft)）

乙太飄移絕對是今年最沒錢的系列了，整個系列最有用的除了地牌外，大概就是 {% mtglink "Stock Up" %} 。雖然是載具主題，但我記得輪抽紅白載具是最爛的色組……賽車這個主題也不太符合MTG的風格 ~~不過後來合作系列更超出我的想像就是了~~

{% mtgcard "The Aetherspark" %} 
 
史上第一張神器鵬洛客（鵬洛客卡恩不是神器……），故事中是比賽冠軍的獎品，[茜卓](https://scryfall.com/card/dft/116/chandra-spark-hunter)想要得到這個去送給已經失去火花的[妮莎](https://scryfall.com/card/mat/22/nissa-resurgent-animist)。當初我還在猜是不是能讓佩帶的生物變成鵬洛客，結果果然是我想太多。

雖然是這個系列的卡王，但是我沒印象哪邊會用到……

{% mtgcard "Stock Up" %} 
 
近年來最強的3費巫術抽牌，這張最貴的時候有到13鎂左右，明明是U卡卻收不太到……（我收的時候好像是一張NTD.350）
最近大概是環境太快了，比較少在賽場上看到。

**邊陲地 Verge Lands**

![邊陲地](https://i.meee.com.tw/boxb1dh.png)
 
繼鬼屋系列之後把對色邊陲地出完了，不得不說這是最近幾年來設計的最好的雙色地，可以站著進真是太棒了！完美搭配電震地/刺探地這種有基本地類別的地牌。

邊陲地最大的問題大概是常常忘記產不出第二個顏色，現實沒辦法像數位版那樣有顏色提示。

> 真的要的話，其實還有10個組合可以出（把前後能產的顏色互換），不過跟朋友討論之後覺得這樣太強了，應該是不會出……吧？

{% mtgcard "Ketramose, the New Dawn" %} 
 
黑白神 aka 曾經的DFT卡王，當初近代因為拿來對付 {% mtglink "Grinding Station" %} 套牌的關係暴漲。但狡兔死，走狗烹，隨著 {% mtglink "Underworld Breach" %} 被禁， {% mtglink "Grinding Station" %} 套牌直接消失，黑白神也就退出了前線，現在只剩7鎂左右（現在還比不上 {% mtglink "Stock Up" %} ）

{% mtgcard "Monument to Endurance" %} 
因為世界賽中伊捷課程套牌大放異彩的關係而價格飆升，讓這個系列感覺沒那麼糟……（其實還是沒多好）

## 韃契: 龍襲風暴 （Tarkir: Dragonstorm, [TDM](https://scryfall.com/sets/tdm)）

我很喜歡第一次韃契（韃契可汗）時的標準，因為當時因為[KTK](https://scryfall.com/sets/ktk)這個系列牌強又有找地地，導致當時大量開補充包，連一些標準必須放四張的R卡大概也都100元左右，輪抽甚至有些人拿都不拿了。

回到這次的韃契，雖然牌強度沒有當年那麼誇張，但市場反應依舊熱烈，開盒量比其他系列高出許多，這也間接導致牌價相對較低。能在龐大的供貨量下仍維持如此高的銷售動能，並帶來相對親民的牌價，這才是真正良性的市場循環啊！

限制賽部分，雖然這是個三色系列，但是開發完之後大家就開始猛拿紅白快攻……XD 畢竟系列越慢，快攻就越厲害！不過，我自己還是比較喜歡拿五色龍套牌。

{% mtgcard "Cori-Steel Cutter" %} 
 
第一張就直接拿刀出來講，預覽的時候都沒注意到這張是做壞的牌，刀就是更難處理的 {% mtglink "Monastery Mentor" %} ，直接讓紅藍靈技成為T1套牌；也因為刀標準實在是沒有非常有效的處理手段，千葉Spotlight之後就毫無懸念的禁掉了……

不過這張在近代仍然是強如鬼神，甚至有需多0費咒語可以讓刀二回開始啟動，組一套近代紅藍靈技便宜又強力！推薦！

{% mtgcard "Marang River Regent" %} 

另一張在千葉Spotlight大量出現的就是藍龍侯。主要用在白藍全知全能的出口：兩隻龍 + {% mtglink "Roiling Dragonstorm" %} 就可以把牌庫抽起來……其實不行，最後一張是抽不起來的（一次抽兩張會抽爆）。

我在千葉就有對到對手致勝手段卡在牌庫最後一張牌，不過他的版本有放 {% mtglink "One with the Multiverse" %} ，可以從牌庫頂施放……所以我還是倒了。

現在需要堆墳的套牌或是控制都還是很愛這張。

{% mtgcard "Ugin, Eye of the Storms" %} 
 
明明是對抗奧札奇的人，能力卻如此契合奧札奇，你真的不是叛徒嗎 = =？

{% mtgcard "Craterhoof Behemoth" %} 
 
以前還叫WMCQ的時候，我拿阿布贊挖墳有打到四強。一般都會放一張當更快的致勝手段，不過其實那副最強的牌應該是 {% mtglink "Angel of Serenity" %} ，現在基本失業中。

{% mtgcard "Mox Jasper" %} 
 
叫瑪珂的（應該）都不是弱者，很抱歉這張就不行。其實還有[另一張瑪珂](https://scryfall.com/card/mh1/226/mox-tantalite)也沒人用……不過大概沒人在意。我記得一開始也很貴，後來就被看破手腳。

{% mtgcard "Winternight Stories" %} 

最後就拿這張來講。其實我覺得這張也是導致 {% mtglink "Proft's Eidetic Memory" %}被禁的原因之一，3點法力抽3張實在抽太大了。棄牌就另一方面有更多操縱空間，搭配Warp的 {% mtglink "Quantum Riddler" %} 直接再從墳場Harmonize更是妙不可言。

## 太空戰士/最終幻想 （Final Fantasy, [FIN](https://scryfall.com/sets/fin)）

這系列給老威嚐了一個大甜頭，在上市之前就已經是MTG有史以來賣最好的系列，也大概是這樣之後合作系列可能只會多不會少。

這次跨界合作也是第一次進標準（之前的合作除了Secret Lair之外，像[魔戒](https://scryfall.com/sets/ltr)、[刺客教條](https://scryfall.com/sets/acr)都是要近代以上才能使用；[龍與地下城](https://scryfall.com/sets/afr)則是威世智自己的IP所以不太算合作系列）。

說真的，這個IP實在太紅了，不太可能真的完全不認識任何FF的角色（也許你沒玩過FF，但也看過[蒂法](https://scryfall.com/card/fin/206/tifa-lockhart)跟[艾莉絲](https://scryfall.com/card/fin/4/aerith-gainsborough)）。我自己只有完整地破完FF5/6/7/8/9就只有玩一部份（這樣是不是暴露年齡了？）。

如果你有去數一下這系列的牌分別出自FF哪一代，會明顯發現牌集中在6/7/10/14，這剛好也是FF系列最紅的幾代。順便一提FF14繁中服剛開，有興趣的可以去玩玩看。

另外我覺得這個系列的英文翻譯跟日文不太一樣，所以會附上日文牌名。

{% mtgcard "Vivi Ornitier" %} 
<p style="text-align: center;">《迷える黒魔道士、ビビ》</p>
 
FF9 的真主角！看看吉坦 {% mtglink "Zidane, Tantalus Thief" %}被放在U卡，而比比卻放在MR就知道了吧XD！

能夠看力量產法力這點在預覽時就備受討論，PT上也有比比搭配 {% mtglink "Agatha's Soul Cauldron" %} 來大量展開的「比比鍋」套牌。雖然在PT甚至是千葉Spotlight上並沒有很亮眼，但是禁牌跟輪替之後，比比鍋竟然幾乎沒有少東西，一下子就躍遷成T0套牌。

後來雖然紅快崛起，但對到鍋子其實也沒有到真的多好打，於是之後標準就陷入了不可言喻的惡夢中。一直到11月初老威終於把比比送進banlist，才算是結束這一切。

{% mtgcard "Suplex" %} 
<p style="text-align: center;">《メテオストライク》</p>
 
Suplex一般叫後背摔／過肩摔。沒玩過FF6的人大概不知道為什麼要對著火車做過肩摔。從日文原文翻的話要叫MeteorStrike才對。

這是FF6裡面馬修的技能「必殺技」的其中一招。其中一段劇情是他們誤上了載運死者靈魂的[魔列車](https://scryfall.com/card/fin/110/phantom-train)，最後打BOSS的時候我方角色會被魔列車追著跑，這時候使用Suplex就可以把魔列車抓起來摔。可能因為太好笑了，這個梗意外的很有名。

{% mtgcard "Self-Destruct" %} 
<p style="text-align: center;">《自爆》</p>
 
這張是FF5在次元狹縫中，主角和ネクロフォビア對戰時，先前的對手[吉爾迦美修](https://scryfall.com/card/fin/139/gilgamesh-master-at-arms)突然出現來協助，並留下了flavortext的那段話：「如果就這樣離開的話，只會在歷史上留下臭名！」說完道別的話，就和BOSS自爆了……

> 「このまま 帰ったんじゃ、かっこわるいまま歴史に残っちまうからな！」
――ギルガメッシュ

吉爾迦美修的招牌BGM也是FF系列非常有名的「[大橋上的死鬥](https://scryfall.com/card/fca/9/fatal-push)」。這張也有出成[FCA](https://scryfall.com/sets/fca)的牌喔。

{% mtgcard "A Realm Reborn" %} 
<p style="text-align: center;">《新生エオルゼア》</p>
 
這張是FF14 2.0版本的名字。那一定有人會問1.0是啥？當初FF14第一版做太爛了，所以最後直接砍掉重練（真的是砍掉，都把伺服器關了……）。最後應該是參考不少魔獸世界的設計弄了一個2.0版本，所以新的FF14其實也有人戲稱是日本魔獸世界。

{% mtgcard "Summon: Bahamut" %} 
<p style="text-align: center;">《召喚：バハムート》</p>
 
每次說到日本三大RPG，一定會有的就是FF太空戰士、DQ勇者鬥惡龍，第三個好像沒有定論……

那講到FF最大的特色大概就是召喚獸，而召喚獸裡面最有名的一定就是巴哈姆特。現在台灣最大的電玩資訊站[巴哈姆特](https://www.gamer.com.tw/)其實就是從這個名稱來的。

這次把召喚獸設計成傳記生物真的是很符合召喚獸的風味，不過也為了這個稍微修改了規則：傳記失去異能的時候不會直接爆掉，結果讓[克撒傳](https://scryfall.com/card/mh2/259/urzas-saga)撿到便宜XD，不怕[腥紅之月](https://scryfall.com/card/2xm/118/blood-moon)了。

> 編按：有興趣的讀者歡迎回頭查閱這篇 — [血月如何從克撒傳的天敵變隊友](https://guildmagesforum.tw/How-does-Urzas-Saga-Become-Blood-Moons-Friend/)

{% mtgcard "Stay with Me" %} 
<p style="text-align: center;">《最後まで・・・/リスティックの研究》</p>
 
最後偷偷放一張FCA的牌。很多沒玩過FF10的人都有問我為啥這張只有優娜在哭？我只能說……這是大雷，自己去玩FF10吧！FF10應該是公認FF系列劇情最棒的一代了。

整體來說FF真的是有用心設計的系列，很多地方是有玩過遊戲的人真的能感到共鳴。今年去千葉Spotlight也有很多FF相關的介紹和展示。雖然整體牌的強度沒多高，不過圖是真的棒棒。至於之後有沒有機會出其他的日系IP合作就很難說了。

## 虛空邊域 （Edge of Eternities, [EOE](https://scryfall.com/sets/eoe)）

雖然又回到MTG時空了，但是這個系列已經飛出外太空，除了有太空船之外還有星球，實在是太過科幻了，不太像MTG……

意外的有一些老種族出現：卡甫、裂片妖、奧札奇……所以是說這些種族都是從外界來的嗎？其實演到這邊我已經不知道故事發展到哪裡了XD。

EOE應該是我今年輪抽打最多次的系列，我印象中還算平衡，好像沒有哪個特別強或特別弱的。而且算是有不少強R跟秘稀的系列，但是大概是因為電震地已經重印太多次了，[史芬斯](https://scryfall.com/card/eoe/72/quantum-riddler)跟[蛇蛇](https://scryfall.com/card/eoe/201/ouroboroid)還是很貴QQ。

{% mtgcard "Quantum Riddler" %} 
 
近代霸者！為什麼手牌在1張以下抽牌就會多抽1張啊……每次對手二回合 {% mtglink "Psychic Frog" %} ，三回合Warp {% mtglink "Quantum Riddler" %} ，我就覺得要倒了。搭配雲移更是妙不可言。標準雖然也有 {% mtglink "Splash Portal" %} 可以去雲移史芬斯，不過效率差很多，就沒那麼強力。

{% mtgcard "Ouroboroid" %} 
 
綠色常有的限制超級炸彈，活過兩回合大概遊戲就結束了。以往這種東西只能活在限制賽，但這次應該是做得有點離譜。標準藍綠快攻跟紅綠躁狂我都看過有人放，不過身材1/3還是太脆了，沒放到豆就被殺的話tempo整個被拉走。

{% mtgcard "Cosmogrand Zenith" %} 
 
俗稱刀刀人。因為打紅藍刀之前我就有打EsperSelf-Bounce，在刀被禁掉之後我就跑去收這張打回老deck。其實強度上是不錯的，但是三色的ManaBase真的是有夠爛，常常被自己搞死。3費也比較難在施放的該回合同時做第二個咒語，還是沒達到刀的高度。

{% mtgcard "Icetill Explorer" %} 
 
地套牌最愛的東西都塞進來了：一回合下2張地+墳場下地，還可以幫忙自磨，不擔心墳場沒東西。這張最好笑的大概是EOE的特別來賓卡位有印 {% mtglink "Strip Mine" %} ，如果兩張都有開到就可以在限制賽炸光對手地牌。

{% mtgcard "Diplomatic Relations" %} 
 
不知道有多少人知道，這張如果照原本牌面敘述的話，是可以用對手的生物打他自己的。這實在太不綠色，所以上市之前就hotfix改掉了，現在那個+1/+0給警戒只能給自己生物。

{% mtgcard "The Endstone" %} 
 
可以跟對手的 {% mtglink "Hidetsugu’s Second Rite" %} 形成友情組合技，第二條異能結算完被直擊10點傷害死去XD 雖然都是標準可用，但應該不會有人真的放……吧？

## 漫威蜘蛛人 （Marvel's Spider-Man, [SPM](https://scryfall.com/sets/spm)）

蜘蛛人在預覽之前大家還是很期待的，但是最後產出的卻是一坨……嗯……
蜘蛛人系列一直罵聲不斷，我覺得有幾點原因：

1. 牌強度不夠（牌不夠強就沒人要）。
2. 補充包貴（合作就漲價）。
3. 合作系列（總是有些人對MTG跟外部系列合作不滿）。

FF牌其實強度也不夠，為什麼罵聲就很小？看看那個日繪，香的咧……牌強度重要嗎？老威還不快點開竅……

另一點就是蜘蛛人限制賽的不平衡讓很多人也不想打，因為有Web-slinging這個異能可以讓你快速的下出高費生物，讓落後方非常難追tempo。白綠／白藍的勝率高出許多。至於2 Pick輪抽我在現實中沒打過，MTGA上拿起來感覺是很容易撞色啦，不過我也不是輪抽大師就不評論這部分。

另外，因為大人的版權問題，蜘蛛人系列在數位版本（MO/MTGA）上有另外的圖片，牌名也幾乎都改了（通常是傳奇）。這擺在FF之後更是讓玩家憤怒，我連想換個蜘蛛人的頭像都沒辦法？明年的漫威英雄系列我猜會有一樣的問題，可能要有心理準備……

該回到牌了。先說一下我對漫威一點也不熟XD，在這之前我好像只看過鋼鐵人1。因為MTG跟蜘蛛人合作，我還去借了復仇者聯盟3&4來看。蜘蛛人電影的部分我是看2012的《驚奇再起》，其他多重宇宙的蜘蛛人就是網路上看過一些資料而已。如果有講錯的部分請多多包涵。

{% mtgcard "The Soul Stone" %} 
 
在復仇者聯盟三中薩諾斯到處收集的無限寶石其中一顆。這次只出一顆，想當然而剩下的就得等其他漫威合作了（是要等到何年何月？）。我不了解的是這顆跟蜘蛛人沒關聯吧？？？為啥是出這顆？？？

要得到靈魂寶石需要犧牲你的摯愛，在MTG中只要隨便犧牲一個token生物就可以了，真是太划算！

{% mtgcard "With Great Power…" %} 
 
沒看過蜘蛛人的也應該聽過的名言：「能力越大，責任越大」（With great power comes great responsibility.）。在MTG裡面只能用來承受傷害了。


{% mtgcard "Impostor Syndrome" %} 
 
著名的蜘蛛人互指梗圖，但是其實這張圖的對象只是假扮成蜘蛛人的竊盜犯。但這個梗實在太紅，後來索尼也有故意讓三代蜘蛛人演員互指來重現這個迷因。

{% mtgcard "Superior Spider-Man" %} 
 
這大概是除了 {% mtglink "Multiversal Passage" %} 之外，蜘蛛人在標準系列用量最多的牌了。蜘蛛人的著名反派[八爪博士](https://scryfall.com/card/spm/128/doctor-octopus-master-planner)跟[彼得帕克](https://scryfall.com/card/spm/10/peter-parker-amazing-spider-man)交換意識之後，八爪博士決心成為比蜘蛛人更優秀的英雄，所以就叫究極蜘蛛人……MTG中大家只會拿來變成[惡魔](https://scryfall.com/card/lci/94/bringer-of-the-last-gift)，八爪博士你還是繼續當壞人好了。

{% mtgcard "The Death of Gwen Stacy" %} 
 
因為我只看了第一集，莫名其妙被牌名暴雷= =。不過在其他多重宇宙中，會變成彼得死亡、關活下來，這個時空就是關變成[Ghost-Spider](https://scryfall.com/card/spm/78/gwen-stacy-ghost-spider)。

## 降世神通: 最後的氣宗 （Avatar: The Last Airbender, [TLA](https://scryfall.com/sets/tla)）

這系列合作要出之前應該很多人很傻眼：「怎麼會跟這個合作？」不過降世神通其實在歐美非常的紅，而且評價也很高，只是亞洲圈這邊知道的人不太多。如果想看的話，Netflix上可以找的到，他甚至有出過真人版XD（這個應該就不太需要看了……）。

降世神通雖然才出了一個月不到，但是還在預覽就出現各種強牌，甚至在世界賽八強中，使用率最高且我覺得也是最強的套牌是伊捷課程，其中使用了大量的TLA新牌。這系列也是是目前合作系列最強的一個。

限制賽的話大家都知道這系列紅白／白藍是強力色，不過好像也沒有到蜘蛛人那種不拿白就沒辦法打牌的程度，只是慢的色組更需要炸彈去支撐。

{% mtgcard "Badgermole Cub" %} 
 
在發售後幾周被大家發現做壞的牌，價格也不斷飆升。搭配綠色各種mana頭可以做出超級加速。我的[粉專回文最多的文章](https://www.facebook.com/share/p/1BcPx97fCP/)竟然是靠北 {% mtglink "Badgermole Cub" %} 太貴的那篇XD。不過世界賽之後有點被看破手腳，我覺得 {% mtglink "Badgermole Cub" %} 不是不強，是他更適合在有各種特殊地牌的老賽制發光發熱。

{% mtgcard "Boomerang Basics" %} 
 
我覺得這才是真正有可能吃Ban的牌。他就是更強的 {% mtglink "This Town Ain't Big Enough" %} 。現在藍色套牌沒有放 {% mtglink "Stormchaser's Talent" %} + {% mtglink "Boomerang Basics" %} ，都不知道要怎麼玩牌了。法力足夠的狀況下就可以一直循環Talent生水獺又抽牌，加上又是Lesson，各種加分。

{% mtgcard "Accumulate Wisdom" %} 
 
想體驗使用Power 9的快感嗎？這張就是 {% mtglink "Ancestral Recall" %} 。你說還要兩費？沒關係，我們還有下面一張牌。

{% mtgcard "Gran-Gran" %} 
 
蘇卡跟凱塔拉的奶奶。墳場有3張Lessons就可以減費實在太簡單，讓伊捷課程整副爆發力更高，阿嬤功不可沒！

## 結語
    
今年的MTG是個大起大落的一年，從年初評價不太行的乙太飄移，到年中大賣特賣的太空戰士/最終幻想；然後是失望的蜘蛛人，降世神通原本不期待卻又大幅改變了環境。

Universe Beyond （UB）的評價過於兩極，標準系列數量的增加、持續高騰的卡價、還有不斷發生的禁牌，很難說標準是個健康的環境，只希望2026的系列能讓構築環境變得越來越好。
