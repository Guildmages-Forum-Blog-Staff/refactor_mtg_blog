## 前言

{% mtglink "Gollum, Riddle Master" %} 在剛預覽時，讓許多人（包括我）質疑：「這樣的能力也能印成秘稀！？」殊不知，如何把這張牌用出符合他秘稀的身價，正是謎語大師出給玩家們的第一個考題。


## 有趣的設計

![](https://i.meee.com.tw/Yf8pjtR.jpg)

> 謎語大師咕嚕 {1}{B}
> 
> 傳奇生物～半身人／驚懼獸
> 
> 於咕嚕進場時，選擇奇數或偶數。（零是偶數。）
> 每當任一對手施放魔法力值為該種數值的咒語時，選擇一項，且不能是此前選過的～
> 
> - 在咕嚕上放置一個+1/+1指示物。
> - 每位對手各失去2點生命且你獲得2點生命。
> - 抽一張牌。

三選一，要喊對才有回報，且同一個選項不能重複選。如果三個選項都選過，這個異能會被從堆疊移除，什麼事都不會發生。附帶一提，咕嚕進場選奇偶數的規則寫法，與 {% mtglink "Pithing Needle" %} 與 {% mtglink "Cavern of Souls" %} 相同，都是 " *As ... enters, ……* "。不使用堆疊，也無法被回應。

- 情境一：乍看之下要求有點高，如果落空的話，二費出一隻3/1「白板」在現在的標準中可能無法接受。
- 情境二：如果我們選中了呢？假如對手毫無干擾，讓我們僅以二費獲得一隻4/2生物、4點血差、以及抽一張牌，那這個投資是非常棒的！更不用說咕嚕若進攻造成傷害、或防守換掉對手的生物，那更是十分美妙！

實際使用上，我們的體感會落在上面兩種情境之中，而本篇要說的，就是如何讓我們盡可能地趨近情境二。

## 如何成為謎語大師？

咕嚕一進場選擇奇數或偶數後，很大程度上就決定了他的上下限。接下來我們以一個極端的例子，來看看我們在構築賽中可以怎麼使用咕嚕。

薪傳（Legacy）賽制中，假設你是先手的黑底套牌，你對手調度一，你下沼澤後先手施放 {% mtgilink "Dark Ritual" %} 後，施放 {% mtglink "Thoughtseize" %} 看到了以下手牌：

![](https://i.meee.com.tw/MpIXS6B.jpg)

你將 {% mtglink "Kappa Cannoneer" %} 棄掉，用剩餘的兩點黑施放了 {% mtglink "Gollum, Riddle Master" %} ，那這時謎底應該相當清楚了 —— 選擇「偶數（even）」。

當然，以上只是一個假設性的範例。但其實這個案例中正好體現了用好謎語大師咕嚕的兩個重點：

1. 使用能看手牌的牌，如 {% mtglink "Thoughtseize" %} 、或像 {% mtglink "Arachne, Psionic Weaver" %} 這類可以讀到對手手牌的效果。
2. 若對手手牌未知，嘗試去讀他是meta上的哪一副套牌，並在賽前熟讀meta套牌的牌張配置。

## 標準賽中的謎語大師

隨著[HOB](https://scryfall.com/sets/hob)的發售，MO上也已經有幾副套牌嘗試著將咕嚕放進套牌中，比如說這副純黑快攻。

[純黑快攻牌表](https://www.mtggoldfish.com/deck/7917382#paper)

正如上面所說的，利用黑色的棄牌閱讀手牌資訊，等於是在知曉謎底的狀況下使用咕嚕。但如果要增加我們的命中率，熟讀環境meta必不可少。接下來我們會拆解[2026年8月10日禁牌](https://magic.wizards.com/en/news/announcements/banned-and-restricted-august-10-2026)後的標準環境。於2026年8月20日檢索mtggoldfish上14天內的標準高使用率套牌為例，並輔以幾副台灣賽場較常見，但meta佔比較少的套牌。

![](https://i.meee.com.tw/jTiXkII.jpg)


### 1. 純綠地落（Mono-Green Landfall）

![](https://i.meee.com.tw/vAixJk0.jpg)

> 截圖中的mana value是主備牌的總和，實際考慮時要把主備牌局、還有對手可能會有的換備計畫一併納入考慮，才能有助於謎語大師的猜題命中率！

純綠地落的奇偶數牌數量差不多，我們的選擇會相對困難一些。但好處是對手正編幾乎沒有解牌，只要喊對了，咕嚕就能幫我們賺到大量的價值。喊的時候要看出咕嚕的回合數。
- 假設我方先手，對手一回 {% mtglink "Llanowar Elves" %} ，那這邊我方二回若沒有解，選擇出咕嚕的話可以考慮喊「奇數（odd）」，目標吃對手跳費出 {% mtglink "Earthbender Ascension" %} 或 {% mtglink "Lumbering Worldwagon" %} 。
- 同樣我方先手，對手一回 {% mtglink "Sazh's Chocobo" %} ，一樣出咕嚕選 **奇數** ，對手可能會再拍一隻chocobo然後下找地地。這邊建議優先選放+1/+1變成4/2就能幫我方爭取一些時間；選抽一張也是可以，但很快對面的Chocobo就會變到3/4以上，我們的咕嚕就換不掉了。
- 後手第三回合，因為下回合對手應該會拍出四費威脅，這邊如果施放咕嚕建議選 **偶數** 。如果對手是出生物就選放+1/+1試著頂住4防生物。若對手出 {% mtglink "Sapling Nursery" alt="樹妖結界" %} 的話我們應該快輸了，趕快抽一張牌看看未來。

> 以上的情境，都是在手牌沒有正確的威脅對應牌、且手上沒有其他比咕嚕更好的選擇才會進行。如果有更好的選擇，就不需要出咕嚕。

![白綠地落](https://i.meee.com.tw/tBao2aU.jpg)

如果對手是白綠地落的變體，那對於我們而言，抉擇就簡單得多。除了純綠地落會看到的威脅外，白綠地落新增的解牌、爆發性的威脅 {% mtglink "	Practiced Offense" %} 等都是奇數，喊 **奇數** 的命中率會較高。

### 2. 四色控制（4c Control）

![](https://i.meee.com.tw/RjNTiYF.jpg)

四色控制中，除了 {% mtglink "Firebending Lesson" %} 解牌大多集中在偶數。但關鍵威脅如 {% mtglink "Tablet of Discovery" %} 、 {% mtglink "Jeskai Revelation" %} 、甚至備牌的 {% mtglink "Thor, God of Thunder" %} 等都是奇數牌。我的建議如下：
- 對手 {% mtglink "Tablet of Discovery" alt="石板" %} 尚未登場、且你有應對的方式 — 喊 **偶數** 。增加咕嚕待在場上的機會，或至少幫其他生物擋一張解。
- 對手石板已結算，且你對接下來的威脅沒有抗性 — 喊 **奇數** 。看有沒有機會在對手施放奇數威脅時神抽一張去應對。
- 我方後手，對手第二回合法力開放，我方沒有應對石板牌並決定打出咕嚕 — 喊 **奇數** 。下限是對手回應偶數解去除咕嚕，第三回合準時拍石板；但如果對手沒有，就有機會讓對手用偶數牌繞著打，咕嚕就幫我們爭取到時間。（如果對手手上是 {% mtglink "Stock Up" %} ，那我們就更有機會在石板結算前先抽一張對應牌）。
- 我方先手，第二回合出咕嚕 — 喊 **偶數** 。去擋對手的二費解跟 {% mtglink "Consult the Star Charts" %} ；若被回應 {% mtglink "Firebending Lesson" %} 小虧，但沒有到不能接受。
- 如果對手下回合可能掃場 — 不要出咕嚕。所以不用喊XD

![潔斯凱控制](https://i.meee.com.tw/yg71kXP.jpg)

而若是潔斯凱控制這邊，對手的解牌是以課程牌為主，幾乎都是二費，因此喊 **偶數** 的期望值較高。但同四色控制，對手的威脅都集中在奇數，仍需依當前回合數與情勢去考慮要喊什麼。

### 3. 藍黑中速（Dimir Midrange）

![](https://i.meee.com.tw/lLhXPRg.jpg)

從圖上看起來奇偶數牌數量差不多。但藍黑中速是削得很尖的節奏套牌，我們比較不能接受的是被一費點殺如 {% mtglink "Requiting Hex" %} 換掉咕嚕。因此我的建議是：大部分的情境可以喊 **奇數**，尤其是對手保留一費開放時。

而咕嚕3/1的體格，在跟體格偏小的藍黑對陣時，甚至可以單吃 {% mtglink "Enduring Curosity" alt="藍貓" %} ！當我們選過抽牌後，第二次觸發第二次咕嚕的異能時可以選在咕嚕身上放豆。讓我們能擋住對手沒有 [+1] 的 {% mtglink "Kaito, Bane of Nightmares" %} 、或變成生物的 {% mtglink "Restless Reef" %} ，也能頂著1/1小飛兵進攻。

比較差的狀況是被跳 {% mtglink "Floodpits Drowner" %} ，若判讀出對手可能有這張牌，則可以考慮改喊 **偶數** 。

### 4. 藍黑拷打魔（Dimir Excruciator）

![](https://i.meee.com.tw/TxIZaZT.jpg)

絕大多數喊 **偶數** ，去應對對手二、四、六回合的關鍵威脅。即使被一費點殺，擋掉一張殺牌也是好的。但要注意若被對手的 {% mtglink "Superior Spider-Man" %} 變成我方的咕嚕，頭痛的就會是我們。

奇數牌的部分，大多是點殺、棄牌、抽牌、與掃場。而這些牌在對局中結算了，除了掃場外通常也不會讓你直接輸掉對局，因此還是喊偶數的綜效較高。如果對手因為咕嚕的存在而沒有選擇把費用打滿而去做其他的事，那我們也是爭取到了時間。當然，如果你想打貪心一點，選 **奇數** 也沒有不行。

### 5. 黑白補血（Lifegain）

![](https://i.meee.com.tw/0WY4APV.jpg)

雖然對手奇數牌不少，但 **偶數** 牌通常更為關鍵。由於對手的解牌較少，除了抽牌以外，我會建議優先、或次優先選擇放豆。4/2的體格面對 {% mtlgink "Deep-Cavern Bat" %} 、 {% mtglink "Voice of Victory" %} 這樣的牌可以用體格優勢硬打搶血。雖然對手超級會奶，但能把握的進攻機會仍是不容錯過。吸2血通常是最後的選項，除非你已經被打到快沒命了。

### 6. 伊捷咒語元素（Izzet Spellementals）

![](https://i.meee.com.tw/k8Z0UAV.jpg)

對手套牌結構嚴重偏向 **奇數** ，因此我們的選擇就簡單很多。少數會考慮選 **偶數** 的情境是不想被對手的 {% mtglink "Prismari Charm" %} 一換二。

### 7. 藍白節奏（Azorius Tempo）

![](https://i.meee.com.tw/tQ3aKNr.jpg)

對手的偶數牌不少，但我會比較建議選 **奇數** ，三費的閃現威脅都不容小覷。在場上已結算 {% mtglink "High Noon" %} 的情況下，如果能讓對手顧忌咕嚕而少出一次三費閃現，那帶來的節奏優勢是很棒的。

### 8. 蘇勒台掀墳（Sultai Reanimator）

![](https://i.meee.com.tw/QYR4kGJ.jpg)

關鍵威脅 {% mtglink "Superior Spider-Man" %} 是偶數牌，但起動的資源點上， {% mtglink "Oblivious Bookworm" %} 、 {% mtglink "Dredger's Insight" %} 也是偶數、但 {% mtglink "Overlord of the Balemurk" %} 、 {% mtglink "Rapid Rescue" %} 、與決殺前的生物導師 {% mtglink "Formidable Speaker" %} 都是奇數。不太容易選。初步的理解是對手前四回合的經營階段時可選 **奇數** ，但如果下回合幾乎確定對手會出蜘蛛人，則可以選 **偶數** 拼抽一張應對牌。

### 9. 瑪爾都棄牌（Mardu Discard）

![](https://i.meee.com.tw/QYR4kGJ.jpg)

我方二回先手選 **偶數** 。二回後手，如果對手沒有關鍵的二費威脅在場，還是選 **偶數** 。有命中優先選吸2點血，然後對手推過來咕嚕能擋就要擋，一來一回至少靠咕嚕幫你奶到5～6點血差，夠本了。

如果對手場上什麼都有，看起來下回合就要用 {% mtglink "Practiced Offense" %} 起跑、甚至可以跑兩次時才會去選 **奇數** 。這個對局，活下去是第一要務。

### 10. 純紅快攻（Mono-Red Aggro）

![](https://i.meee.com.tw/EEHetSH.jpg)

**奇數，一定選奇數** ！

除了對手高密度的一費生物與一費燒外，關鍵更在於不能被對手Warp出的 {% mtglink "Nova Hellkite" %} 進場點死咕嚕，對手出龍我們可以先在咕嚕上放豆而不被點死，進而保留一個阻擋者來讓當回合傷害不至於崩盤。

對手二回出的生物我們幾乎都能用咕嚕擋死（ {% mtglink "Zhao, the Moon Slayer" %} 除外）。而四回的 {% mtglink "Sunspine Lynx" alt="山貓" %} 登場前，我們也有機會先奶2血撐一下，若結算第二次，則可讓咕嚕放豆，這樣我們可以頂住山貓。偶數牌中比較麻煩的是新牌 {% mtglink "Smaug the Magnificent" %} ，我們拿他一點辦法也沒有，而且下一回合進攻就能輕鬆點殺咕嚕。

> 但我覺得台灣會選擇打紅快的人，應該不太會想多花錢去收 {% mtglink "Smaug the Magnificent" alt="史矛革" %} ……吧？ ~~這應該也算是一種meta判讀？~~

### 11. 藍白 Momo（Azorius Momo）

![](https://i.meee.com.tw/rP9RMIo.jpg)

也是一個一定選 **奇數** 的對局。受益 / 受限於 {% mtglink "Momo, Friendly Flier" %} ，這副套牌的生物威脅都是奇數，也是一個好選的對局。

### 12. 伊捷靈技（Izzet Prowess）

![](https://i.meee.com.tw/H4g9dle.jpg)

伊捷靈技堪稱標準中的不死鳥、百足之蟲，死而不僵！經歷了多次禁牌，這副套牌仍可以停留在meta上，就可窺見之前這副套牌究竟有多強！

而靈技套牌的特性，就是套牌中會放滿各種一費的過牌咒語（Cantrips）。那我們的答案也是顯而易見。選 **奇數** 。

### 13. 波洛斯龍（Boros Dragons）

![](https://i.meee.com.tw/42ObpEU.jpg)

雖然一費有 {% mtglink "Momo, Friendly Flier" %} 跟點殺，但這副套牌的資源點基本上是二費，不論先後手，二回後手對手通常是要拍一個 {% mtglink "Sarkhan, Dragon Ascendant" %} 或 {% mtglink "Magda, the Hoardmaster" %} 來賺珍寶；若先手對手二回已先結算Sarkhan，那下回合應該是要跳費出四費龍。從概率上看，選 **偶數** 的期望值應較高。

別忘了，Sarkhan進場若請援（behold）派出珍寶，他必須展示一張龍牌。那我們就等於提前知道了答案。

### 14. 白綠 Ouroboroid（Selesnya Ouroboroid）

![](https://i.meee.com.tw/EC6VIFF.jpg)

{% mtglink "Badgermold Cub" %} 被禁的最大受害者，但考慮到台灣玩家可能牌都收了不想換套牌，還是有機會會有人繼續打這副，因此上榜。

這副的猜法相當接近上面介紹過的瑪爾都棄牌，絕大多數都選 **偶數** ，除非對手下回合要用 {% mtglink "Practiced Offense" %} 衝爆你才改選 **奇數** 。

### 15. 鐵木爾 Kona（Temur Kona）

![](https://i.meee.com.tw/w2tG1gL.jpg)

雖然關鍵威脅 {% mtglink "Kona, Rescue Beastie" %} 是偶數，但我們若選偶數就錯了。組合技套牌，等到他要結算威脅時通常就來不及了；我們要做的事，是讓對手前面的抽牌、導師元件做得很不舒服。因此，必須選 **奇數** 來卡住對手。更巧的是，這副套牌的解牌都是一費的回手咒語，那選奇數可以讓對手用得更痛苦，甚至還能再來一次！

## 結語

寫著寫著，就變成了標準賽制中的各主流套牌的費用盤點。但奇偶費用的集中程度與對局情境，正好與謎語大師咕嚕的猜題準確率有著千絲萬縷的關係。

總結一下猜題的情境：

- 若你有棄牌咒語、或看手牌的效果。那不用猜，你已經知道謎底了。
- 若對手套牌未知，那你賽前要先研究該賽制的meta來增加命中率，像這篇做的假設這樣。
- 若你能在對局中讀出對手可能握著某張關鍵牌，那就大膽地猜對應的費用。猜錯了也無妨，但猜對了，你就能收到對手痛苦的神情作為回報。

而三個答對謎語的報償，我們也可以針對不同套牌去排優先次序：

- 面對快攻，我們必須活下去。先選吸2血，再選放豆增加阻擋上限，最後選抽牌。
- 面對中速、控制、甚至組合技套牌，先選抽牌，再依對局狀態選其他兩項。

當然，不要忘了不同對局的形勢，甚至攻守雙方的角色都會不斷轉換。以上的建議都只是一般性的參考，讀者要使用得好，必須動態地去調整。

成為謎語大師的第一步已準備好，接下來就是你們的旅程了。
