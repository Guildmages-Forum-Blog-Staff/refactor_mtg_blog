## Before We Start

在預覽降世神通：最後的氣宗（Avatar: The Last Airbender, [TLA](https://scryfall.com/sets/tla)）的牌張時，我第一眼看到 {% mtglink "Joo Dee, One of Many" %} 時，首先是為她那令人毛骨悚然的構圖而感到驚艷~~嚇~~，但在看第二次時，我注意到她竟然不具有傳奇的超類別，這在以角色為名的魔法風雲會牌張中幾乎是頭一次。為了瞭解更多，我開始對這張牌、以及降世神通的故事做了一些研究。

這是我初次接觸降世神通這個IP而寫下的粗淺理解，如有疏漏或不精確之處，也希望喜歡這個IP的朋友不吝指正。

## Joo Dee是誰？

{% mtgpick "tla" 105 %}

在降世神通的故事中，Joo Dee是[神](https://scryfall.com/card/tla/4/aang-the-last-airbender)[通](https://scryfall.com/card/tla/59/katara-bending-prodigy)[小](https://scryfall.com/card/tla/241/sokka-lateral-strategist)[隊](https://scryfall.com/card/tla/198/toph-the-blind-bandit)（Team Avatar）為了找回 {% mtglink "Appa, Loyal Sky Bison" alt="飛天蠻牛阿帕" %} ，造訪強土國（Earth Kingdom）首都 {% mtglink "Ba Sing Se" alt="霸新塞" %} 期間負責接待他們的文化大使，但她實際的任務，卻是奉戴笠之命妨礙神通小隊找到阿帕行蹤的監視者。她臉上總是面帶親切但詭異的微笑、且從不正面回覆任何敏感性的問題，讓觀眾對其身份以及背後的故事感到好奇。

{% mtgpick "tle" 18 %}

[Joo Dee初登場 - B2: Earth CH:34](https://youtu.be/JHmMuHvyOv8?si=GWlpaOi3r64KgQmG&t=91)："You’re in Ba Sing Se now. Everyone is safe here."

在Joo Dee的「陪同」下，試著在霸新塞中查探阿帕消息的神通小隊一無所獲，而我們也注意到強土國民在Joo Dee在場時的反應相當不自然，懸疑的氛圍逐步加劇。由於急於求見 {% mtglink "The Earth King" alt="強土王" %} ，神通小隊混入貴族們的宴會時，遇見Joo Dee前來要他們盡快離開，但 {% mtglink "Aang, Swift Savior" %} 在宴會上不慎展露自己截氣神通的能力，[Joo Dee也因任務失敗，第一次面部出現笑以外的表情變化](https://youtu.be/PA4lxaBYugw?si=FfLqV34SANOl9r_n&t=321)。

在這之後，[神通小隊與龍鳳碰面，談話不歡而散後出現在他們面前的，是同樣名為「Joo Dee」、面貌相仿的另一個女人](https://youtu.be/Jpmc3VeJZXg?si=Ld45AMUZKPzzvsmd&t=126)。一周後，[Joo Dee從勞改湖（Lake Laogai）「度假」後回歸](https://youtube.com/shorts/cEZmdmrMduY?si=JeW4-x0eUiPt6x7N)，彷彿什麼也沒發生似的，卻更讓人覺得詭譎。在阻止神通小隊繼續尋找阿帕的任務失敗後，Joo Dee向戴笠（Dai Li）頭子 {% mtglink "Long Feng, Grand Secretariat" alt="龍鳳（Long Feng）" %} 回報時[罕見地表露出自我意志](https://youtu.be/CafopIYdmhg?si=8PiWl2lqbOx4idJz&t=914)，但隨即被龍鳳以[關鍵詞 "the Earth King has invited you to Lake Laogai" 強化洗腦效果](https://www.youtube.com/watch?v=O8pNjlIyrUk)。

{% mtgpick "ttla" 2 %}

後來，[神通小隊與反抗軍闖入戴笠的秘密基地，目睹Joo Dee們的洗腦培訓過程](https://youtu.be/O8pNjlIyrUk?si=NPE--54phg0RwpqP&t=10)，也正式揭破龍鳳與戴笠的非人道行為。而在強土國被 {% mtglink "Azula, Cunning Usurper" %} 奪權後，[Azula指派Joo Dee為傀儡政府的最高行政長官](https://youtu.be/dI0Cf0U1FNQ?si=2AKGSjIeclfJRuQF&t=67)，諷刺的是，漫畫中的Joo Dee雖衣著華貴登場，但手中卻是拿著薄荷糖，身為「最高行政長官」，卻仍忠實執行著接待外賓的文化大使的職責。在烈火國準備一舉毀滅強土國的這段時間裡，Joo Dee仍忠實扮演著她的角色，依照掌權者的指示去接見各方人士，作為穩定霸新塞政權的一枚棋子。

隨著 {% mtglink "Avatar Aang" %} 擊敗 {% mtglink "Ozai, the Phoenix King" %} ， {% mtglink "Fire Lord Zuko" %} 登基，烈火國與強土國的百年戰爭結束，戴笠瓦解，自由和平的新時代到來，Joo Dee們彷彿被遺忘在舊時代裡，不知所終……

## 異想天開

### Joo Dee與Jane Doe

延伸到英文上，Joo Dee的這個名字的設計，很有可能有致敬 "Jane Doe" 的意味。

這邊說明一下，Jane Doe在英文上並不是指特定的一個人，而是一個女性的「無名氏」，常用來指稱「訴訟程序中不知真實姓名的當事人」、「某人或普通人」、或是「未被確認身分的女性死者」。

> 文字出處為紐約時報中文網的《[Jane Doe：無名女的哀歌](https://cn.nytimes.com/culture/20181016/wod-jane-doe/zh-hant/)》

而強土國中那些被洗腦、被剝奪掉名字與主體性的女子們、那些總是笑臉迎人、機械性執行著任務的Joo Dee們，不正似古今中外的這些Jane Doe們，雖有一個「名字」，但僅僅是一個無法被識別的「代號」嗎？

那麼，傳奇的這個超類別，自然也無法與之匹配了。

### 勞改湖（Lake Laogai）

操控Joo Dee的關鍵詞 "the Earth King has invited you to Lake Laogai" 除了明示對Joo Dee們毫無人性的洗腦活動是發生在勞改湖底下的基地外，更是直指核心的與「勞改」二字相符。在戴笠全面滲透強土國國政以來，不知尚有多少Joo Dee們在此受到迫害、非人性地摧毀心智、甚至永遠沉眠在勞改湖底。

### TLE Source Material中Joo Dee的選牌的討論

{% mtgpick "tle" 18 %}

如同前面所說的，Joo Dee既然作為無名女子的代號，那傳奇的這個類別自然是不適用的。但在[TLE](https://scryfall.com/sets/tle)的設計中，卻是挑選了 {% mtglink "Sakashima of a Thousand Faces" %} 這張傳奇生物，相當可惜；真的要重印的話，選 {% mtglink "Sakashima’s Student" %} 或許更為適合。

從Joo Dee在故事中的篇幅來看，TLA中將她設計為不是傳奇這一點，才讓她的牌名 "Joo Dee, **One of Many** " 的意象更為貼切、更幽微地將戴笠鐵幕下的陰影，濃縮在Joo Dee這 **眾人之一** 身上。

## 補個魔風點

![](https://i.meee.com.tw/HbMtxAL.jpg)

沒錯！又是辣個熟悉的 {% mtglink "Agatha's Soul Cauldron" alt="鍋子" %} 最對味！今天我們要做的料理是Joo Dee鍋！只要把用鍋子放逐掉墳場的 {% mtglink "Joo Dee, One of Many" %} ，你其他身上有+1/+1指示物的生物，就可以在巫術時機，支付任意一點有色法力並橫置來派出自己的複製品！當然，作為效果的一部分，犧牲一個神器或生物這個代價還是少不了的。

> 這邊簡單說明一下：
> 1. 支付任意一點有色法力是Joo Dee的起動式異能中做為費用的一點黑色法術力，而鍋子的第一條效果則允許你用任意色法力來付費。
> 2. Joo Dee派出複製品的敘述是寫 "……. Create a token that's **a copy of this creature**, ……" 所以複製出來的會是身上有+1/+1指示物、且因鍋子而獲得Joo Dee起動式異能的那隻生物。

今天的料理是不是簡單又容易上手呢？那我們下期的魔風料理小教室再見囉！（並沒有）

## 結語

希望透過這篇短文，能讓讀者們理解降世神通深邃的內涵與魅力；而這個內容引發了我這次的探索，也間接證明了無疆宇宙（Universe Beyond, UB）的策略並不是僅會帶來不良的影響。精緻的設計與系列建構，將原本優秀的文本以全新的方式渲染給新的讀者，這是一次藝術的增幅，也是我希望UB能真正地做到的 — 雙向創造更多喜愛彼此內容的受眾，進而讓整體社群擴大並深度體驗。

回到本篇的女主角。雖然網路上我找不到更多的額外線索，但我相信在結局後的Joo Dee們，能於不再有戴笠的和平之世裡散入民間，逐漸拾回自己的記憶、名字、身分、以及主體性，並取回[內心的寧靜](https://scryfall.com/card/emn/36/peace-of-mind)。
