忍者龜（Teenage Mutant Ninja Turtles, [TMT](https://scryfall.com/sets/tmt)）將於2026年2月27日舉行售前賽活動、隔一週2026年3月6日正式發行，想更了解TMT的色組主題與組牌策略嗎？那就來看看這一系列的TMT限制賽初探吧！

- 機制介紹請看這篇：[忍者龜機制解析](https://guildmagesforum.tw/TMT-mechanism/)
- 在官方2026年2月20日發布的[Magic: The Gathering® | Teenage Mutant Ninja Turtles Prerelease Guide](https://magic.wizards.com/en/news/feature/teenage-mutant-ninja-turtles-prerelease-guide)中，有提到 "**key removal spell**" ，點選各色的魔法力符號就能查詢到相關資訊。話說，無色的 {% mtglink "Henchbots" %} 跟 {% mtglink "Weather Maker" %} （如果上面放了超過3個充電指示物）勉強也能算去除咒語，大家可以記一下。 

## 色組主題

![TMT輪抽五色組卡圖](https://i.meee.com.tw/zoROaQ1.webp)

### <span style="color:#C3B270">白</span><span style="color:#808080">黑</span>奇襲忍者 — （Sneaky Ninjas）

[奇襲機制牌有27張](https://scryfall.com/search?as=grid&order=name&q=oracle%3ASneak+(game%3Apaper)+set%3Atmt+prefer%3Abest)，其中15張是忍者、11張是瞬間/巫術（五色各2張 + 1張白黑色組的巫術 {% mtglink "Karai's Technique" %}）。

> 另有1張黑色的職業（Class） {% mtglink "Ninja Teen" %} 的LV3可以讓你墳場的生物有奇襲 {三}{<span style="color:#808080">黑</span>} ，但間接了點就是。

而[忍者生物牌在TMT中有42張](https://scryfall.com/search?as=grid&order=name&q=(type%3Acreature+type%3Aninja)+(game%3Apaper)+set%3Atmt+prefer%3Abest)，扣掉上面提到具有奇襲費用的15張後，仍有27張。而白黑色組可用的忍者（包含混血法力牌）則有26張，選擇上相當的豐富。

![](https://i.meee.com.tw/8iTXRgn.jpg)

讓我們從上圖最右邊3張的雙色U卡指標牌（Signpost）開始。兩張白黑雙色牌都具有奇襲費用，而忍者生物的 {% mtglink "Karai, Future of the Foot" %} 如果是以奇襲費用施放，她後續造成戰鬥傷害後觸發的效果會增強。而另一張 {% mtglink "Koya, Death from Above" %} 進場就能放逐一張生物，更讓你在回合結束時，選擇要不要支付 {三}{<span style="color:#808080">黑</span>} 來將該生物永久放逐。你可以單純將其視為一發 {% mtglink "Turn to Mist" %} ，或合計支付7費將威脅徹底鏟除！

> 像 {% mtglink "Koya, Death from Above" %} 這樣，TMT各單色生物中都有一張在規則敘述中有使用到另一個顏色的起動式、或觸發式異能，他們也是作為U卡的指標牌來為限制賽服務。

至於最左邊的兩張牌， {% mtglink "Leonardo, Cutting Edge" %} 作為一張R卡的 {% mtglink "Ajani's Pridemate" "war" alt="阿耶尼的群伴" %} 一定是要更厲害一點。除了自帶繫命外，如果你讓他奇襲登場、且抄起埋伏在場上的專武 {% mtglink "Quintessential Katana" %} ，戰鬥傷害結算後你就會收穫一隻4/4、且可阻擋的繫命巨龜！

![](https://i.meee.com.tw/56pBWhU.jpg)

不過，要想打好忍者主題，首先你需要有足夠的一二費曲線，最好是有一些穿透能力。如上面這五張白黑色組的一費曲線，除了 {% mtglink "Leonardo, Leader in Blue" %} 可能更偏後期（但它也有一個 {一}{<span style="color:#C3B270">白</span>} 獲得先攻的起動式異能）外，其他4張都很適合做為你的忍者起動點。

![](https://i.meee.com.tw/SIMiwpy.jpg)

而當你進入第二回合進攻且未被阻擋，那你就有機會施放手上這五張奇襲費用僅需二費或更少的牌，其中又以 {% mtglink "Dark Leo & Shredder" %} 以及 {% mtglink "Splinter, Hamato Yoshi" %} 兩張牌的破壞力最高。前者可以鋪開忍者大軍，後者則是忍者領主，且奇襲費用只要一點 {<span style="color:#808080">黑</span>} ，也就是說你有機會在戰階後將回手的一費生物再拍下來。此外，最右邊的 {% mtglink "The Last Ronin's Technique" %} 若能二回登場將是爆炸性的展開，也很適合在紅白聯手主題中使用，殺對手個猝不及防。

### <span style="color:#006DB3">藍</span><span style="color:#AF2321">紅</span>機械 — （Machines）

![](https://i.meee.com.tw/DJigIFM.jpg)

兩張藍紅雙色牌都與神器相關，因此我們知道TMT的藍紅色組是關注於神器主題。 {% mtglink "Baxter Stockman" %} 可以讓你一隻神器生物化身為難以阻擋的大殺器；而 {% mtglink "Brilliance Unleashed" %} 除了作為一張笨重的生物去除外，是否值得使用，還是要看第二個選項能不能發揮，如果墳場有神器就很值得用，如果回場的是非生物神器，變成3/3飛兵說不定更厲害！另一張 {% mtglink "Metalhead" %} 進場就能將一張神器或生物回手，如果有多餘的神器可以犧牲，就能支付一點 {<span style="color:#AF2321">紅</span>} 起動，讓他一進場就變成至少5/5的敏捷生物！

最左邊的兩張藍色牌， {% mtglink "Donatello, Gadget Master" %} 若能對對手造成戰鬥傷害，不論是複製一個 {% mtglink "Bespoke Bō" %} 、或 {% mtglink "Metalhead" %} ，瞬間就能拉開節奏優勢！

![](https://i.meee.com.tw/84K8zUO.jpg)

C卡的 {% mtglink "Donatello, Turtle Techie" %} 只要進場時你場上有神器就能立刻補回牌差，而MR的 {% mtglink "Donatello, Mutant Mechanic" %} 也需要場上有神器的支援，就能簡單暴力的造出神器大軍，並持續維持體格優勢！然而，這兩張牌都無法獨立運作，需依賴其他神器的支援才能發揮完整價值。

![](https://i.meee.com.tw/YhV5GFX.jpg)

U卡的 {% mtglink "Donatello, Way with Machines" %} 單體不強，但只要搭配像 {% mtglink "Mouser Foundry" %} 、或 {% mtglink "Mechanized Ninja Cavalry" %} 這類神器進場一帶二的牌，就能一口氣讓Donatello變成3/4或更大的飛兵！此外，像 {% mtglink "The Ooze" %} 這樣的牌，只要在場上就能持續移墳並派出突變劑衍生物，也很適合與之互動。

![](https://i.meee.com.tw/BBh4m0w.jpg)

終究還是來了！辣個令人聞風喪膽的機制 — 神器共鳴（Affinity for Artifacts）！只要你持續地派出神器， {% mtglink "Krang, Master Mind" %} 就能以最低兩點藍施放，除了本身自帶 {% mtglink "Cranial Plating" "tsr" alt="顱骨護甲" %} 般的效果外，一進場還能幫你一口氣補足4張手牌。而 {% mtglink "Improvised Arsenal" %} 作為紅色版的顱骨護甲，中後期費用夠多還能派出自己的複製品。而另一張 {% mtglink "Ravenous Robots" %} 更是強橫，每次施放神器都會多帶一隻1/1機器人token。最右邊的 {% mtglink "Purple Dragon Punks" %} 定位上較像是輔助，別忘記這系列有這張神器mana頭，起動式異能如佩帶（Equip）都能靠他來產費。至於 {% mtglink "Don & Raph, Hard Science" %} 只要一攻擊，就可以讓你下一發非生物咒語有神器共鳴，這對於施放高費咒語如 {% mtglink "Turtles in Time" %} 很有幫助。但我猜大多是免費吃一個[披薩](https://scryfall.com/search?as=grid&order=name&q=Pizza+color%3C%3DC+%28game%3Apaper%29+set%3Atmt+prefer%3Abest)，大家怎麼看？

不過，別忘了有一張牌可以直接把藍紅神器主題打爆，如果知道對手有的話，記得帶張 {% mtglink "Negate" "tmt" %} 以保平安。

### <span style="color:#808080">黑</span><span style="color:#4A8A3D">綠</span>消失 — （Disappear）

![](https://i.meee.com.tw/jeOalk7.jpg)

[消失機制牌有9張](https://scryfall.com/search?q=oracle%3ADisappear+(game%3Apaper)+set%3Atmt+prefer%3Abest&unique=cards&as=grid&order=name)，主要都分布在黑綠色組；除了一張藍黑混血生物 {% mtglink "Krang & Shredder" %} 。而 {% mtglink "Pizza Face, Gastromancer" %} 、或 {% mtglink "Lord Dregg, Insect Invader" %} 這類機制回報單卡則鼓勵你往這個方向發展。黑色武具 {% mtglink "Shredder's Armor" %} 本身就是個穩定觸發消失的引擎，MR的 {% mtglink "Super Shredder" %} 則可透過每次消失的觸發而持續變強。別忘了，前面白黑色組提過的奇襲機制、以及能犧牲找地進場的 {% mtglink "Escape Tunnel" %} 也能觸發消失！

![](https://i.meee.com.tw/Setq5Sy.jpg)

> 小搭配，如果你同時操控 {% mtglink "Super Shredder" %} 跟 {% mtglink "Michelangelo, Weirdness to 11" %} ，你每犧牲一個突變劑token，就可以在Super Shredder身上放至多4個+1/+1指示物！嗯……所以他們兩位很談得來嗎？
> 1. 犧牲突變劑本身放的+1/+1指示物加倍（可放給其他生物）
> 2. Super Shredder因永久物離場觸發，所放的+1/+1指示物加倍

![](https://i.meee.com.tw/AstHy0q.jpg)

此外，黑綠色組還有食品（Food）的副主題，以 {% mtglink "Courier of Comestibles" %} 為核心的披薩歡樂送系列。今晚想來點什麼口味呢？是傷敵一千自損七百五的 {% mtglink "Spicy Oatmeal Pizza" alt="火辣燕麥披薩" %} ，還是劇毒可口的 {% mtglink "Anchovy & Banana Pizza" alt="鯷魚香蕉披薩" %} ？香甜滑順的 {% mtglink "Guac & Marshmallow Pizza" alt="酪梨棉花糖披薩" %} 看起來不錯、但經典不敗的 {% mtglink "Omni-Cheese Pizza" alt="乳酪滿溢披薩" %} 還是令人難以割捨……不如就點應有盡有的 {% mtglink "Everything Pizza" alt="全家福披薩" %} 吧！只要美食運手能及時送達，熱騰騰的披薩總是令人垂涎三尺！~~寫得我都餓了XD~~

>  {% mtglink "Courier of Comestibles" alt="美食運手" %} 的牌張設計也非常的棒！如果你牌庫裡找得出一張需要的食品牌，恭喜你，外送準時送達，你獲得了一份熱騰騰的披薩！即使你找不到，你仍會獲得一個冷掉的披薩（一個「普通」的食品token，還是蠻好吃的），但你請他送餐所支付的 {一}{<span style="color:#4A8A3D">綠</span>} 可是不能退的。只要讀讀那段風味文字，你就能感受到用一張牌說一個小故事的獨特魅力！

### <span style="color:#AF2321">紅</span><span style="color:#C3B270">白</span>聯手 — （Alliance）

![](https://i.meee.com.tw/B6ZEOY0.jpg)

[聯手機制牌有10張](https://scryfall.com/search?q=oracle%3AAlliance+(game%3Apaper)+set%3Atmt+prefer%3Abest&unique=cards&as=grid&order=name)，皆分布在紅白色組。 {% mtglink "The Neutrinos" %} 本身具有聯手可以加攻擊力的基本加成，而他攻擊時可以讓另一個你操控的生物重新進場且正在攻擊，可以額外賺一次聯手且不錯過當回合的進攻； {% mtglink "Go Ninja Go" %} 除了觸發一次聯手的效果外，還可以作為一張去除。至於 {% mtglink "Old Hob, Alleycat Blues" %} 光站著不動，每次戰階就可以派出一隻生物觸發聯手，異能也能支付 {一}{<span style="color:#C3B270">白</span>} 來讓目標攻擊生物獲得不滅。 {% mtglink "Raphael, Most Attitude" %} 本身聯手的效果可以放逐牌庫頂牌，並在他攻擊時可以使用其中一張，若裝備上 {% mtglink "Hard-Won Jitte" %} 則讓攻擊更具侵略性。

> 不選R卡的 {% mtglink "Raphael, the Nightwatcher" %} 的原因是：兩個連擊異能也不會讓你打出第三下。 

![](https://i.meee.com.tw/2D5PPTl.jpg)

 {% mtglink "Sally Pride, Lioness Leader" %} 是紅白色組的大炸彈，進場可以派出眾多的2/2突變體token觸發聯手，進攻時又能全體放豆灌大！其他像是 {% mtglink "Mechanized Ninja Cavalry" %} 、或是 {% mtglink "Mighty Mutanimals" %} 都是一帶二、進場能觸發兩次聯手異能的好牌。另外像是 {% mtglink "Wingnut, Bat on the Belfry" %} 只要有觸發聯手就能獲得多項關鍵字異能，一攻擊的全體加攻效果相當強力！至於 {% mtglink "Raphael, Tough Turtle" %} 則是生物版的 {% mtglink "Impact Tremors" "fdn" alt="衝擊震顫" %} ，搭配聯手可以打出額外的傷害。

### <span style="color:#006DB3">藍</span><span style="color:#4A8A3D">綠</span>突變劑 — （Mutagen）

![](https://i.meee.com.tw/o9aPVbR.png)

[突變劑機制牌有12張](https://scryfall.com/search?q=oracle%3AMutagen+(game%3Apaper)+set%3Atmt+prefer%3Abest&unique=cards&as=grid&order=name)，主要分佈在藍綠色組，有11張；另有1張傳奇神器牌 {% mtglink "The Ooze" %} 。雖然在藍綠色組中已有許多牌都能讓你額外派出突變劑token，但只要 {% mtglink "Genghis Frog" %} 在場，你之後登場的其他突變體與蛙生物都能持續派出突變劑token。而 {% mtglink "Ray Fillet, Man Ray" %} 可以讓你拔掉+1/+1指示物來抽牌， {% mtglink "Venus, Torn Between Worlds" %} 只要造成傷害，就能放等量的+1/+1指示物在她身上；而每有一個身上有指示物的生物對玩家造成戰鬥傷害，還可以支付 {<span style="color:#006DB3">藍</span>} 來抽牌！限制賽中應該跟 {% mtglink "Enduring Curiosity" alt="藍貓" %} 差不多猛了。 
  
基於綠色的體格優勢，裝備了 {% mtglink "Novel Nunchaku" %} 的生物可以輕鬆互鬥掉對手較小的生物，而 {% mtglink "Michelangelo, Mutant BFF" %} 則能讓你身上有指示物的生物難以被阻擋，每次進攻還能持續派出突變劑！藍綠色組就是要不斷地將這些指示物換成體格、手牌、以及你的勝利！

![](https://i.meee.com.tw/03US2ox.jpg)

另外，也別忘了拿下一些能派出突變劑token的非生物咒語吧！有需要時他們會是你可靠的幫手。

### 盤點一下TMT主要的生物類別吧！

[生物總共有117張](https://scryfall.com/search?q=%28type%3Acreature%29+%28game%3Apaper%29+set%3Atmt+prefer%3Abest&unique=cards&as=grid&order=name)，佔總牌張數190張的61.6%左右。

- [忍者（Ninja）：42張](https://scryfall.com/search?as=grid&order=name&q=(type%3Acreature+type%3Aninja)+(game%3Apaper)+set%3Atmt+prefer%3Abest)，五色都有。
- [龜（Turtle）：29張](https://scryfall.com/search?q=%28type%3Acreature+type%3Aturtle%29+%28game%3Apaper%29+set%3Atmt+prefer%3Abest&unique=cards&as=grid&order=name)，五色都有。附帶一提，不具有忍者類別的龜僅有3張，分別是 {% mtglink "Metalhead" %} 、 {% mtglink "Slash, Reptile Rampager" %} 、 {% mtglink "Tokka & Rahzar, Terrible Twos" %} 。
- [突變體（Mutant）：61張](https://scryfall.com/search?q=%28type%3Acreature+type%3Amutant%29+%28game%3Apaper%29+set%3Atmt+prefer%3Abest&unique=cards&as=grid&order=name)，五色都有。而如果僅計入[非忍者、非龜的突變體（Mutant）的生物的話則有28張](https://scryfall.com/search?as=grid&order=name&q=%28-type%3Aninja+-type%3Aturtle%29+%28type%3Acreature+type%3Amutant%29+%28game%3Apaper%29+set%3Atmt+prefer%3Abest)。
- [非突變體的其他生物：56張](https://scryfall.com/search?q=-%28type%3Amutant%29%28type%3Acreature%29+%28game%3Apaper%29+set%3Atmt+prefer%3Abest&unique=cards&as=grid&order=name)，五色皆有。但忍者龜裡「[一般人](https://scryfall.com/search?q=-type%3Aninja+-type%3Amutant+%28type%3Acreature+type%3Ahuman%29+%28game%3Apaper%29+set%3Atmt+prefer%3Abest&unique=cards&as=grid&order=name)」還真是少數族群，僅有12張，差不多比10%多一點的人口比率。

![](https://i.meee.com.tw/E8X1I4t.jpg)

至於為什麼要這樣去區分呢？上圖額外揭露一個小主題，在TMT中，有四張牌可以跟可以跟忍者、龜、和/或突變體這三個生物類別產生互動；雖然地牌 {% mtglink "Turtle Lair" %} 因為風味需要，排除了與突變體類別的互動，但大方向上，我們在限制賽中（尤其是沾綠的色組），可以稍微留意一下這幾張牌。至於其他的，就讓我們上市後盡情探索吧！

## 結語：你印象中的忍者龜是什麼模樣？

也許把這次UB，想像成忍者龜們穿越到神河時空也不錯。或者說，之前神河的一些設計，要說沒有借鑑或致敬忍者龜的元素，那也是說不過去的。顯而易見的如 {% mtglink "Silver-Fur Master" %} 與 {% mtglink "Splinter, Hamato Yoshi" %} 、  {% mtglink "Kappa Tech-Wrecker" %} 與忍者龜們；隱晦一點的，忍者龜中的[四風化身](https://scryfall.com/search?as=grid&order=name&q=wind+avatar+(game%3Apaper)+set%3Atmt+prefer%3Abest)也與神河的[五方木靈](https://scryfall.com/search?q=Tree+Kodama&unique=cards&as=grid&order=name)互為對照。

說說我與忍者龜的童年回憶。在那個《最終幻想》仍被翻成「太空戰士」，哆啦A夢還是叫「機器貓小叮噹」的年代裡，四名忍者龜也有著非常奇葩的台式譯名：紅豆冰（[Raphael](https://scryfall.com/search?as=grid&order=name&q=Raphael%2C+type%3Acreature+%28game%3Apaper%29+set%3Atmt+prefer%3Abest)）、藍天使（[Leonardo](https://scryfall.com/search?q=Leonardo%2C+type%3Acreature+%28game%3Apaper%29+set%3Atmt+prefer%3Abest&unique=cards&as=grid&order=name)）、紫葡萄（[Donatello](https://scryfall.com/search?q=Donatello%2C+type%3Acreature+%28game%3Apaper%29+set%3Atmt+prefer%3Abest&unique=cards&as=grid&order=name)）、與柳丁花（[Michelangelo](https://scryfall.com/search?q=Michelangelo%2C+type%3Acreature+%28game%3Apaper%29+set%3Atmt+prefer%3Abest&unique=cards&as=grid&order=name)）。長大後才知道，他們的名字源自文藝復興大師，甚至連Raphael的武器是「十手」而不是三叉戟這件事，也是直到TMT消息公布後才更新了我的認知。我對忍者龜的印象也從小時候的「好帥！」，過渡到「不怎麼帥……」與「好像又有點帥？」之間反覆震盪。雖然我並非資深擁護者，但我知道一定也有一群人還是覺得忍者龜超帥，且深深喜愛著這個IP。

身為玩家，我們只需持續支持自己認同的價值，盡力滿足自己的體驗就足夠了。那麼，讓我們TMT限制賽再見吧！
