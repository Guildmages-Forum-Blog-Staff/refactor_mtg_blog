## 套牌列表與單卡詳解

在你理解了什麼是風暴機制之後，讓我們來看看套牌列表吧！
> [MTG Goldfish 牌表連結](https://www.mtggoldfish.com/deck/7878267#paper)

![](https://images.guildmagesforum.tw/posts/Modern-Ruby-Storm/7c4d81c53105.webp)

風暴是由四大元素所組成的：**減費組件**、**法力源**、**賺牌**，與**中繼＆終結點**。
我們的獲勝方式就是拍出減費組件後，交替使用法力源與賺牌組件來疊加風暴數，最後拍出一發大發的 {% mtglink "Grapeshot" %} 或是 {% mtglink "Stormscale Scion" %} 來贏得遊戲。

這是一套單一計劃、對多數套牌有首局優勢、且爆發力極高的套牌，非常有操作感且好玩～讓我們來一一解析這四大組件分別有些牌，並且熟悉這些牌各自有什麼需要注意的重點吧！

### 1. 減費組件

這是整副套牌能動起來的關鍵。除非你很確定丟出來對手沒辦法解掉他，或是你手上有複數張，不然儘量不要在第二回合直接丟出來。如果被對手解掉，你的套牌會直接當機喔！

{% mtgcard "Ruby Medallion" %}
這副套牌就是以他為名，能讓所有紅色咒語都減一費施放。是的～是所有的紅色咒語。所以包含 {% mtglink "Ral, Monsoon Mage//Ral, Leyline Prodigy" %}、{% mtglink "Artist's Talent" %} 甚至是備牌的 {% mtglink "Stormscale Scion" %} 都能享有減免效果，身為神器的特性讓他在正編局比較不容易被對手解掉。

{% mtgcard "Ral, Monsoon Mage//Ral, Leyline Prodigy" %}
相較於 {% mtglink "Ruby Medallion" %}，他只能讓瞬間與巫術咒語減少一費施放，而且作為生物的原罪就是很容易吃殺死去。甚至在對手 tap-out 的時候，都可能被憑空出現的 {% mtglink "Solitude" %} 給送去異次元。還有運氣很差的時候翻硬幣永遠翻輸，然後就把自己痛死……

但這可不代表 {% mtglink "Ral, Monsoon Mage//Ral, Leyline Prodigy" alt="拉爾" %} 比較差。只要你能成功施放 6 個以上的瞬間巫術並且贏得擲硬幣，它翻到背面後就能直接開大絕。替你帶來大量免費的牌張，這也幾乎是宣告你的勝利。

而這張牌也是這整套牌中細節最多，也最影響你勝率的一張。如果你要打這套，以下這些你一定要熟記於心！

1. **拉爾翻面計算方式**：拉爾翻面時是看在這之前「施放」（而非「結算」）過幾個瞬間巫術來獲得額外的忠誠。所以在法力允許的情況，我們會在要到達魔術數字 6 之前，維持優先權，然後儘量疊加瞬間到堆疊上，如此可以大幅增加拉爾的翻面機率。

> **看不懂上面這段在講啥？我舉個例子你就會快速了解了！**
>
> 假設本回合你已經施放了三個巫術瞬間，這時候你手上只剩下三張 {% mtglink "Desperate Ritual" %}，只要拉爾翻過去你就贏了。你會怎麼做？
> 如果你傻傻地一發一發施放並結算，那第四與第五發擲硬幣基本上就是完全 WASTED 掉的。因為你如果擲贏了也不能選擇翻面（翻過去拉爾沒法直接開大）。你只能賭第六發的 50% 機率，非常非常的不穩～
> **正確的做法是**：你施放第四發並且拉爾丟硬幣的觸發上堆疊時，保持你的優先權，把第五跟第六發也依次施放並放上堆疊。這時候三個擲硬幣的觸發他們看到的都是「你已經施放 6 個巫術瞬間」，所以三次擲硬幣只要任何一次擲贏，你都能選擇翻面。這讓你獲勝的機率暴增為 **87.5%**！這將近四成的機率差可以說是天與地的差異，而且這個技巧用到的機率非常高，所以務必要熟記於心！！
 
2. **躲殺牌的技巧**：如果對手在你的回合放招要殺拉爾，你可以回應施放瞬間來觸發擲硬幣，擲贏了就能讓拉爾翻面來躲過殺牌。所以如果你懷疑對手手上有殺，咒語的施放順序與保留就會變得很重要。在法力允許的情況下，你會想要盡可能地去保留拯救拉爾的機會。
參考示範影片：[Mengucci 預判對手有 Solitude 而調整了他的出牌順序](https://youtu.be/A9j9CtkdeEE?t=1140)
*不過要注意拉爾的擲硬幣只會在自己的回合觸發，在對手的回合是沒用的。所以不要傻傻的在對手回合丟招想來救人。這是很多人常常忽略的地方。*

3. **獨立計算**：拉爾計算的是你本回合使用的瞬間巫術數量，不是風暴數（風暴會算入非瞬間巫術，對手做的事情也會算入）。所以不要混用！兩個要分開算，不然你翻過去才發現沒法開大就尷尬了。

<p style="text-align: center;"><a class="small">（選用）</a></p>

### 2. 法力源

![Rituals](https://images.guildmagesforum.tw/posts/Modern-Ruby-Storm/9c26e4f9a522.webp)
在有減費組件在場的狀況下，就是一張牌額外提供 2 點法力。其中 {% mtglink "Desperate Ritual" %} 具有通聯古咒（Splice onto Arcane）。而套牌中除了 {% mtglink "Desperate Ritual" %} 自己之外，{% mtglink "Hex Magic" %} 也是古咒。在允許的狀況記得做，可以獲得額外的法力。

{% mtgcard "Manamorphose" %}
在有減費組件在場的狀況下，額外提供 1 點法力並抽一張牌。同時也具有替備牌調色的功能。

{% mtgcard "Strike It Rich" %}
<p style="text-align: center;"><a class="small">（選用）</a></p>
不會讓你賺到任何法力，但因為這套套牌第一回合基本上沒事做，所以有些人會投入 1～2 張，讓你有機會提早一回合擊殺對手。但不是在第一回合抽到的話，大概只有洗風暴數的功能。所以不是人人都會投入，同時也是換備牌時優先會換掉的東西。

### 3. 賺牌與濾牌

![Exile_2](https://images.guildmagesforum.tw/posts/Modern-Ruby-Storm/b3c3ecdb0476.webp)
可以賺一張牌，也是提供火力給你演牌的啟動點。很適合在第二回合時丟一發，來 set 第三回合的爆發。也有人用 {% mtglink "Opera Love Song" %} ，但這就看個人的喜好了。

{% mtgcard "Hex Magic" %}
[MSH](https://scryfall.com/sets/msh)系列帶來的新玩具，現在幾乎是接管了下面幾張的飯碗。能在前期提供 4～5 張牌的優勢。做出來幾乎是勝利的保證。但到了開始連招的階段就會隨著手牌數減少而越變越爛。是把套牌削得更尖更極端的一張牌。

{% mtgcard "Glimpse the Impossible" %}

### 4. 中繼 & 終結點

{% mtgcard "Past in Flames" %}
讓你墳場的瞬間巫術全部獲得返照（Flashback），是這套牌的中繼點。使用上很簡單直觀，但要學習的技巧是怎樣逼出對手的剋墳牌！

> **舉個例子：**
> 例如對手場上有 {% mtglink "Tormod's Crypt" %} 或是你知道對手手上有 {% mtglink "Endurance" %}，這時該怎麼辦？
> 先決條件是，你墳場要先有個幾張法力源與賺牌，然後手上也要有個幾張。
> 首先施放 {% mtglink "Past in Flames" %}，對手通常會回應用掉他的 {% mtglink "Tormod's Crypt" %} 或 {% mtglink "Endurance" %}（當然如果對手不做事，你就開心的用你墳場的那幾張牌）。先讓對手的清墳結算完，然後在 {% mtglink "Past in Flames" %} 還在堆疊上時，回應施放手上的瞬間法力源。這樣這些牌就會獲得返照，讓你可以獲得大量的法力用來爆發。
> 如此可以在受到最小傷害的情況下逼掉對手的清墳。是一個很實用的技巧。

{% mtgcard "Wish" %}
可以找中繼也可以找勝利的重要卡片，甚至有些時候還能拿來找備牌的解。特別要注意它的效果是 **本回合可以使用一張備牌**，而非強制你要在結算當下就用喔！而且你也不需要宣布你要用哪張，等你需要的時候再去備牌拿你要的牌來用就好。至於何時該許願？又該許什麼願呢？
- 通常第一發都是找 {% mtglink "Past in Flames" %} 中繼。這裡要記得算好法力，在有一個減費組件的情況下，你會需要 `2 + 3 + 1 = 6` 點法力（{% mtglink "Wish" %} + {% mtglink "Past in Flames" %} + 發動墳場的法力源）才能繼續演下去。不要為了貪多發一兩發賺牌咒語，結果反而法力不夠斷掉自己的連招。
- 如果風暴數累積得很順利，當然是直接許願 {% mtglink "Grapeshot" %} 殺人。而且你其實不需要真的把風暴數搞到 20 來殺人。如果法力充足（7 點以上），在對方血量 20 點的情況下，你只需要達到風暴數 6，接下來就能 {% mtglink "Wish" %} + {% mtglink "Grapeshot" %} （風暴數 8 + 本體 = <font color="#FF0000">9 點傷害</font>） + {% mtglink "Past in Flames" %} + {% mtglink "Grapeshot" %} （風暴數 10 + 本體 = <font color="#FF0000">11 點傷害</font>），剛好打滿 <font color="#FF0000">20 點傷害</font>。如果對手的血量因為地牌只有 18 點的話，則只需風暴數 5 就能打掉。所以其實只要牌張是對的，要打死人需要的風暴數沒有想像中的高。但很多時候這條 Line 很容易被忽略。
- 當然在你沒有辦法走這條 Line（例如被下了 {% mtglink "Rest in Peace" %}），且風暴數沒辦法一路累積到斬殺的時候，另外兩個選擇就出現了：{% mtglink "Stormscale Scion" %} v.s. {% mtglink "Empty the Warrens" %}
- 如果法力允許，請務必以 {% mtglink "Stormscale Scion" %} 為第一優先，因為穿透力強，且龍又超大隻。{% mtglink "Empty the Warrens" %} 是真的法力不夠且又要斷招的時候才做的不得已選擇。

> 你說生個十幾二十隻鬼怪也很猛啊？那你不妨看看 Mengucci 的悲慘教訓吧！
> [Mengucci 教訓影片](https://youtu.be/A9j9CtkdeEE?t=1866)

{% mtgcard "Grapeshot" %}
除了偶爾可以拿來解場續命之外，多數時候都是當最後一擊用。平常抽上手就是卡在手上。所以有些套牌會把這張從正編轉到備牌，改成多放一張靈活性更好的 {% mtglink "Wish" %}。但如果對手備牌是有放 {% mtglink "Surgical Extraction" %} 的話，記得要在備牌局把一張 {% mtglink "Grapeshot" %} 放回正編，不然 {% mtglink "Wish" %} 被切掉的話你就直接贏不了了。
> 另外也要注意風暴本身是個觸發式異能，是可以被 {% mtglink "Consign to Memory" %} 給康掉的，被康就會只剩原本那一發喔！

## 套牌操作與決策重點

### 什麼時候該開演（Go-off）？

這大概是剛開始玩這套套牌的人會有的最大疑問。理論上手牌越多或是法力越充足，你演到底的成功率就會越高。但對手不是木樁，不會站在那裡乖乖等你演，理論上越早開演，你被打斷的機會就越少，所以學會何時開演就是很重要的課題。

首先，在完全無干擾的狀況下，Ruby Storm 的黃金開演時間通常都是 **第三回合** 。在有三張地的情況下，兩點下減費組件，一點施放法力源，然後開始交錯施放法力源跟賺/濾牌的牌來取得勝利。而這個黃金第三回合，你知、我知、獨眼龍也知，因此在這個會遭受到最多的干擾與壓力的時候，你就要問你自己以下幾個問題：
- 我的對手是什麼類型的套牌？
- 我如果現在不開演，我下一回合會不會死？
- 此時我如果開演可能會受到什麼干擾？

依對手類型採取不同策略：
- **中速型套牌**（如：伊捷共鳴、Blink、約格莫夫……等等）：干擾相對少，或是偏向巫術時機，且你能從場上的狀況很清楚地掌握你什麼時候可能會死。這時候你可以稍微有點耐心，利用賺牌咒語來累積法力與火力，確保你開演的時候能抵抗一次的干擾來獲得勝利。
- **控制類型**（如：白藍控、藍黑青蛙）：干擾很多（康、掉牌）偏控制類型的，這個你拖越久越不利。正編局該儘快取勝。備牌局會非常依賴 {% mtglink "Orim's Chant" %} 的保護。
- **競速類型**（如：Prowess、泰坦護身符、Neoform……這類）：干擾很少，但是跟你比看誰比較快殺死對手的類型。如果你感覺到危險，你甚至可能要拼更極限的二回殺。

> **經典實例分享：**
> 一個經典的例子就是在我取得 MIT 資格的決定最終戰（Win & In），當時我跟打 Prowess 的對手 1：1 平手，第三盤我後手的狀態。對手一回 {% mtglink "Monastery Swiftspear" %}，然後第二回合設謀（Plot） {% mtglink "Slickshot Show-Off" %}。這時我心中警報大響！因為對手在第二盤上了很多干擾的備牌，打得偏被動並一直處於保有法力狀態。但這時候居然直接 tap-out 來設謀了 Prowess 最有爆發力的 {% mtglink "Slickshot Show-Off" %}。
> 我頓時覺得我如果這回合不贏，我可能就沒有下一回合，或是即使有下一回合，我的血量也有可能低到會被自己的 {% mtglink "Ral, Monsoon Mage//Ral, Leyline Prodigy" alt="拉爾" %} 給痛死。看著只要進牌一不好就會斷，但是有機會一拼的手牌。我就牙一咬、冒著失敗的風險就衝了！最後運氣很好，在極限的操作下完成擊殺。而對手也無奈的 show 出手上那個可以下一回合直接幹掉我的 17 點傷害。
> 如果我沒有問自己我下一回合會不會死，而是採取了比較穩固的第三回合路線的話，今天的結果就會完全不一樣了。

所以熟悉對手套牌的類型、知道對手可能有什麼干擾、被干擾的話你是否會直接卡住、以及最重要的現在如果不做，下一回合會不會死？這些就是你在練習這副套牌時的重點。組合技操作本身你對著牆壁都可以練習，但是與真人對練的時候，如果要檢討與學習，那請務必著重在這幾點上面。

### 換備思路

我個人很不喜歡抄個 Sideboard guide 然後就無腦跟著換。對我來說去理解每張備牌的存在意義與適合上場時機，才能讓你在碰到意料之外的對局或是牌的時候不會慌亂無措。

尤其風暴這套套牌很特別，其他套牌的備牌通常都是干擾別人用的haters。但只有風暴是完全不想干擾別人，備牌的存在完全是為了避免別人干擾我們。

所以要講解換備，就要先了解風暴這套套牌害怕的是什麼？
1. **咒語次數限制與放逐區限制牌**：
   頭號敵人！如 {% mtglink "High Noon" %}、{% mtglink "Deafening Silence" %}、{% mtglink "Damping Sphere" %}、{% mtglink "Mai, Scornful Striker" %}、{% mtglink "Soulless Jailer" %}、{% mtglink "Drannith Magistrate" %}、{% mtglink "Trinisphere" %} 等等。只要被定下這些基本上就是整套都動不了。
2. **清墳**：
   會拖慢一些套牌的速度，但不會很致命，即使不用到備牌也有方法可以應對。
3. **康與禁言**：
   {% mtglink "Force of Negation" %} 與 {% mtglink "Orim's Chant" %} 等等，啟動點被康掉或是招做到一半被斷都很容易會多卡住好幾回合。

理解這些天敵之後，再來看看備牌列表就很好理解該怎麼上備牌了～

![](https://images.guildmagesforum.tw/posts/Modern-Ruby-Storm/153d96fd513e.webp)
對手只要定了我們的頭號敵人，我們就幾乎完全沒有贏的可能，所以這些掃除haters的牌就是你的救星。只要對手會出現那些牌，你就得依照對手會上的種類，上個四張以上來應對。

{% mtgcard "Orim's Chant" %}
防康、防禁言、防瞬間清墳。偶爾還可以增幅來救自己一命。

如果你要打的是沒開牌表的比賽，我會建議你賽前把前十套熱門套牌裡面，對手會用的備牌有什麼是克制你的，記錄在你的 sideboard 用紙上。這樣換備的時候就可以知道你該上哪些東西來應對。

### 對局剖析

- **Esper Goryo’s**：不太好打
    *   *正編局*：會被對手 {% mtglink "Thoughtseize" %} 掉關鍵牌，{% mtglink "Ruby Medallion" %} 可能會被 {% mtglink "Force of Negation" %}，然後 {% mtglink "Ral, Monsoon Mage//Ral, Leyline Prodigy" alt="拉爾" %} 可能會死於 {% mtglink "Solitude" %} 或 {% mtglink "Fatal Push" %}。但頭過身就過，你的減費組件如果沒有被搞掉，你開演後對手也只能雙手一攤等你演完。
    *   *備牌局*：對手基本上除了一點點清墳，基本上還是圍繞在各種康來干擾你。上 {% mtglink "Orim's Chant" %} 來確保你可以安心演出吧！

- **Esper Blink**：還算好打
    *   *正編局*：對手大概只能殺 {% mtglink "Ral, Monsoon Mage//Ral, Leyline Prodigy" alt="拉爾" %} ，跟你的互動不會太多，而且這套偏慢，你血量壓力通常不大。所以不要抽太爛且稍微小心一點，大概不太會有什麼問題。
    *   *備牌局*：因為對面會有 {% mtglink "High Noon" %}，所以記得上清除咒語。另外對手的康也會變多，可以上一些 {% mtglink "Orim's Chant" %}。

- **Izzet Prowess**：很難打
    *   *正編局*：對手超快，你的血量壓力會超大。尤其當對手知道你是風暴，會毫不留情的 all-in 他的招。不過對手基本上對你也是 0 干擾，所以你也可以放心 all-in。這就會變成是很純的競速，祈禱丟贏骰子吧～
    *   *備牌局*：對手會上比較多康牌，所以會慢一些些。但你也因此得帶 {% mtglink "Orim's Chant" %}，所以你也會變慢。總之重點就是我前面講的，感知危險，盡快取勝！

- **Mono-Green Broodscale (俗稱蜥蜴刀)**：好打
    *   *正編局*：對手只有 {% mtglink "Vexing Bauble" %} 可能會卡到 {% mtglink "Ral, Monsoon Mage//Ral, Leyline Prodigy" alt="拉爾" %} 的大招。其他基本上對你束手無策。在對手做出無限前打死他就好。
    *   *備牌局*：對手會有 {% mtglink "Damping Sphere" %} 或 {% mtglink "Soulless Jailer" %} 這類干擾。帶上你的拆神器牌吧。拆掉這些一樣是隨你演。

- **Affinity**：好打
    *   *正編局*：對手只有 {% mtglink "Tormod's Crypt" %} 跟少量的 {% mtglink "Metallic Rebuke" %} 來拖慢你，所以不要被一二回 {% mtglink "Kappa Cannoneer" %} 灌死，你都能游刃有餘的開心演出。真的被做了也還有機會在死前做出組合獲勝。
    *   *備牌局*：一樣會碰到 {% mtglink "Damping Sphere" %} 跟少量的康。帶上你的拆神器大隊，{% mtglink "Orim's Chant" %} 我覺得可帶可不帶。

- **Boros Energy**：還算好打
    *   *正編局*：大概只怕 {% mtglink "Ranger-Captain of Eos" %} 斷你的招，以及 {% mtglink "Ral, Monsoon Mage//Ral, Leyline Prodigy" alt="拉爾" %} 被宰掉。不然對手基本上也無法跟你有什麼互動。
    *   *備牌局*：一樣是會有討人厭的 {% mtglink "High Noon" %}，帶上拆除大隊吧。

- **Eldrazi Tron**：普通對局
    *   *正編局*：通常沒什麼血量壓力，主要是看對手正編上了多少 {% mtglink "Trinisphere" %}。小心不要施放 {% mtglink "Past in Flames" %} 被 {% mtglink "Kozilek's Command" %} 清墳導致卡住就好。
    *   *備牌局*：會有一堆神器干擾，一樣帶上神器拆除大隊。

- **Dimir Frog**：很難打
    *   *正編局*：對面一堆康，會被康到歪頭。只能找例如對面為了下 {% mtglink "Psychic Frog" %} 而 tap-out 的空檔趕快做 combo。或是對手如果不康你的賺牌咒語，看看有沒有機會用資源換贏。
    *   *備牌局*：{% mtglink "Orim's Chant" %} 上滿，然後也是拼時機與資源戰。

- **Eldrazi Trudge**：好打
    *   *正編局*：只要不被二回 {% mtglink "Emrakul, the Promised End" %} 大概都能輕鬆贏。
    *   *備牌局*：跟對到 Mono-Green Broodscale 一樣，都只會有神器干擾。拆除大隊 go~。

- **Boros Ponza**：好打
    *   *正編局*：如果對面正編 {% mtglink "High Noon" %}，且是開卡表局會比較難打，因為對面會積極調度到有。而你正編沒解，就會直接 GG。但最近風暴比較不流行，所以有些正編已經不帶 {% mtglink "High Noon" %} 或是帶很少。那這樣就是輕鬆打。你基本地一堆根本不怕他炸。
    *   *備牌局*：基本上就是只怕 {% mtglink "High Noon" %}。請把拆結界帶滿。

- **Neoform**：很難打
    *   *正編局*：對面干擾不多，但是他們平均速度比我們快。我常常二回就被對面做出來死去。後手通常很難贏…
    *   *備牌局*：{% mtglink "Orim's Chant" %} 上滿來斷他以爭取時間。記得是他要下 {% mtglink "Allosaurus Rider" %} 時就要回應去斷。你等他下 {% mtglink "Neoform" %} 或 {% mtglink "Eldritch Evolution" %} 就來不及了。會直接死去…

- **Devoted Druid Combo**：好打
    *   *正編局*：對手對你毫無干擾，且通常也沒你快。
    *   *備牌局*：對手頂多 {% mtglink "Abrupt Decay" %} 拆你減費組件。如果碰到對手上 {% mtglink "Crystal Barricade" %}，你就改做 {% mtglink "Stormscale Scion" %} 那邊就好。

- **Amulet Titan**：好打
    *   *正編局*：對手對你毫無干擾，而你通常比他們快一回合啟動。
    *   *備牌局*：會有一些神器干擾。帶個四張拆除大隊就夠了。

還有很多套牌無法一一列舉，但我已盡量把熱門套牌都說一遍。看完這些你就大概知道這套套牌強勢對局與弱勢對局的套牌類型了。


## 實體比賽注意事項

風暴這套套牌很特別，因為其特性的關係，在線上操作起來很簡單，但在實體卻有非常多需要特別注意的地方。所以我特別獨立一段來講講實體比賽玩風暴的建議。

實體要玩得好，關鍵重點就是兩個字 **「清楚」** ！

1. **清楚的計數**
   你需要清楚地記錄你現在有多少法力以及現在的風暴數是多少。然後別忘了，拉爾是看巫術瞬間數量，但是風暴是看全部的咒語（含對手），所以你也得分開記，不清楚搞混了會很尷尬。
   平常大家通常都是用骰子來記錄最快速方便，但如果是競爭型比賽，我個人會推薦用紙筆記錄這些數字，因為如果對手有意或無意地去撞一下桌子，結果你骰子滾動完，你不記得到底計數器數字是多少。那這樣弄不好，可能會導致這場比賽的勝負受到影響。

2. **清楚的區域**
   風暴會有一堆牌丟到放逐區，雖然放逐區只有一個，去的牌狀態卻會有許多種。有「到下回合都可施放的」、「本回合必須施放的」、「本回合必須施放，如果沒施放會變成奧札奇後裔的」、「本回合必須施放，但不需支付費用」。
   所以實體玩請務必準備區域標示的紙卡！
   [可以參考 Pierre Liebsch 的精彩對局作法](https://youtu.be/OR6I2TPNtzw?si=40vrT8oYZTx_PJOa)
   另外如果施放了 {% mtglink "Past in Flames" %}，當下哪些牌獲得返照也請標示清楚。用完該放逐就放逐，後續的牌也不要混在一起。

3. **清楚的表示**
   風暴會有很多堆疊利用與操作，所以務必跟對手講清楚你現在堆疊怎麼排、你現在在做什麼……等等。
   例如 {% mtglink "Ral, Monsoon Mage//Ral, Leyline Prodigy" %} 的丟硬幣，實戰上大家很常會用丟骰子來代替。但每一次你要丟的時候都要宣告清楚，骰子出什麼點數代表成功翻面。
   我自己就發生過，平常我每次都是宣告丟出奇數等於成功翻面。有一輪，上一回合我丟的時候有講，但到了下一回合丟之前我忘記講，結果對手就抗議說我沒有先宣告，所以當次不算。如果因此而錯失了關鍵一骰導致輸掉會很可惜也很不爽。所以請務必每次都宣告清楚。

## 結語

風暴也許不是最強、也不是最穩定的套牌。但它的趣味性與操作感絕對是數一數二的！而且因為相對低調又造價不高，對上任何套牌卻都有一戰之力，用這套來突襲賽場也許會收到奇效喔！

如果你也喜歡這類型燒腦的組合技套牌，Ruby Storm 絕對值得一玩！

## MIT#13 實戰選牌與環境調整心得

現在的 Modern 算是相對平衡的狀態，所以備戰時，選擇針對 meta 的套牌就很重要。

翻開 meta 勝率表，當下最高勝率的套牌分別是：**蜥蜴刀**、**紅黑月影**、**泰坦護身符**、**Living End**，以及**藍白封口**。上述這些，除了藍白封口是完全打不贏的天剋套牌之外，其他對局風暴都有一戰之力！尤其對我預測會很多的蜥蜴刀是優開，再加上這套是我練習最多、也操作最熟練的套牌，所以這次就毅然決然的選了風暴上陣！

### 為什麼選擇紅綠版本？

與之前的紅白版本卡表不同，為了針對賽場環境，我特意把套牌調成了**紅綠版本**，主要有以下三個原因：

1. **環境不再適合白色防護**：因為藍白控轉型成為封口型套牌，使得 {% mtglink "Orim's Chant" %} 完全失去了效用，幾乎已經沒有太多對局是適合換上它的。
2. **用更強的單卡應對棄牌與康牌**：因紅黑勝率亮眼，使得賽場原本就已經不少的 {% mtglink "Thoughtseize" %} 數量陡然上升。{% mtglink "Veil of Summer" %} 不只能很好的對抗棄牌咒語，真的碰到康牌也很有用，用它取代 {% mtglink "Orim's Chant" %} 可以說是十分完美。
3. **正編局對抗haters的彈性**：因為是開表打，所以對手如果正編就有如 {% mtglink "High Noon" %} 或是 {% mtglink "Trinisphere" %} 等haters的話，他可能會很積極地去調度。畢竟原本混白色的版本正編局如果直接吃到這些haters的話，那是直接鏟牌投降的。但如果是混綠的版本，就能在正編很自然地加入 {% mtglink "Boseiju, Who Endures" %}，這樣可以在不降低強度的情況下還能有對抗力！（偶爾還可以去拆[克撒的傢俱](https://scryfall.com/search?as=grid&order=name&q=%28type%3Amine+OR+type%3Apower-plant+OR+type%3Atower%29+%28game%3Apaper%29+prefer%3Abest)）

### 備牌小巧思與賽事回顧

最後我在備牌加入了一點自己的小巧思 —— {% mtglink "Defense Grid" %}，這是我想到對付藍白封口的最佳利器了。但很可惜在我成績是 4-1 時的關鍵第六局（贏了就八強），偏偏碰到了最不想碰到的藍白封口。 {% mtglink "Defense Grid" %} 雖然發揮了不錯的效果，但還是逆轉不了那巨大的劣勢，最後以 **5-2** 的成績排名第十作收。

沒有成功進入八強固然可惜，但我很慶幸我當初選擇了這套來玩。因為這套牌是一個有趣的心情綜合體～每次對手打開牌表的時候，第一句話幾乎都是：「靠！怎麼會有人玩這一套？」然後搭配上驚訝的表情。

接著我開始動腦並找尋最佳的開演時機與方法，那種絞盡腦汁的探索過程；最後再加上直接 go-off 開演時，不知道下一張會翻到什麼的刺激感。這些情緒交織在一起後，即使起了個大早打了整天的比賽，我一點也不覺得累，反而還有真正玩了好多場好玩遊戲的滿足感！

經過了MIT#13後，我會更加強烈地推薦你：風暴真的很好玩，而且強度也很不錯，然後還很便宜，甚至可以自己在家裡練牌。
