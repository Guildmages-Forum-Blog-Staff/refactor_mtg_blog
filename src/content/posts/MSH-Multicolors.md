漫威超級英雄（Marvel Super Heroes, MSH）限制賽介紹 — 多色將於2026年6月19日舉行售前賽活動，而於隔一週2026年6月26日正式發行，想更了解在限制賽的單卡評分與建議嗎？那就來看看這一系列的MSH限制賽介紹吧！

- 機制介紹請看這篇：[漫威超級英雄機制解析](https://guildmagesforum.tw/MSH-mechanism/)

## 色組主題
![](https://media.wizards.com/2026/images/daily/b7uhlyEnwc/en_JQpeGc0z0U.jpg)

### <span style="color:#006DB3">藍</span><span style="color:#C3B270">白</span> 聯合協作（Teamwork）

![](https://i.meee.com.tw/G6Le0dV.png)

團隊合作不只讓夢想成真，還能讓你的咒語威力加倍！白藍套牌的核心，就是將帶有『聯合』異能的咒語與可橫置的生物完美結合。 {% mtglink "Captain America, Living Legend" %} 能以堅毅之姿引領你的生物走向勝利。不妨加入 {% mtglink "Borough Backup" %} 與 {% mtglink " S.H.I.E.L.D. Deployment Drone" %} 等能產生token的咒語和生物，來全力支持藍白套牌吧！

### <span style="color:#006DB3">藍</span><span style="color:#808080">黑</span> 抽第二張

![](https://i.meee.com.tw/H4Mjx28.png)

利用這副藍黑套牌來掌控時間與戰局的節奏！ {% mtglink "Kang, Temporal Tyrant" %} 和他的同夥們非常看重『單回合內抽兩張牌』的效應。建議加入低點數的抽牌咒語，以及具有籌謀（Connive）異能的生物來支持他們。別忘了，你也可以在對手的回合觸發這些異能，因此像 {% mtglink "Thirst for Knowledge" %} 和 {% mtglink "Visions of Villainy" %} 這類瞬間咒語會特別具有影響力。

### <span style="color:#AF2321">紅</span><span style="color:#808080">黑</span> 反派崛起

![](https://i.meee.com.tw/DfJ7yLp.png)

率領成群的反派，來實行你的邪惡計畫吧！利用 {% mtglink "Madame Hydra" %} 與其他強大生物，來製造源源不絕的反派衍生物。此系列中還包含了數張黑色的『計劃（Plan）』結界。如果你開到了複數張的 {% mtglink "The Masters of Evil" %} 以及幾張令人興奮的計畫牌，就能組出一副陰險狡詐的完美套牌，並藉此啟動像 {% mtglink "Doom Reigns Supreme" %} 這類強力咒語！

### <span style="color:#AF2321">紅</span><span style="color:#4A8A3D">綠</span> 超能強化（Power-up）

![](https://i.meee.com.tw/BfRQUFi.png)

有些套牌風格講求精明計畫、精密計算與高超操作……紅綠可不是那一類的套牌。用 {% mtglink "Hulk, Gamma Goliath" %} 與其他具有『超能（Power-up）』異能的生物，直接擊潰對手的阻擋者吧！想讓你的生物碾壓能力加倍嗎？ {% mtglink "Wonder Man, Hollywood Hero" %} 能讓聚光燈永遠聚焦在你套牌中最棒的生物身上！

### <span style="color:#C3B270">白</span><span style="color:#4A8A3D">綠</span> 英雄登場

![](https://i.meee.com.tw/I2BbG4z.png)

集結來自漫威宇宙的各路英雄，鋪滿你的戰場吧！白綠套牌與藍白聯合套牌共享了數張關鍵的白色卡牌。利用能製造『英雄(Hero)』衍生物的白色牌，來重複觸發 {% mtglink "Black Panther, Vanguard" %} 與 {% mtglink "Wakandan Royal Guard" %} 的異能。一旦你建立起龐大的英雄陣容，就能利用 {% mtglink "White Widow, Free Agent" %} 和 {% mtglink "Training Regimen" %} 來強化他們的威力，發動全軍突擊贏得勝利！

### <span style="color:#C3B270">白</span><span style="color:#808080">黑</span> 單刀赴會

![](https://i.meee.com.tw/lE6Ozze.png)

利用一系列的生物、武具與更多卡牌，來全力支援你的孤勇特工吧！當某個生物隻身進攻時， {% mtglink "Black Widow, Double Agent" %} 和 {% mtglink "Voltaic Whip" %} 都能為你帶來豐厚的回報。你只需要為這項任務找到對的超級英雄就行了，例如 {% mtglink "Luke Cage, Power Man" %} 。

### <span style="color:#AF2321">紅</span><span style="color:#006DB3">藍</span> 神器大軍

![](https://i.meee.com.tw/SyiH34G.png)

打造世上最偉大的發明，並武裝你的生物吧！在套牌中投入高密度的神器，來啟動 {% mtglink "Iron Lad, Diverging Destiny" %} 與 {% mtglink "HYDRA Assault Robot" %} 的異能。這個套牌原型非常看重你所累積的神器數量，即便它們的效果微乎其微也無妨。無論是珍寶、線索還是機器人反派衍生生物，都能為 {% mtglink "Iron Man, Master of Machines" %} 的威力添磚加瓦！

### <span style="color:#808080">黑</span><span style="color:#4A8A3D">綠</span> 墓中生物

![](https://i.meee.com.tw/4VNEipU.png)

將你生物的死亡，轉化為套牌的運作燃料！有數張卡牌會檢視你的墳墓場中是否含有『兩張或更多生物牌』。在遊戲前期，利用『磨牌(Mill)』效應或像 {% mtglink "Roxxon Brutes" %} 這類具『循環(Cycling)』異能的生物來快速達成條件。一旦你將兩隻生物送入墳墓場，像 {% mtglink "Killmonger, Scourge of Wakanda" %} 與 {% mtglink "Arnim Zola, Bio-Fanatic" %} 這類的卡牌，光憑一己之力就能為你贏得比賽！

### <span style="color:#AF2321">紅</span><span style="color:#C3B270">白</span> 非生物咒語

![](https://i.meee.com.tw/BHxIacn.png)

施放一系列的非生物咒語，來證明你的套牌夠格吧！像 {% mtglink "Agent of Atlas" %} 與 {% mtglink "Thor Odinson" %} 這類帶有『靈技(Prowess)』異能的生物，只需配合幾道咒語，就能迅速膨脹為奠定勝局的巨獸。這個套牌原型比起一般套牌需要更多低法術力費用的卡牌，因此選牌時請密切留意像 {% mtglink "Super Speed" %} 、 {% mtglink "Vibranium Energy Daggers" %} 這類的複數張卡牌。

### <span style="color:#4A8A3D">綠</span><span style="color:#006DB3">藍</span> +1/+1指示物

![](https://i.meee.com.tw/UqZgVsC.png)

把你的生物養大，並高高在上地碾壓你的對手吧！利用瞬間、法術和其他支援效應，將像 {% mtglink "Beast, Erudite Aerialist" %} 這類具穿透異能的生物，轉化為泰坦級的巨大威脅。請務必在套牌中加入保護手段，來守護你身上堆滿指示物的生物。關鍵時刻， {% mtglink "Kid Loki" %} 能賦予你的生物『辟邪(Hexproof)』異能；而 {% mtglink "Claim the Kingdom" %} 則能藉由『不滅(Indestructible)』指示物，為你最強大的生物提供永久的保護。





## 評分內容

 
 {% mtgpick "MSH" 198 %}
 分數：3.0
 評語：4費4/4踐踏是合格但不突出的曲線生物，Power-Up 提供後期把自己變成5/5並互鬥的額外價值，讓它不只是單純的填充曲線。7費的啟動費用看似偏高，但若把它視為一隻7費5/5踐踏、進場互鬥的生物，本身並不算差；更重要的是它也能先作為4費曲線生物登場，分期付款的彈性讓實戰表現比純後期牌好。
        
 
 {% mtgpick "MSH" 199 %}
 分數：3.5
 評語：3費4/4警戒的優質體質，即使不利用複製能力也已經是很強的曲線生物。複製神器、非靈氣結界或地的能力上限很高，若場上有強力永久物就可以帶來額外價值。
        
 
 {% mtgpick "MSH" 200 %}
 分數：3.5
 評語：類似 {% mtglink "Urabrask's Forge" %} 的持續威脅牌，需要一點時間暖機，但只要遊戲拖長，每回合製造越來越大的敏捷 Alien token 會帶來很強的壓力。而且，這張的 token 不會在回合結束犧牲，長期上限更高；但費用是4費，而且指定色較高，準時施放難度高很多，產出的 token 必須攻擊，導致落後時無法用於防守。
        
 
 {% mtgpick "MSH" 201 %}
 分數：3.5
 評語：3費2/2的基本體質普通，但在藍綠+1/+1指示物主題中是很強的引擎。攻擊時多付1就能放一個+1/+1指示物，並因第二個異能額外製造1/1 Insect token；若牌組裡有其他放指示物的手段，即使它不方便攻擊，也能每回合靠主題牌持續產生生物，快速累積場面。缺點是本體偏小且容易被去除，自己要進攻啟動時也有一定風險。不過整體而言，還是藍綠牌組非常想要的關鍵生物。
        
 
 {% mtgpick "MSH" 202 %}
 分數：3.5
 評語：3費4/3本身是很有壓力的進攻體質，並且能讓自己所有進攻生物死亡時回手，使攻擊交換變得非常有利，特別適合主動進攻的黑紅牌組。對手若阻擋，往往只是暫時處理你的生物；若不阻擋，又會承受大量傷害。不過回手仍需要重新花費用施放，節奏上不是完全免費，而且 Ares 自己必須每回合攻擊，沒有威懾或先攻時也可能被大生物或雙擋處理。整體是黑紅進攻牌組的強力核心，但比較偏好進攻型的優勢牌。
        
 
 {% mtgpick "MSH" 203 %}
 分數：3.0
 評語：紅藍神器主題的資源牌，第一章在有多個神器時可以補大量手牌，但因為對手也會抽一張，通常至少要抽到2張才算小賺，抽到3張以上才明顯有價值；第二章能降低神器咒語費用，配合高神器密度時有爆發力；第三章則比較像收尾補傷害，能打對手但不能打生物，因此影響有限。整體來說，在神器數量夠高的紅藍牌組中有不錯上限。
        
 
 {% mtgpick "MSH" 204 %}
 分數：3.5
 評語：2費1/1本體非常脆弱，但每次抽牌都能放一個+1/+1指示物，包含每回合正常抽牌，因此只要存活就會逐漸成長，也能和藍綠的抽牌與+1/+1指示物主題很好配合。第二個異能可以把累積的指示物轉換成1/1 Insect token，讓它在後期或面對去除時保留部分價值。不過它進場當下不會立即影響場面，需要時間成長。
        
 
 {% mtgpick "MSH" 205 %}
 分數：3.0
 評語：紅黑反派(Villain)主題的傳記，第一章製造兩隻2/1威攝反派衍生物，能提供不錯的進攻壓力並支援後續章節。第二章對所有非反派生物和對手各造成2點傷害，理想情況下可以形成接近單方面掃場，但實戰中很吃對局與場面，對中大型生物影響有限，若對手也有反派則效果會下降。第三章能依反派數量製造珍寶(Treasure)，提供爆發或支援高費牌，但本身需要手上有出口才能真正轉化成優勢。整體在紅黑反派密度夠高時不錯，但太吃構築與場面，不是穩定炸彈。
        
 
 {% mtgpick "MSH" 206 %}
 分數：3.0
 評語：4費3/3的基本體質偏弱，作為多色生物如果沒有觸發抽牌很不理想。不過它只要對玩家造成戰鬥傷害就能抽牌，讓對手不能完全放著不管；若有在它身上放 +1/+1指示物，還能獲得飛行，使抽牌能力更容易觸發，也能和藍綠 +1/+1指示物主題配合。問題是它本身不會放指示物，且必須把指示物放在自己身上才有飛行，對支援要求不低。整體是藍綠主題中有上限的威脅，但下限偏低。
        
 
 {% mtgpick "MSH" 207 %}
 分數：3.5
 評語：白綠英雄(Hero)主題的頂級U卡。4費4/4本體合格，後續每當另一個非衍生物英雄進場時，都能依場面選擇製造1/1 士兵或讓全隊 +1/+1 到回合結束。前者能持續鋪場，後者能把已有場面轉化成強力進攻，和白綠英雄/橫向鋪場策略非常契合。整體是白綠英雄牌組很想要的核心牌，不過需要足夠高的英雄生物密度支援。
        
 
 {% mtgpick "MSH" 208 %}
 分數：3.0
 評語：黑白主題的關鍵生物。3費3/2死觸本身已經是不錯的戰鬥體質，若自己單獨攻擊，會同時擁有先攻、死觸與威懾，幾乎沒有生物能在戰鬥中舒服地處理它。它也能把先攻與威懾給其他單獨攻擊的生物，讓其他強力生物更容易穿透並避免交換。不過它仍然很怕去除，也沒有進場立即賺牌，強度主要建立在主題配合上。
        
 
 {% mtgpick "MSH" 209 %}
 分數：2.5
 評語：3費2/3的體質普通，無論進場還是啟動都需要額外支付資源，犧牲神器或棄牌在限制賽中不是小成本，絕大多數情況會是利用籌謀來達成棄牌的觸發；若沒有多餘神器衍生物、可棄的低價值手牌，或需要進墳場的搭配，這張很容易只是普通身材加上昂貴的打2。
        
 
 {% mtgpick "MSH" 210 %}
 分數：3.0
 評語：白藍聯合(Teamwork)主題的重要單卡。它本身是三費 3/4 警戒，身材已經相當合格，而異能可以讓我方生物在自己回合第一次被橫置後重置，因此能很好地配合聯合費用。就算沒有太多聯合牌，它也可以讓生物在攻擊後重置，變相獲得警戒，讓牌組在進攻與防守上都更有彈性。
        
 
 {% mtgpick "MSH" 211 %}
 分數：3.0
 評語：不錯的干擾型單卡。進場可以看對手手牌，並暫時放逐一張非地牌或一隻生物，能有效打亂對手節奏，也能處理場上最麻煩的威脅。本身有死觸與繫命，交換能力不差。不過三費 2/2 的體質偏弱，而且放逐效果會在它離場後失效，因此不算穩定去除。
        
 
 {% mtgpick "MSH" 212 %}
 分數：4.5
 評語：高強度炸彈。第一章進場就能處理對手最麻煩的威脅，讓這張牌不會只是單純慢牌。第二、三章雖然只是讓對手失去生命，但可以持續累積壓力。真正的強度在第四章，能製造一個 16/16 飛行、踐踏的行星吞噬者(Galactus)，對手如果沒有答案通常很難撐住。雖然傳記暖機偏慢，但這張牌本身合計就能造成20點壓力，加上進場帶有去除效果，已經是非常值得優先選取的炸彈。
        
 
 {% mtgpick "MSH" 213 %}
 分數：4.0
 評語：這張是紅白很強的節奏與資源核心。他下場當回合就能開始進攻，攻擊後又不會犧牲防守節奏，讓對手很難用普通生物交換處理。最重要的是，只要它能持續攻擊，就能不斷補牌，讓紅白這種偏進攻的牌組不容易打到後面沒資源。英雄數量夠多時，攻擊壓力會再明顯提升；即使沒有特別圍繞它構築，本身也已經是色組正確時非常值得首選的強牌。
        
 
 {% mtgpick "MSH" 214 %}
 分數：2.5
 評語：這張就是穩定可用的曲線牌。閃現讓它可以保留彈性，不用在自己回合先投入戰場；不能被阻擋則讓它很適合穩定偷傷害，不過三費 2/2 本身壓力不算高，也沒有補牌或解場能力，單獨來看只是穩定輸出的小威脅。
        
 
 {% mtgpick "MSH" 215 %}
 分數：4.0
 評語：紅綠超能(Power-up)主題的重要單卡。本體作為五費6/5延勢踐踏已經相當合格，能在中後期提供很大的場面壓力，也不怕被飛行生物輕易打穿。它最重要的價值是能降低其他超能生物的啟動成本，讓紅綠在後期更容易把多餘魔法力轉成實際威脅。自己也有很高的成長上限，一旦成功變大，會讓對手很難用普通阻擋處理。
        
 
 {% mtgpick "MSH" 216 %}
 分數：3.0
 評語：紅藍神器主題的核心單卡。它本身有飛行和警戒，代表只要攻擊力被神器撐起來，就會變成很難處理的空中威脅，而且攻擊後還能留下來防守。這張最吃牌組的神器密度；如果牌組能穩定讓神器進場，它就不只是打點，也能持續補資源，讓紅藍在中後期不容易斷牌。缺點是沒有神器支援時本體偏弱，單獨來看壓力不足，但在成形的紅藍神器牌組裡會是很重要的高順位牌。
        
 
 {% mtgpick "MSH" 217 %}
 分數：3.0
 評語：藍黑色組中可用的中期價值單卡。它在能順利攻擊時可以慢慢提升手牌品質，也能累積一些血量差，打久了會有不錯的後期價值。不過它本身沒有穿透能力，也沒有警戒，攻擊後會犧牲防守節奏；如果場面落後、沒有攻擊空間，就會比較普通。
        
 
 {% mtgpick "MSH" 218 %}
