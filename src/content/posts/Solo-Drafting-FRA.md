## 前言

在這個娛樂選項多如繁星的現在，要約成一桌八人輪抽是越來越難了。本次企劃，以現實碎片（Reality Fracture, FRA）作為示範系列，盡可能以套牌強度與主題協同性為主要考量，試著完成獨自輪抽的挑戰！

![座位示意圖](https://i.meee.com.tw/9l5SdLp.jpg)
<p style="text-align: center;"><a class="small">本次輪抽座位示意圖。圖片由Gemini 3.1 Pro生成</a></p>

輪抽座位如上圖。
> 須特別留意，本文輪抽座位次序與正式輪抽不同。正確的輪抽位置應該是從1號玩家到8號玩家，以順時針方向依序入座。這是我的理解有誤，但發現問題時照片已經全數拍完，因此決定保留不變，並於此附註說明。有興趣的讀者可參閱官方的這篇：[Bahr: Here's What the Optimal Draft Looks Like](https://wpn.wizards.com/en/news/bahr-heres-what-optimal-draft-looks)

進行方式比照一般八人輪抽規則，第一包向左傳、第二包向右傳、第三包再向左傳。每包補充包中除了最後一張的衍生物／廣告牌不用傳以外，其他14張牌都需傳出。輪抽過程不限時，也允許隨時查看已抽選的牌張。過程中，我盡量在單一人腦可負荷的範圍內，完成八位獨立「玩家」的輪抽選牌與套牌構築。

### 第一包：抽選過程

![1](https://i.meee.com.tw/VHamf2N.jpg)
鏘鏘！First pick解謎篇！除了1號與2號玩家外，其他六名玩家均拿下自己那包的R／MR卡。1號玩家未選擇 {% mtglink "Puppet Crafting" %} 的原因是這張牌需要搭配、且[FRA](https://scryfall.com/sets/fra)並不是以神器／結界為主題的系列。而2號玩家未選擇的 {% mtglink "Codie, Ravenous Codex" %} 的主因，則是 {% mtglink "Eye of Jace" %} 每回合刺探一的效果更為全面。

> 輪抽重點：第一包首挑通常應優先考慮單卡強度與顏色開放性，其次才是主題。原因是首挑的當下，你很難確保這個主題是不是真的成立、以及有足夠的可用牌。

![2](https://i.meee.com.tw/OMNBvB4.jpg)
- 1號玩家由於首挑 {% mtglink "Titanbones, Towering Heart" %} ，會希望走白綠加血的套路，比起一次性加血的 {% mtglink "Emergency Phytomedic" %} ，能透過地落多次加血、甚至灌大體格的 {% mtglink "Koth of the Homestead" %} 更適合。
- 2號玩家首挑 {% mtglink "Eye of Jace" %} ，此時傳來 {% mtglink "Puppet Crafting" %} 相當誘人，決定提高後續神器／結界的選次，朝綠底的[神器緘靈](https://scryfall.com/card/m15/54/zht/%E7%A5%9E%E5%99%A8%E7%B7%98%E9%9D%88-(ensoul-artifact))快攻前進。
- 3號玩家首挑 {% mtglink "Variable Chaser" %} ，這一包有相當多紅藍色組的牌可選擇。在 {% mtglink "Way of the Pyromancer" %} 、 {% mtglink "Way of the Cryomancer" %} 、 {% mtglink "Violent Echoes" %} 這三張之間，選擇第一張的紅結界來搭配加速使用。
- 4號玩家首挑 {% mtglink "Liliana the Faultless" %} 後，同樣往白綠加血的思路發展。在 {% mtglink "Vigorbloom Charm" %} 與 {% mtglink "Way of the Wildspeaker" %} 之間選了彈性較大的 {% mtglink "Vigorbloom Charm" alt="白綠charm" %} 。
- 5號玩家首挑 {% mtglink "Hexhaven Invigorator" %} 後基本上就是有綠就拿，這一包沒什麼好選擇，拿下 {% mtglink "Inspired Tethermage" %} 。 
- 6號玩家首挑 {% mtglink "Sanctum Lurker" %} 後選擇相對開放，決定維持黑色，拿 {% mtglink "Ferocity of the Hunt" %} 做為一個trick。拿 {% mtglink "Woodwork Prodigy" %} 也是可以，但就還不想這麼早往第二色走。
- 7號玩家首挑 {% mtglink "Lyra, Archangel of Dawn" %} 同樣鎖定白色，拿下 {% mtglink "Saheeli, Consul of Oversight" %} 。 
- 8號玩家首挑 {% mtglink "Uldaros Theorix" %} 後，套牌構築方式就往黑底的墳場利用走，傳來的 {% mtglink "Liliana the Repentant" %} 、 {% mtglink "Extended Absence" %} 、以及藍色的 {% mtglink "Surveillance Phantasm" %} 都相當不錯，但考慮到稀有度與套牌發展性後決定拿下 {% mtglink "Liliana the Repentant" alt="黑莉莉" %} 。

![3](https://i.meee.com.tw/MGmLemC.jpg)
2號玩家鎖定神器主題後，拿下 {% mtglink "Warrior's Blades" %} 。7號玩家在上家傳來藍色的 {% mtglink "Surveillance Phantasm" %} 後，有轉往藍白刺探主題發展的態勢。8號玩家在[兩張賈路結界](https://scryfall.com/search?as=grid&order=name&q=Way+of+the+%28oracle%3A4%2F4+oracle%3ABeast%29+%28game%3Apaper%29+set%3Afra+prefer%3Abest)與黑綠色組的 {% mtglink "Hapatra, the Desert Fang" %} 間猶豫，最後選了可被挖回場上的黑綠Hapatra。

![4](https://i.meee.com.tw/uwfrFcP.jpg)
2號玩家放著神器生物 {% mtglink "Keeper of the Quiet Hour" %} 不拿跑去拿 {% mtglink "Winter, Tormented Loner" alt="黑Winter" %} ，以及4號玩家不繼續拿綠色加血引擎 {% mtglink "Greenhouse Propagator" %} ，都是主題性上的不一致。7號玩家拿了第三色的 {% mtglink "Way of the Wildspeaker" %} 算是情非得已，其他藍白色組能拿的牌的影響力都偏低。而5、6、8號玩家，在這一挑中都拿到了自己主題的重要單卡。

![5](https://i.meee.com.tw/Wi6YACO.jpg)

1號玩家開始與套牌主題發生分歧。五費的 {% mtglink "Fateshaper Aspirant" %} 雖是張堅實的單卡，但一來不支援加血體系、二來也無法與第3挑拿下的 {% mtglink "Generous Revival" %} 互動。這副套牌此時最缺的是二三費曲線，因此拿一張五費牌並不是最佳選擇，改拿中後期還能起飛進攻的 {% mtglink "Afterthought Sentry" %} 可能更好。而7號玩家往第四色走，拿下兩點紅的 {% mtglink "Violent Echoes" %} 也並非合理的選擇，同一包甚至有藍白雙色地可以選。優先維持雙色仍是一個較穩妥的選法。8號玩家則無視豐富的藍黑色組解牌，選了 {% mtglink "Tinybones, Pocket Nuisance" %} ，繼續充實墳場可再利用的生物。

![6](https://i.meee.com.tw/59tryAj.jpg)

1號玩家受到上下家爭搶綠色牌的影響，這一包面臨了混第三色的抉擇，在紅色的 {% mtglink "No Admittance" %} 與黑色的 {% mtglink "Extended Absence" %} 間選擇了較扎實的後者（也能觸發補血），但套牌也因此不可避免地往較笨重的路線發展。而2號玩家無視 {% mtglink "Afterthought Sentry" %} 去拿毫無搭配的 {% mtglink "Mabel, Bitter Recluse" %} ，很明顯地是還沒認清主色應是綠色。3號玩家在缺乏體格的情況下選擇 {% mtglink "Arni, Humble Scribe" %} 並不實際，非生物主題的套牌必須要靠去除、干擾、或體格較佳的生物度過前期，才有中後期主題發揮的空間。改拿其他體格較佳的紅色生物、甚至 {% mtglink "Icy Reception" %} 做二費干擾都會更好。 

![7](https://i.meee.com.tw/qvy2DGk.jpg)

這包相對平淡，但5號玩家拿到了 {% mtglink "Codie, Ravenous Codex" %} ，有機會讓備法（prepare）咒語能多複製一次。同一包還有 {% mtglink "Budding Insurgent" %} 可選，但輪抽中仍建議選擇上限高的那邊。

![8](https://i.meee.com.tw/o5sFf2A.jpg)

2號玩家終於回過神來拿紅色的曲線，開始把色組鎖定紅綠雙色，並看有無機會混白。5號玩家還有第二張 {% mtglink "Woodwork Prodigy" %} 可拿純屬意外。6號玩家拿下 {% mtglink "Koth, the Geomancer" %} 後已有三張可以觸發非戰鬥傷害的引擎生物，紅黑的牌型已相當明確。8號玩家拿下 {% mtglink "Extrapolate the Impossible" %} 後，也稍微改變了他之後的拿牌策略，稍微往擴增備牌可用性的路線去走。

![9](https://i.meee.com.tw/UDKNjQc.jpg)

1號與6號玩家很幸運地撿回自己的 {% mtglink "Greenhouse Propagator" %} 與 {% mtglink "Stingerquill Charm" %} 。

![10](https://i.meee.com.tw/YTtE8Ib.jpg)
2號玩家選擇拿紅綠雙色地而放過了 {% mtglink "Medic's Kitesail" %} 不能算錯，但並不是能提高上限的選法。

![11](https://i.meee.com.tw/dgozhdJ.jpg)
2號玩家拿下的 {% mtglink "Living Library" %} ，除了增加前期的防禦外、也是增加主題協同性、並作為隱藏的中後期解牌的好選擇。 

![12](https://i.meee.com.tw/BAc3trU.jpg)

4號玩家能撿到 {% mtglink "Medic's Kitesail" %} 是意外的驚喜。 

![13~14](https://i.meee.com.tw/HBP7jpo.jpg)

最後幾挑中，6號玩家看到這一系列的回傳，連 {% mtglink "Stinging Vitriol" %} 也被傳到最後，幾乎能篤定整桌只有他一人打紅黑。沒意外的話，他可以抽出一副相當完整的紅黑套牌。

### 第二包：抽選過程

![15](https://i.meee.com.tw/u2wqarm.jpg)

- 1號玩家太在意沒有強力生物，放掉了 {% mtglink "Vigorbloom Charm" %} 而首挑搭配度較低的 {% mtglink "Ghalta the Unstoppable" %} 。事後來看並不理想。
- 2號玩家第一包的思路完全無法融入 {% mtglink "Lyra, Tolarian Archangel" %} ，因此選擇了紅色可用的強牌 {% mtglink "Jiang Yanggu, Alone" %} 。
- 3號玩家看到這一包心情猶如槁木死灰，拿下 {% mtglink "Protege's Awakening" %} 。以事後諸葛論，若這邊拿下 {% mtglink "Theorix Charm" %} 往沾黑去走，最終的套牌強度應能提升不少。但當下誰知道呢？
- 4號玩家這一包有許多好料，拿下最強牌 {% mtglink "Guiding Hydra" %} 。
- 5號玩家的綠底基礎已相當扎實，拿下 {% mtglink "Ghalta the Unstoppable" %} 讓全家踐踏相當兇猛！另外也有考慮拿 {% mtglink "Way of the Warlord" %} 搭配讓 {% mtglink "Hexhaven Invigorator" %} 觸發找地。但大恐龍還是更符合主題。 
- 6號玩家這包沒什麼好料，拿了 {% mtglink "Cast Away Doubt" %} 稍嫌早了一點，但不是不能接受。也與紅黑燒血的思路吻合。如果不拿這張的話，紅色基本地循環的 {% mtglink "Awaken the Inferno" %} 也是個不錯的選擇。
- 7號玩家被白綠R卡、以及混三色的可能性所迷惑。若重選一次，這邊應該要拿 {% mtglink "Fatehold Charm" %} 。 ~~雖然後面也傳回來了~~
- 8號玩家首挑黑色基本地循環 {% mtglink "Apex Witchstalker" %} ，並非無謀之舉。前期找地、中後期挖回來，在藍黑色組已有 {% mtglink "Uldaros Theorix" %} 時是個合理的選擇，且放走同一包 {% mtglink "Plan for All Outcomes" %} 的損失並不大。本體六費正拍也不弱，再考慮到第一包拿下的 {% mtglink "Extrapolate the Impossible" %} ，基本地循環更能方便你施放備牌乍看用不出來的其他色炸彈。

![16](https://i.meee.com.tw/EisVJbw.jpg)

2號玩家與其拿 {% mtglink "Konstrari Charm" %} ，純綠的 {% mtglink "Compel Brutality" %} 會是更好的選擇。8號玩家在這邊拿到最需要的 {% mtglink "Rewrite Regrets" %} ，挖墳的上限又更高了！ 

![17](https://i.meee.com.tw/UHRryUD.jpg)

有鑑於上一包的訊號，6號玩家決定賭自己的 {% mtglink "Stingerquill Voxmancer" %} 會傳回來，優先拿下 {% mtglink "Way of the Pyromancer" %} 做加速。8號玩家這邊拿得不好，當時應只考慮到備牌混色的可能性。這一包直接拿下 {% mtglink "Mindseeker Oculus" %} 會更好，或改拿 {% mtglink "Yuriko, Hope from the Shadows" %} 潤滑前期曲線也不差。

![18](https://i.meee.com.tw/E4gJAZG.jpg)

2號玩家這邊若拿白色基本地循環 {% mtglink "Hexhaven Battalion" %} 的上限會更高。3號玩家前兩挑錯過了轉黑的時機，這邊只能先拿調色石 {% mtglink "Murmuring Volume" %} 徐圖進取。6號玩家在這邊拿到第二張的 {% mtglink "Command the Stage" %} ，搭配充足的非戰鬥傷害來源，更多了一個中速壓倒致勝的計畫。7號玩家再度被1號玩家放掉的 {% mtglink "Vigorbloom Charm" %} 所迷惑，還沒放棄混綠色的計畫。 

![19](https://i.meee.com.tw/PDKEdBG.jpg)

這一挑沒有特別想提的。但7號玩家沒有拿 {% mtglink "Lyra, Tolarian Archangel" alt="藍萊拉" %} 而選了 {% mtglink "Jace's Machinations" %} 完全是我的失誤。當時太想往白藍混綠走了，甚至沒有好好看清楚這包有什麼。

![20](https://i.meee.com.tw/GRBzSYv.jpg)

上一包的錯誤讓8號玩家拿到不該有的 {% mtglink "Lyra, Tolarian Archangel" alt="藍萊拉" %} 。5號玩家拿到的 {% mtglink "Yoshimaru, Scrappy Stray" %} 在純綠豐富的魔法力下相當適合。 

![21](https://i.meee.com.tw/mkuzE1w.jpg)

1號玩家撿到一張 {% mtglink "Ferocity of the Hunt" %} ，跟上一挑拿到的 {% mtglink "Danitha, Sword of Hope" %} 算有搭配。3號玩家終於有稍微像樣的終結者 {% mtglink "Ruric Thar, Biomagus" %} 。7號玩家與8號玩家撿到 {% mtglink "Way of the Healer" %} 與 {% mtglink "Theorix Charm" %} 真的是賺到了。 

![22](https://i.meee.com.tw/POxDGmh.jpg)

本pick中5號玩家的套牌迎來了質變！撿到了純綠最大的回報單卡 — {% mtglink "Roiling Canopy" %} 。與 {% mtglink "Hexhaven Invigorator" %} 搭配，有機會在造成戰鬥傷害前，透過其他傷害找出多張樹林來爆出驚人的體格加成！8號玩家則拿到了 {% mtglink "Loot, the Anomaly" %} ，他在藍黑自磨的遊戲計畫中將是致命的打手！

![23](https://i.meee.com.tw/OME4Lwp.jpg)

1. 中速墳場利用：使用 {% mtglink "Uldaros Theorix" alt="藍黑史芬斯" %} 與 {% mtglink "Rewrite Regrets" %} 直接挖墳；或用 {% mtglink "Theoretical Necromancer" %} 撿墳，達到一張牌用兩次以上的效果。

3. 自磨 →  {% mtglink "Loot, the Anomaly" alt="黑爛寶" %} 強攻：墳場累積7張以上（門檻，Threshold），黑爛寶就能犧牲生物來灌大。受益於負值的攻擊力，當 {% mtglink "Tetsuko Umezawa, Fugitive" %} 在場時黑爛寶就不能被阻擋；如果再瞬間跳 {% mtglink "Yuriko, Hope from the Shadows" %} 甚至有機會一拳打爆對手。
4. 自磨 → 用 {% mtglink "Recursive Recruitment" %} 從墳場八費返照做出兩隻巨大的學徒。

而 {% mtglink "Extrapolate the Impossible" %} 能讓你找出當下需要的備牌，偶爾也會有奇效。

## 對戰結果

對戰方式採8人單淘汰，三戰兩勝制。感謝不願具名的玩家協助完成本次對戰。

### 第一輪
第一桌由操控白綠混黑的1號玩家對決使用藍黑色組的8號玩家。8號玩家獲勝的兩局基本上是毫無懸念的中盤資源量輾壓。輸掉的一盤則是因為8號玩家卡在四塊地，被1號玩家曲線擊倒。

第二桌相對拉鋸，第一盤由操控藍白色組的7號玩家先以 {% mtglink "Yuriko, Blade of the Mighty" %} 搭配飛兵快速擊倒。但接下來二三盤，使用紅綠神器的2號玩家都能在穩住場面後反打致勝。

第三桌也是一面倒的戰局。操控紅藍色組的3號玩家在面對6號玩家曲線密集的紅黑色組，防線很快就被打穿，再加上紅藍色組沒有補血手段，面對紅黑穩定的非戰鬥傷害攻勢毫無扳回的機會。

而最後的第四桌，4號玩家的白綠加血策略，即使其中一盤有順著曲線展開，但面對5號玩家生物的體格優勢，很快就無法持續施壓對手。被跳費後基本上就是必輸的局面。

### 第二輪

第二輪第1桌由8號玩家對決2號玩家。2號玩家的遊戲計畫，在雙方都順利展開的條件下，無法有效擊倒具有長盤資源優勢的8號玩家。

而第2桌由操控純綠的5號玩家對決使用紅黑的6號玩家。紅黑方雖以快速的曲線與血量直擊拿下第一盤，但後續兩盤面對純綠的超加速，以及燒牌面對對方王牌 {% mtglink "Hexhaven Invigorator" %} 時的巨大劣勢，最終在純綠猛攻下落敗。

### 第三輪（決賽）

## 結語：「全知」的視野，是否能造就八副「全能」的輪抽套牌？

獨自完成八人輪抽，比想像中困難許多。即使不限時，也能反覆查看各「玩家」先前拿過哪些牌，仍會受限於當下的理解、偏好與疲勞，做出事後看來並不理想的選擇。輪抽的過程也迫使你不斷在八種思路之間切換，而筆者的腦容量有限，在撰文回顧時，也發現了許多當時的盲點。正因如此，這次嘗試讓我有機會反覆從不同視角，重新審視整場輪抽的變化。

所謂「全知」，並不是真的能預知每一包會開出什麼，而是盡可能掌握「已知」的資訊：誰在搶同一色組、誰的主題正在成形、誰缺少曲線或互動，以及每一次選擇會向上下家傳遞什麼訊號等。這邊提到的「全能」，也不是要打造八副最全面的套牌。而是讓每一副都具備明確的主題、合理的曲線與足夠的互動，這些足以在對戰中獲勝的基礎條件。

回顧整場輪抽，真正決定套牌成敗的，往往不是某一挑拿到最強的單卡，而是能否在正確的時間點，做出與套牌主題一致的取捨。主題提供輪抽方向，曲線決定對局節奏，互動決定容錯率。當這些要素彼此咬合，42張選出的牌，才會從一堆「不差的牌」，拼湊成一副真正能運作的模組。

一個設計良好、可玩性極高的系列，就應該像[FRA](https://scryfall.com/sets/fra)這樣。官方的色組主題只是起點，當你把不同元件拼湊起來，便會發現還有許多值得探索的可能性。輪抽是一場將想像付諸實踐的過程，而實際對戰，則是用來確認這些想像能否經得起現實考驗。

如果你手邊剛好有一盒補充包，不妨也試著獨自完成一場八人輪抽。你會發現，最難的並不是在每一挑中選出「最強」的牌，而是在自身盲點的限制下，為八名不同的玩家，做出各自合理的選擇。此時，你的思考不再只為一副套牌服務，而必須以近乎「全知」的鳥瞰視野，同時衡量訊號、主題、曲線與互動間的平衡，構築出八副主題各異、強度相近，卻各自具備獲勝計畫的套牌。

{% mtglink "The Theorist, Jace Beleren" alt="傑斯貝連" %} 在故事中，以凡人之軀逐步走向「全知全能」，並最終達到這個境界。而獨自完成八人輪抽，或許也是朝此目標邁出的一小步：不為追求無所不知、無所不能。而是在每一次切換視角時，更真誠地面對自己的偏誤。
