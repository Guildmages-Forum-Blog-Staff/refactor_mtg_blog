漫威超級英雄（Marvel Super Heroes, MSH）將於2026年6月19日舉行售前賽活動，而於隔一週2026年6月26日正式發行，想更了解在限制賽的單卡評分與建議嗎？那就來看看這一系列的MSH限制賽介紹吧！

- 機制介紹請看這篇：[漫威超級英雄機制解析](https://guildmagesforum.tw/MSH-mechanism/)

## 評分內容

{% mtgpick "MSH" 85 %}
分數：2.5
評語：本身就是一個一帶一的生物，這系列也很需要反派（Villain）去死掉進墳是很好的曲線生物。

{% mtgpick "MSH" 86 %}
分數：3.0
評語：只要墳場達成條件和有多餘法力就是一直三費叫2/1三費叫2/1，叫出來的還是威懾（Menace）根本超強，但要注意生出來的是躺著的沒辦法立即參與攻防。

{% mtgpick "MSH" 87 %}
分數：2.5
評語：本身效果十分強力，但三點黑讓他很難三回合叫出來，用一隻五回合會出的生物來看他比較合理，下面那條就是送的限制賽基本不可能達成。

{% mtgpick "MSH" 88 %}
分數：3.5
評語：身為一個反派領主讓反派少一費就很強，反派進場還能抽濾，真的有夠壞。

{% mtgpick "MSH" 89 %}
分數：3.5
評語：先手二回下這個生物大概率都能偷到一張，選擇讓他長大還可以讓他有機會打到第二下，能NTR對面就是強！！！

{% mtgpick "MSH" 90 %}
分數：2.5
評語：雖然藍黑的主題是抽第二張牌，但除非是準時下結界不然應該是很難觸發下面的效果，最強的反而是可以繼續橫鋪場面，腦控對手就當作有機會爽到的就好了。

{% mtgpick "MSH" 91 %}
分數：3.5
評語：四回叫進來就是一隻強力的死觸生物，而且你還能一直養他，養他還能扣對面血量，整個就是他獨自升級升到一半對面就受不了殺他、或是對手就這樣被解決了。

{% mtgpick "MSH" 92 %}
分數：2.5
評語：三費解牌費用可接受，但限制只能放逐三費以下的射程偏短。好在聯合2（Teamwork 2）後就是一個正殺加奶三血，有機會的話就盡量聯合施放吧！

{% mtgpick "MSH" 93 %}
分數：3.0

{% mtgpick "MSH" 94 %}

{% mtgpick "MSH" 95 %}

{% mtgpick "MSH" 96 %}

{% mtgpick "MSH" 97 %}

## 結語
這個系列的黑色很明顯沒有哪種一進來就從街頭炸穿到巷尾的超級大炸彈，基本上都很明顯的在服務各個雙色主題，只有 {% mtglink "Doctor Doom" %} 是比較破格的強力單卡而已。
