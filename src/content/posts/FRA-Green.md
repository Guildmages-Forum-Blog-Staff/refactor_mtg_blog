現實碎片（FRA）將於2026年9月25日舉行售前賽活動，而於隔一週2026年10月2日正式發行，想更了解在限制賽的單卡評分與建議嗎？那就來看看這一系列的FRA限制賽介紹吧！

- 機制介紹請看這篇：[現實碎片機制解析](https://guildmagesforum.tw/FRA-Mechanism/)

## 評分標準

5.0：無條件必拿，能帶來幾近勝利的優勢
4.5：色組正確無條件必拿，能帶來大幅的優勢
4.0：有首選價值，與色組主題的相性極佳，能成為混色／轉色或進入色組的決定性牌張
3.5：系列頂 U、C 與其他強度夠的單卡，與色組主題相性佳，能成為進入色組的關鍵牌張
3.0：色組主題的重要單卡，以及其他高於平均值的單卡，會希望進到最終牌組
2.5：平均水準，通常是不錯的曲線填充物
2.0～1.0：低於平均，基本傾向不放，必要時可用來填充，但不宜過多。2.0分也可以作為強力備牌的分數。
0.5～0.0：不可用，基本上別放，放了只會幫你輸

分數：3.0
評語：老樣子，死觸保底一換一。若前期準時施放，很高機率能幫你賺一張地牌。

{% mtgpick "fra" 101 %}
分數：3.0
評語：MTG第一張用鵬洛客造成傷害的咒語，不過大部分情況下場上生物體質應該會比鵬洛客的忠誠值更高。瞬間時機加上可以指定對手的鵬洛客，是張非常好用的解牌。

{% mtgpick "fra" 102 %}

評語：針對的範圍太小注定這張只能是備牌，請務必注意這張只能指定對手的紅色、白色永久物，其他顏色的永久物連指都不能指。

分數：3.0
評語：[黑市](https://scryfall.com/card/clb/739/zht/%E9%BB%91%E5%B8%82-(black-market))綠色版（有人說這張叫花市，滿好笑的），只需要進行幾輪生物攻防交換就可以開始大量跳費了。產出來法力僅限在戰鬥前的主要階段使用。

{% mtgpick "fra" 105 %}

評語：指定色太重了所以分數沒辦法更高，雖說這系列有心材衍生物的主題可以稍微減輕指定色的壓力。體質好的不得了，而且觸發式異能可以找任意的地牌，並不限於基本地。

{% mtgpick "fra" 107 %}
分數：3.5
評語：這系列能吃的神器其實並不多，比起直接犧牲心材衍生物給敏捷開打，我會覺得留著神器跟費用做保護更強。

分數：3.0

{% mtgpick "fra" 110 %}
分數：0.0

{% mtgpick "fra" 112 %}

評語：把前期刺探下去的牌撿回來，或單純回收被對手解掉的炸彈都是很好的選項。單純用來觸發白綠色組的回血payoff也不虧。墳場如果沒有永久物牌是不能空發的，請留意。

{% mtgpick "fra" 114 %}

評語：除了瞬間找接下來用的牌以外，磨牌可以配合藍黑門檻相關牌張，回血則可以配合白綠回血相關牌張。是靈活且有構築彈性的單卡。

{% mtgpick "fra" 115 %}
分數：2.5
評語：很不錯的曲線填充物，用異能去除對手的飛行生物可以避免被咒語反擊。

{% mtgpick "fra" 116 %}
分數：2.5
評語：曾經的王者回來了，這系列刺探跟磨牌咒語蠻多的，長到4/5的體質應該不是難事。
另外，塔莫耶夫是會檢查所有玩家墳場類別的喔！計算體質的時候請再三確認。如果墳場沒有瞬間牌而對手施放[No Admittance](https://scryfall.com/card/fra/89/no-admittance)指定體質為2/3的塔莫耶夫時，塔莫是不會死的哦！詳細規則請看[這篇](https://guildmagesforum.tw/What-is-SBA/)。

{% mtgpick "fra" 264 %}

{% mtgpick "fra" 269 %}

評語：可以視為兩費巫術互鬥，起動式異能的費用過於高昂，但仍然算是一張解牌，該正編就要正編。

## 結語
這次看到很多老朋友以新面貌重出，感覺非常親切。如果有沒發現的致敬請各位讀者務必告訴我們。喜歡大生物的玩家一定超愛這系列啦！[魯瑞雜爾](https://scryfall.com/card/fra/265/ruric-thar-magecrusher)、[戈厄塔](https://scryfall.com/card/fra/260/ghalta-the-unstoppable)都好帥啊！而且綠色的調色跟跳費又多又好，在限制賽可以非常靈活的構築牌組。

非常推薦各位讀者到附近的店家玩玩看這次的限制賽哦！
