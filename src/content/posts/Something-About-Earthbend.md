## 前言

[運土（Earthbend）](https://guildmagesforum.tw/TLA-Mechanism/#%E9%81%8B%E5%9C%9F%EF%BC%88Earthbend%EF%BC%89)是這次降世神通的中，顯然非常強大的新機制之一，尤其[獾地鼠幼獸](https://scryfall.com/card/tla/167/badgermole-cub)更是從預覽期開始就是萬眾矚目的焦點，和其強度成正比的是，運土的機制複雜度也相當之高，甚至連官方的機制介紹文章都難得的出包了，說是2025年標準系列中最複雜的新機制也不為過。今天就讓我們來看看運土究竟能搞出多少問題吧！

![前言](https://i.meee.com.tw/w5Mwlk2.png)

## 運土規則簡介

運土的正式規則條文如下：

- 701.66a 「運土N」意指「目標由你操控的地成為0/0，具敏捷異能的地生物，且仍具有原本類別。在其上放置N個+1/+1指示物。當該地死去或進入放逐區時，將它在你的操控下橫置移回戰場。」

![Earthbend](https://i.meee.com.tw/RWeb8M2.png)

其實真要說難記也不算很難記，畢竟這種把地變成生物的效果也不少見了，但這種一次動到多層[Layer](https://guildmagesforum.tw/Layer/)的機制，就總是有被玩出規則炸彈的潛力。

不過實戰中牽涉到運土的規則問題，其實大多都是最後一句 **<font color="#FF0000">「當該地死去或進入放逐區時，將它在你的操控下橫置移回戰場。」</font>** 造成的。關於這個效應，先總結出兩項重點，後續的範例中會再詳細解釋其原理。

### 1.死去或放逐時回場是個觸發式異能，且不是這個地自身的異能

在MTG術語中，只要你看到 **<font color="#FF0000">「當（When）」</font>** 這個字時，就代表這是個觸發式異能了，是會上堆疊也可以被回應、被康的。

另外這是個作用於這地生物上面的效應，會創造一個延遲觸發式異能，而不是被運土的地具有的異能，所以讓被運土的地生物失去所有異能，並不能阻止它回場。

### 2.無論在誰的操控下死去，操控權皆回到當初執行運土的玩家

被運土的地生物，死去或放逐後會回到誰的場上，這是運土早期最大的規則爭議，這裡面也有官方介紹時出包的鍋。只說結論就是：這個地生物當初是哪位玩家運土的，回場時的操控權就回到那位玩家。

至於同一塊地經歷多位玩家運土過，就是另一個進階問題了。

## 運土規則範例

![1](https://i.meee.com.tw/szBzSoY.png)
> ● **[得享安息](https://scryfall.com/card/big/4/rest-in-peace)：** 
> 如果任一張牌或衍生物將從任何地方置入墳墓場，改為將它放逐。
> ● **[吸魂器](https://scryfall.com/card/dsk/248/ghost-vacuum)：** 
> {T}：將目標牌從墳墓場放逐。

可以利用得享安息或吸魂器，來阻止被運土的地因[謀殺](https://scryfall.com/card/j25/467/murder)死去時，橫置回場的效果嗎？

首先得享安息是完全不行，得享安息的死去改為放逐是一種替代性效應，但是運土的搶救範圍本來就是死去or放逐，所以你把消滅解改成放逐解，依舊沒脫離運土的搶救範圍，這塊地會因為進去放逐區而被運土重新橫置回到戰場。

而上面也說過，運土的回場是一種  **<font color="#FF0000">觸發式異能</font>** ，可以被回應，所以當運土的地死去時，完整流程是：
地生物被消滅 → 地牌進入墳場 → 觸發式異能觸發 → 觸發式異能結算，該地牌橫置回場

那麼如果能在這張地牌還待在墳場，並且觸發式異能結算前，讓其從墳場消失，就能阻止它被運土拉回來，吸魂器的瞬間放逐墳場正好能做到這點。

至於這明明最後也是進入放逐區，為何得享安息無法阻止，吸魂器卻可以？ 原因簡單的來說就是，這個異能是在墳場觸發的，結算時這個物件必須還待在墳場沒區域移動過，這異能才追蹤的到這物件，完整規則如下：

- 603.6. 與物件改變區域有關的觸發事件稱為「改變區域觸發」。許多具有改變區域觸發的異能在該物件改變區域之後對該物件作出影響。在結算過程中，這些異能在該物件移動到的區域中尋找該物件。如果該物件在它移動去的區域中無法找到，則該異能嘗試對該物件作出影響的部分沒有任何效果。該異能可能由於該物件從未進入該區域、由於它在該異能結算之前離開該區域、或由於它所在的區域並不對某玩家公開（例如牌庫或對手的手上）而無法找到該物件。 （此規則對即使該物件離開該區域並在異能結算之前返回該區域的情況也同樣生效。）最常見的改變區域觸發為進入戰場觸發和離開戰場觸發。




{% mtgpick "tla" 94 %}
> ● **[黑陽日反攻](https://scryfall.com/card/tla/94/day-of-black-sun)：** 
> 所有魔法力值等於或小於X的生物都失去所有異能直到回合結束。消滅這些生物。

用黑陽日反攻掃掉被運土的地生物，這些地牌能不能回來？ 這是這次TLA限制賽就經常遇到的問題。

當我們在討論一個物件獲得獲失去異能時，實際上說的都是[Layer第6層](https://guildmagesforum.tw/Layer/#%E5%B1%A46%EF%BC%9A%E6%B7%BB%E5%8A%A0%E3%80%81%E7%A7%BB%E9%99%A4%E7%95%B0%E8%83%BD%E7%9A%84%E6%95%88%E6%87%89)的添加、移除異能效應，不過運土的機制在第6層讓它獲得的異能只有敏捷而已，死去或放逐時回場這條是作用於這地上的一個效應，而不是地自己的異能。

| Layer | 被運土的地生物 | 黑陽日反攻 |
| :-: | :-: | :-: |
| 4 | 額外有生物類別 |  |
| 6 | 具敏捷異能 | 失去所有異能 |
| 7B | 成為0/0 |  |
| 7C | +1/+1指示物 |  |
| Other | 死去或放逐時回場 |  |

結論就是： **<font color="#FF0000">失去異能不能阻止運土的地生物回場</font>** 。

> 近似原理的案例，可以參考[勒格文+褪除武裝](https://guildmagesforum.tw/Layer/#%E5%B7%A7%E6%89%8B%E7%AB%8A%E7%8C%B4%E5%8B%92%E6%A0%BC%E6%96%87-%E8%A4%AA%E9%99%A4%E6%AD%A6%E8%A3%9D)。




![2](https://i.meee.com.tw/R1Tps2J.png)
> ● **[究極](https://scryfall.com/card/fin/38/ultima)：** 
> 消滅所有神器和生物。結束本回合。
> ● **[致命掩蓋](https://scryfall.com/card/mkm/83/deadly-cover-up)：** 
> 你可以搜證6，以作為施放此咒語的額外費用。
> 消滅所有生物。如果已搜證，則從對手的墳墓場中放逐一張牌。然後從其擁有者的墳墓場、手牌及牌庫中搜尋任意數量具該名稱的牌，並將它們放逐。該玩家洗牌，然後每以此法從其手上放逐一張牌，其便抽一張牌。

那麼解場就真的拿運土毫無辦法了嗎？ 倒也不是，還是有些去除能夠根治運土的。

究極在掃場後會立刻結束本回合，這代表所有堆疊會清空，等待上堆疊的異能也不會上堆疊了，所以運土的回場觸發式異能會直接蒸發。

> 延伸閱讀：[「結束本回合」是甚麼意思？](https://guildmagesforum.tw/What-does-End-this-Turn-Mean/)

而搜證後的致命掩蓋，掃場後放逐對手墳場的一張牌，這是一個完整的動作，中間沒有任何回應點，假設對手運土了一塊基本樹林，你在致命掩蓋掃場後，可以選擇放逐對手墳場的基本樹林，並將墳場、手牌、牌庫的所有同名牌全部放逐，致命掩蓋結算後才輪到運土，由於基本樹林是進入墳場導致運土觸發的，因此運土會嘗試從墳場尋找那張基本樹林，但是它已經不在墳場裡了，所以運土是救不回來的。




![3](https://i.meee.com.tw/RhHsYuS.png)
> ● **[晃動大地](https://scryfall.com/card/eoe/258/stomping-ground)：** 
> 地～山脈／樹林
> ● **[勤奮的動物管理員](https://scryfall.com/card/tla/171/diligent-zookeeper)：** 
> 對每個由你操控的非人類生物而言，它每有一個生物類別，便得+1/+1，每個生物最多計入10種生物類別。

假設我有一塊晃動大地（紅綠電震地）因運土成為生物，那麼它會因為自己有山脈＆樹林2個類別，而被動物管理員+2/+2嗎？

答案是不會，運土雖然會賦予生物類別，但並不會賦予生物副類別 <font color="#A6A6A6">（以往這類效應常常給的元素之類的類別，完全不給生物類別確實挺罕見的）</font> ，山脈＆樹林都是地的類別，而不是生物的，因此動物管理員不會提供任何加成。




![4](https://i.meee.com.tw/9rNT6G1.png)
> ● **[永固城](https://scryfall.com/card/tla/266/ba-sing-se)：** 
> {2}{G},{T}：運土2。只能於巫術時機起動。
> ● **[不息小屋](https://scryfall.com/card/woe/258/restless-cottage)：**
> {2}{B}{G}：不息小屋成為4/4，黑綠雙色的驚懼獸生物直到回合結束。它仍然是地。
> 每當不息小屋攻擊時，派出一個食品衍生物，並將至多一張目標牌從墳墓場放逐。

WOE、LCI的變身地都與運土有不錯的搭配，因為這些地牌只要攻擊就能觸發異能，即使不是因為自己的起動式異能成為生物也無訪。

假設目前不息小屋被運土2，成為一個2/2生物，攻擊時就能觸發放逐墳場＆生食品的異能，如果你希望能打出更高的傷害，那麼也能瞬間時機起動不息小屋自身的變身異能，把基礎體格從0/0變為4/4，算上+1/+1指示物就是個6/6的生物了。

| 5 |  | 成為黑綠雙色 |
| 6 | 具敏捷異能 |  |
| 7B | 成為0/0 | 成為4/4 |

> ● **[永固城](https://scryfall.com/card/tla/266/ba-sing-se)：** 
> {2}{G},{T}：運土2。只能於巫術時機起動。
> ● **[魂石庇護地](https://scryfall.com/card/fdn/133/soulstone-sanctuary)：** 
> {4}：此地成為3/3，具警戒異能和所有生物類別的生物。它仍然是地。

從上一案例中，我們可以看到運土的成為0/0、以及變身地自己的成為N/N，同屬[7B層](https://guildmagesforum.tw/Layer/#%E5%B1%A47b%EF%BC%9A%E8%A8%AD%E5%AE%9A%E5%8A%9B%E9%87%8F%E3%80%81%E9%98%B2%E7%A6%A6%E5%8A%9B%E7%82%BA%E6%8C%87%E5%AE%9A%E6%95%B8%E5%80%BC)的設定攻防值效應，當有複數的效應同時打算在7B層修改基礎攻防值時，則要比較兩個效應的[時間印記](https://guildmagesforum.tw/What-is-Time-Stamp/)，說白了就是後來的蓋過先來的。

假設有個魂石庇護地已經起動過自身異能，讓它成為3/3警戒生物了，這時你再對它做運土2，則它反而會變成0/0且具有2個+1/+1指示物的生物。當然你也可以再起動一次魂石庇護地的變身，這樣就是3/3有2個+1/+1指示物的5/5敏捷警戒生物。

| Layer | 運土2 | 魂石庇護地 |
| :-: | :-: | :-: |
| 4 | 獲得生物類別 | 獲得生物～所有生物類別 |
| 6 | 具敏捷異能 | 具警戒異能 |
| 7B | 成為0/0 | 成為3/3 |
| 7C | 2個+1/+1指示物 |  |





{% mtgpick "xln" 55 %}
> ● **[攝魂旋律](https://scryfall.com/card/xln/55/entrancing-melody)：** 
> 獲得目標魔法力值為X的生物之操控權。

終於來到重頭戲了，當玩家A運土了一個由他操控的地，之後玩家B獲得了這個地生物的操控權，當這個地生物死去時，究竟會回到誰的場上？ 先讓我們回頭複習一下運土的CR是怎麼寫的：

- 701.66a 「運土N」意指「目標由你操控的地成為0/0，具敏捷異能的地生物，且仍具有原本類別。在其上放置N個+1/+1指示物。當該地死去或進入放逐區時，將它在 **<font color="#FF0000">你的</font>** 操控下橫置移回戰場。」

所以這裡的關鍵，就是 **「你」** 究竟是如何被定義的？ 首先要再次強調，運土的讓地回場的效應，是一種 **<font color="#FF0000">延遲觸發式異能</font>** ，這一點非常重要，因為身為延遲觸發式異能這一分類，直接決定了它適用哪條規則。先讓我們看看規則原文是如何定義  **「你」** ：

- 109.5. 物件上的「你」和「你的」意指該物件的操控者、它即將的操控者（如果玩家正試圖施放或起動它）或其擁有者（如果它沒有操控者）。靜止式異能的操控者為其所在物件的當前操控者。起動式異能的操控者為起動該異能的玩家。觸發式異能的操控者為觸發該異能時該物件的操控者， **<font color="#FF0000">除非該異能為延遲觸發式異能。延遲觸發式異能的操控者，請參閱603.7d-f</font>** 。
- 113.7. 一個的異能的來源為創造該異能的物件。對於堆疊上的起動式異能，其來源為被起動該異能的物件。對於堆疊上的觸發式異能 **<font color="#FF0000">（除延遲觸發式異能外）</font>** 或已經觸發而正在等待進入堆疊的異能，其來源為被觸發異能的物件。 **<font color="#FF0000">決定延遲觸發式異能的來源，參見規則603.7d-f</font>** 。

可以發現大多情況下 **「你」** 的定義都十分簡單，然而牽涉到延遲觸發式異能時，狀況就會變得些許複雜，需要轉到專門定義延遲觸發式異能的章節做補充說明，而延遲觸發式異能是這樣定義異能的操控者的：

- 603.7d 由咒語創造的延遲觸發式異能的來源為該咒語。此延遲觸發式異能的操控者與創造它的咒語結算時該咒語的操控者相同。
- 603.7e 如果一個起動式或觸發式異能創造了延遲觸發式異能，則該延遲觸發式異能的來源與創造它的異能來源相同。此延遲觸發式異能的操控者與創造它的異能結算時該異能的操控者相同。

也就是說，運土的延遲觸發式異能的操控者，就是當初執行運土異能的A玩家，之後這塊地不管是在A還B的操控下死去，都會回到A的場上。


{% folding blue :: 關於官網初版機制文的錯誤介紹 %}

實際上對於運土的地發生操控權轉移後死去，會回到誰場上這個問題，甚至連官方的[TLA機制介紹文章](https://magic.wizards.com/en/news/feature/avatar-the-last-airbender-mechanics)一開始都介紹錯了，最開始官網的寫法是：在誰的操控下死去就回到誰場上。

![官網初版規則文](https://i.meee.com.tw/77y8uT4.png)

好在這個問題很快的就被發現了，作者也有為此發了篇[機制澄清公告](https://x.com/fireshoes/status/1991191535807812028?t=nRwKLXOcJJgpTk7I_d5uSQ&s=19)，並立即修改了文章，現行文章內的介紹已是符合正確規則的描述。

{% endfolding %}

由此還可以衍伸出一個進階問題，假設同樣是玩家A運土了一塊地後，玩家B獲得了這塊地的操控權，之後B也對這塊地做了一次運土，那麼當這塊地死去時，會回到誰的場上？ 

實際上當這個地生物死去時，A與B玩家各自操控的觸發式異能都會上堆疊，所以關鍵是現在是誰的回合？ 多個觸發式異能同時被觸發時，上堆疊的順序流程為：主動玩家的先上堆疊，再來才是被動玩家的上堆疊，這也代表被動玩家的異能會先結算。所以假設目前是A的回合，那就是A的異能先上堆疊、B的異能後上堆疊，B的異能會先結算，因此這塊地最後在B的操控下進場。




{% mtgpick "rvr" 55 %}
> ● **[偽體擬形](https://scryfall.com/card/rvr/55/quasiduplicate)：** 
> 派出一個衍生物，此衍生物為目標由你操控的生物之複製品。

當一塊地被運土變成生物後，使用偽體擬形派出一個這個地生物的複製品Token，那麼這個Token會有生物類別嗎？

其實這個問題就跟複製一般的變身地、載具是一樣的意思，複製效應最高只會看到Layet第1層的可複製特徵而已，而運土的類別、異能、攻防變化，都是在Layer更高層做修改，這些並不是複製效應能夠複製的內容，所以你派出的就是一個這塊地的原版複製品Token。

老實說這題跟下面那題已經跟運土沒什麼關係了，只是一個會運土的達芙引發的問題，不過這題十分有趣，所以還是分享給各位。

目前我同時操控治金師始祖達芙＆遭囚太陽（宣言綠色），之後橫置了一塊樹林產出綠色魔法力，這會引發甚麼後果？

首先遭囚太陽的效果，是一種觸發式魔法力異能，會因為你起動樹林的魔法力異能而觸發，並且因為自己也是魔法力異能，因此是不使用堆疊直接生效的。

- 605.1b 如果一個觸發式異能符合以下所有條件，則它屬於魔法力異能：不需要目標（參見規則115.6）、因起動式魔法力異能的啟動或結算、或因魔法力加到玩家的魔法力池中而觸發（參見規則605.1a）、且在結算時可以加魔法力到玩家的魔法力池中。

然而產出第一點額外的綠色法力後，有趣的就來了，遭囚太陽現在是張地牌，而遭囚太陽因觸發式魔法力異能產出額外一點綠色法力這一事件，又再度滿足了自己的魔法力異能觸發條件。

恭喜你！ 你成功做出了無限Mana Combo，只是這之中有億點小問題，是這個不可控的無限循環動作，遭囚太陽會無限的因為自己的魔法力異能，觸發新的魔法力異能，沒有任何停下的辦法，因此這盤遊戲會以平手收場。

- 104.4b 若一盤沒有使用限制影響範圍模式的遊戲（包括雙人遊戲）中出現了強制動作組成的“循環”，重複一系列事件且無法停止，此盤遊戲為平手。若循環中包含可選擇的動作，便不會導致平手。

這個無限Loop最厲害的地方就在，它甚至全程不使用堆疊，並且也沒有玩家有機會獲得優先權，施放咒語的機會自然是完全沒有，哪怕是[非瑞克西亞祭壇](https://scryfall.com/card/2x2/311/phyrexian-altar)這種以犧牲生物為起動費用的魔法力異能也無法中斷，雖然魔法力異能可以在很多特殊的時機起動，但也不是毫無限制的，只是允許起動的時機比較多而已，然而此情境中沒有任何讓你起動魔法力異能的時機。

- 605.3a 每當玩家持有優先權時、每當他施放一個要求支付魔法力的咒語或起動一個要求支付魔法力的異能時、或每當規則或效應要求支付魔法力，即使處於施放或結算咒語/起動或結算異能的中途時，玩家可以起動一個起動式魔法力能。

> ● **[萬生噬獸依格拉](https://scryfall.com/card/blb/241/ygra-eater-of-all)：** 
> 其他生物都是食品神器，仍具有原本類別，且具有「{2},{T},犧牲此永久物：你獲得3點生命。」
> ● **[治金師始祖達芙](https://scryfall.com/card/tla/247/toph-the-first-metalbender)：** 
> 由你操控且非衍生物的神器均額外具有地此類別。（它們不會獲得{T}產生魔法力的異能。）
> ● **[紅月賢者](https://scryfall.com/card/tsr/175/magus-of-the-moon)：** 
> 非基本地都是山脈。

當依格拉、達芙、紅月賢者三者同時在場時，場上的生物、神器都會變成怎樣？ 這三者的進場順序會影響結果嗎？ 

先讓我們分析一下這三者的效應是如何運作的：

| Layer | 依格拉 | 達芙 | 紅月賢者 |
| :-: | :-: | :-: | :-: |
| 4 | 生物額外是神器～食品 | 神器額外是地 | 非基本地是山脈 |
| 6 | 具有犧牲自己補血異能 |  |  |

可以發現這三者都是作用於同一層，也就是Layer第4層的類別改變效應，雖然一般來說多個效應作用於同一層時，會比較它們之間的[時間印記](https://guildmagesforum.tw/What-is-Time-Stamp/)來決定生效順序，然而這題稍微複雜一點，因為適用一個效應後會改變另一個效應的生效對象，這代表這些效應間有[從屬關係](https://guildmagesforum.tw/What-is-Dependency/)，這會強制決定這些效應的生效順序。

- 613.8. 在一個層或副層中，有時會使用從屬系統來決定效應生效的順序。如果存在從屬關係，它將覆蓋時間印記系統。
- 613.8a 如果一個效應（a）與另一個效應在同一層（或副層）中生效；（b）生效的順序將改變第一個效應的敘述或存在、改變它將生效的對象、或改變它將生效的內容；以及（c）這兩個效應都是或都不是特徵定義異能，則第一個效應「從屬於」第二個效應。否則，這兩個效應不從屬於彼此。

簡單來說，因為先適用了依格拉的 「生物額外是神器」 效應後，會讓達芙的 「神器額外是地」 效應作用對象發生變化，兩者因此構成從屬關係，無論依格拉＆達芙的時間印記先後，兩效應的作用順序會被強制修改為：先處理依格拉的 「生物額外是神器」 → 再處理達芙的 「神器額外是地」 ，後面達芙與紅月賢者的互動也是同理。

最終除了依格拉因為不改變自己類別而逃過一劫外，其他由你操控的生物＆神器，都會額外獲得神器、地～食品、山脈類別，因為紅月賢者成為山脈的效應，失去所有原有異能，並獲得山脈的 「{T}：加{R}」，連達芙和紅月賢者都不例外。另外就是…… 依格拉賦予食品類別時，一同獲得的 「{2},{T},犧牲此永久物：你獲得3點生命。」 這條異能還留著…… 

![Final](https://i.meee.com.tw/OhaTWFq.png)

不過這可不是甚麼食品類別自動賦予的異能，別跟基本地類別賦予產對應顏色法力的異能搞混了，食品這個類別在場上本身沒有任何特殊的規則效力，只是如果有效應讓你派出一個食品Token時，食品這個詞就自帶以下定義：

- 111.10. 一些效應指示玩家派出預定義衍生物。這些效應使用以下的定義來決定其派出時的特徵。派出預定義衍生物之效應也可能修改預先定義的特徵，或對其附加其他特徵
- 111.10b 食品衍生物是具有「{2}，{T}，犧牲此衍生物：你獲得3點生命。」的無色食品衍生神器。

所以為何唯獨犧牲自己補血的這條起動式異能被保留下來了？ 原因在於依格拉的效果同時影響了Layer的第4層與第6層，而當一個效應會同時影響多層時，只要開始作用於某一層，這效應影響的其他層也會確定生效，即使在處理Layer的過程中這個效應被紅月賢者移除了也一樣。

- 613.6 如果一個效應將在多個層 / 副層中生效，效應的各個部分分別在它們對應的層中生效。如果一個效應開始在一個層 / 副層中生效，它將繼續對同樣的物件在其他適用的層 / 副層中生效，即使產生該效應的異能在此過程中被移除。

> 其實這一題大致可以看成[腥紅之月+荒野之魂艾莎婭](https://guildmagesforum.tw/Layer/#%E8%85%A5%E7%B4%85%E4%B9%8B%E6%9C%88-%E8%8D%92%E9%87%8E%E4%B9%8B%E9%AD%82%E8%89%BE%E8%8E%8E%E5%A9%AD)的複雜度升級版，最後處理血月類效應那段是完全一樣的邏輯，只是前面參與規則互動的原件數更多了，並且依格拉額外貢獻了一個食物的分支問題。本文只是簡單介紹的最終結果，更多有關Layer的運作原理，可參閱文章：[Layer：持續性效應的互動](https://guildmagesforum.tw/Layer/)。

## 結語

運土是一個非常強力的機制，可以看做是[醒轉](https://scryfall.com/search?q=oracle%3AAwaken+%28game%3Apaper%29+set%3Abfz+prefer%3Abest&order=set&as=grid)的超級強化版，看的出來官方設計讓運土的地被解掉時能重新回場，是想改善以往醒轉會被炸地的痛點，尤其運土的設計是在遊戲前中期就會執行的，這時如果被炸地可能跟直接輸掉沒兩樣，為了不讓新機制變笑話，就只好這樣加保護了。

雖然立意能夠理解，不過這麼一加，反而讓運土獲得了各種組合技潛力，例如標準內就可以玩[北方家的賞金獵人](https://scryfall.com/card/tla/209/beifongs-bounty-hunters)+[可怖血妖](https://scryfall.com/card/dft/77/bloodghast)+[免費犧牲源](https://scryfall.com/card/eoe/123/umbral-collar-zealot)，配上一個[痛血沙漠](https://scryfall.com/card/dft/77/bloodghast)或其他無限Loop的致勝出口。

![Combo](https://i.meee.com.tw/pwp7X0d.png)

此外既然地死去會回來，那麼[克撒傳](https://scryfall.com/card/mh2/259/urzas-saga)或各種原本以犧牲自己為代價做一次性利用的地，也能玩出不少花活。

![Land](https://i.meee.com.tw/v9OmFpq.png)

個人對於運土的綜合評價是，這是個非常有趣且實用的機制，但也是個風險很大的機制，設計稍有不慎其實滿容易玩壞的。不過目前討論風聲最大的[獾地鼠幼獸](https://scryfall.com/card/tla/167/badgermole-cub)，我反而覺得主要問題不在運土上，畢竟把一個不是傳奇且進場自帶Mana頭的[季寧](https://scryfall.com/card/iko/192/kinnan-bonder-prodigy)，印在一個已經有[羅堰妖精](https://scryfall.com/card/fdn/227/llanowar-elves)的環境內，光這這一點怎麼看就太瘋狂了。

{% mtgpick "iko" 192 %}

雖然從這次世界賽、以及近一周的Meta的統計來看，[獾地鼠幼獸](https://scryfall.com/card/tla/167/badgermole-cub)套牌的使用率與勝率都開始有抑制跡象，或許現在的標準環境確實有能夠消化這傢伙的能力，但我認為這個適應成本依舊是極高的，畢竟當具有極端unfair超展開的套牌成為環境主流時，其餘套牌也勢必要往極端化發展，要嘛極端快、要嘛極端控、要嘛遊戲計畫有著一般套牌難以互動的特殊模式，而fair中速消失，環境主流都是極端偏向的套牌時，通常就是禁卡表出動前的最後掙扎了。

近期的標準還處於不斷有驚喜的動盪階段，到底TLA帶來的影響最終會如何收斂，目前還難以預測，但標準賽制以unfair套牌主導環境時，目前的歷史可以說是一炸再炸，還是希望老威能夠在設計新牌時，稍微思考一下這個主動計畫有多少可有效互動的空間。
