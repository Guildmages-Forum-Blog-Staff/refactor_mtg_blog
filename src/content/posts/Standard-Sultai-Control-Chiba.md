## 前言

大家好，我是子丞，那個[只打蘇勒台的偏執玩家](https://guildmagesforum.tw/Standard-Sultai-Midrange/)。近期我在 MIT 12 與千葉的 Spotlight 分別拿下第 9 名與第 64 名的成績，因此想藉這篇文章分享這次所使用的套牌心得。我會說明整副牌的組牌邏輯、實際使用後特別喜歡的單卡，以及我認為比較好打的對局。由於網路上關於這套牌的資料較少，很難找到夠準確的統計數據作為參考；但如果你想嘗試 4C、潔斯凱以外的控制類型，不妨參考看看。

## 套牌構成

![](https://i.meee.com.tw/sIi6qyD.webp)
[蘇勒台控制_MIT#12](https://melee.gg/Decklist/View/ed25229f-83b4-42a2-9ba3-b4520027dbc9)

![](https://i.meee.com.tw/4itJ2ub.webp)
[蘇勒台控制_千葉 Spotlight](https://melee.gg/Decklist/View/6f2b2b0b-bdfd-4ca4-b016-b457011f7235)

現在環境內的蘇勒台控制大致可分為兩種：一種是以 {% mtglink "Superior Spider-Man" %} 、{% mtglink "Deceit" %} 與 {% mtglink "Wistfulness" %} 為首的價值生物體系；另一種則是以 {% mtglink "Professor Dellian Fel" %} 為首的純控體系。在《洛溫：闇影籠罩》（[ECL](https://scryfall.com/sets/ecl)）登場的呼魂元素，很快就成為多數蘇勒台控制玩家的選擇 —— 萬能的棄牌、強大的體格，加上四費蜘蛛人「再做一次」時既能解場又能站場，這些都是非常吸引人的要素，也是目前最常見的構築類型。
而我選擇的，卻是另一條更傳統的路線：

**以大量抽濾、解牌、搭配少量終結者的 draw-go 型控制。**

這個體系之所以還有競爭力，多虧了斯翠海文的秘密（SOS）推出的旅法師 {% mtglink "Professor Dellian Fel" %} 。

{% mtgcard "Professor Dellian Fel" %}

在這個強度通膨、異能越來越複雜的年代，他卻罕見地擁有如此樸素的異能：補血、抽牌、消滅生物，以及一個足以致勝的徽記。效果看似簡單，卻完美補齊了一副控制套牌最需要的所有元素。
- 過去「活不下來」的問題，靠補血就能讓玩家多出好幾回合的餘裕去尋找解牌；
- 消滅生物也是控制最常使用的手段；
- 而最厲害的，仍是那個徽記。它不僅與旅法本身的邏輯自洽，也讓現在的蘇勒台控制幾乎都會帶上 {% mtglink "Ancient Cornucopia" %} —— 這張早期被大量使用、後來卻逐漸被遺忘的 Mana 石。

{% mtgcard "Ancient Cornucopia" %} 

過去 {% mtglink "Ancient Cornucopia" %} 雖然能提供穩定的法力源與拖延時間的血量，卻有著無法帶來牌張優勢、也無法獲勝的缺點；如今這個問題因為旅法的徽記而出現了質變。與 4C 控制的策略相同，它能在解場的同時，透過額外的傷害持續削減對手血量；只要徽記開過一次，後續完全可以靠各種咒語附帶的補血，活活把對手痛死。這也正是現在純控打得起來的原因。

### 解牌區

![](https://i.meee.com.tw/2CSpzKv.jpg)

{% mtglink "Requiting Hex" %} 、 {% mtglink "Shoot the Sheriff" %}、 {% mtglink "Bitter Triumph" %} 是應對環境內快攻所必備的瞬間解。由於預估環境仍以伊捷靈技佔大宗，面對對手回合場面會快速膨脹的情況，還是需要大量瞬間解才能讓自己活下來。而 {% mtglink "Witherbloom Charm" %} 用途與備牌的 {% mtglink "Pawpatch Formation" %} 類似，針對伊捷靈技可以除去主要的生物威脅，也可以中斷 {% mtglink "Stormchaser's Talent" %} 及 {% mtglink "Boomerang Basics" %} 的搭配；面對瑪爾都棄牌也能處理 {% mtglink "Cool but Rude" %} 。相對其他去除來說雖然犧牲了射程，但換來的是必要時可以拿來抽牌與補血，配合 {% mtglink "Professor Dellian Fel" %} 的徽記也能快速斬殺。

![](https://i.meee.com.tw/ZlFudeQ.jpg)

{% mtglink "Duress" %} 、{% mtglink "Intimidation Tactics" %} 各帶一張。出於個人習慣，我喜歡在主牌放入少量掉手牌咒語；但這副牌既不是組合技、也不是節奏套牌，帶太多來護航主計畫的效益並不高，因此各只投入一張。

{% mtglink "Maelstrom Pulse" %} 是我認為目前環境內最好用的解牌之一。現在環境有大量非生物的獲勝手段，如 {% mtglink "Monument to Endurance" %} 、 {% mtglink "Cool but Rude" %} 、 {% mtglink "Stormchaser's Talent" %} 等，也有許多會製造衍生物或複製品的生物；儘管它是巫術、又要 3 費，但只要能一次解到兩張以上，就是非常有價值的一張解牌。退一步說，它最差也能幫你處理掉那些討厭的旅法，例如 {% mtglink "Professor Dellian Fel" %} 、 {% mtglink "Ral, Crackling Wit" %} 與 {% mtglink "Kaito, Bane of Nightmares" %} 。
掃場方面，我選擇 {% mtglink "Day of Black Sun" %} ，看中的是它能處理一些帶不滅的生物，當然這部分可以依環境調整；而 {% mtglink "Withering Curse" %} 在靈技偏多的環境是個不錯的小型掃場，只是若要完整發揮，補血來源的數量恐怕得再多一些才行。

### 抽牌區

![](https://i.meee.com.tw/RBzq3DQ.jpg)

{% mtglink "Consult the Star Charts" %} 與 {% mtglink "Rakshasa's Bargain" %} 可說是現在環境內最好的抽牌咒語（另外還有一張 {% mtglink "Stock Up" %} ，但因為 {% mtglink "Rakshasa's Bargain" %} 剛好色組正確、又是瞬間，所以我選擇了它）。低費時它們能幫你找到解牌或地牌，高費時則能幫你找到獲勝手段。

### 威脅區

![](https://i.meee.com.tw/N6b1D9i.jpg)

{% mtglink "Emeritus of Abundance" %} 不論哪個版本我都會投入兩張，它也是這次斯翠海文的秘密中我非常喜歡的一張生物。3 費 3/4 警戒的優秀體質，能擋下大部分 3 費以下的生物，需要進攻時也不必擔心被反打。花 2 費就能撿回墳場任一張牌的效果，讓它在控制套牌裡有許多好目標；後期地牌充足後更能持續施放，確保了後期的資源量。

{% mtglink "Professor Dellian Fel" %} 的強大前面已經提過，這裡不再贅述；但除了檯面上的功能，他的「體格」也是隱性的強大優勢。4 費進場時選擇 +2、補 3 點血，忠誠指示物一瞬間就來到 7 點——如果對手不是靠解牌、而是想用生物把他處理掉，等於實質上多給了你 10 點的血量優勢，而且大多數時候，對手光靠場上的生物還不一定能在當回合解掉他。之後每回合 +2 忠誠，讓我想起 {% mtglink "Oko, Thief of Crowns" %} 那個生物戰惡夢般的存在：打也不是、不打也不是。

剩下則是一些見仁見智的選擇。

1. {% mtglink "Wan Shi Tong, Librarian" %} ：可說是控制套牌的常客，當你不知道該放誰時，放它總是不會錯。能抽牌、施放時機靈活，又能很好地阻擋對手，都是很優秀的特點；只是它的目標太少，常常一進場就成為對手殺牌的固定目標，而你又會希望後期一直扣著它，因此實際上的施放時機反而沒那麼靈活。

2. {% mtglink "The Dawning Archaic" %} ：MIT 12 時我最喜歡的一張牌。由於套牌的巫術與瞬間總量高達 27 張，實際上很容易在 4 費內就叫出來；優秀的體格再加上延勢，往往讓對手一時之間無法突破，攻擊後的觸發異能也能穩定累積優勢。雖然後來我改使用另一張，暫時沒把它放進套牌，但我仍認為它非常值得一試！

3. {% mtglink "Overlord of the Hauntwoods" %} ：它其實對應的是 {% mtglink "Ancient Cornucopia" %} 的位置。最初我在網路上看到一副套牌選擇了 4 張 {% mtglink "Overlord of the Hauntwoods" %} 搭配 4 張 {% mtglink "Emeritus of Abundance" %} ，雖然同樣是加速，但它額外提供的地牌能幫助 {% mtglink "Emeritus of Abundance" %} 更快達到再備法的門檻，與 {% mtglink "Consult the Star Charts" %} 的相性也很好，可以加深濾牌的深度。加上它本身是生物，後期單抽到時的效益也比 Mana 石更好。權衡之下，我最後讓兩者各帶兩張。

4. {% mtglink "Together as One" %} ：我把它放進威脅區，是因為它很多時候不只是單純的解牌——配合旅法的徽記，單張就能造成 10 點傷害，讓我快速取勝。它可說是這次比賽中我最喜歡的單卡，也是本次的 MVP。靠著這次新出的地牌 {% mtglink "Great Hall of the Biblioplex" %} ，以及牌組內的四張五色 Mana 石（我把 {% mtglink "Overlord of the Hauntwoods" %} 派出的 Everywhere Token 也算進去），讓我這副 3 色套牌也有機會打出 5 色咒語。6 費造成 5 點傷害、補 5 點血、抽 5 張牌，解場、資源、時間三者一次滿足；有非常多場比賽我都是單靠這一張牌逆轉戰局，可說是非潔斯凱色組版本的 {% mtglink "Jeskai Revelation" %} 。

### 備牌區

備牌大致都是常規的解牌選擇：針對地落體系與四色控制的 {% mtglink "Flashfreeze" %} 、針對底密爾惡魔的 {% mtglink "Disdainful Stroke" %} ，以及墳場仇恨用的 {% mtglink "Ghost Vacuum" %} 與 {% mtglink "Strategic Betrayal" %} 等。其中比較特別的是 {% mtglink "Pawpatch Formation" %} 。無論是俄佐立閃現的 {% mtglink "High Noon" %} 與大量飛兵、瑪爾都棄牌的 {% mtglink "Hardened Academic" %} 與 {% mtglink "Cool but Rude" %} ，或是伊捷靈技的 {% mtglink "Slickshot Show-Off" %} 、與 {% mtglink "Stormchaser's Talent" %} ，它都能有效處理，因此是一張適用範圍非常廣的解牌。

## 對局分析
在千葉 Spotlight 中，我的戰績如下：
- R1　2-0　伊捷靈技
- R2　2-1　瑟雷尼亞地落
- R3　2-0　伊捷靈技
- R4　2-1　鐵木爾全知全能
- R5　1-2　蘇勒台控制（蜘蛛人 {% mtglink "Deceit" %} 版本）
- R6　0-2　純綠地落
- R7　2-1　波洛斯快攻
- R8　2-0　五色 Allies
- R9　0-2　底密爾惡魔
- R10　2-1　伊捷靈技
- R11　0-2　四色全知全能
- R12　0-2　瑟雷尼亞放豆
- R13　2-0　純綠地落
- R14　2-1　瑪爾都棄牌
- R15　2-0　伊捷 Spellelemental

最終拿下 10 勝 5 敗的成績。五場落敗分別輸給蘇勒台控制、純綠地落、底密爾惡魔、四色全知全能與瑟雷尼亞放豆；而面對主流的伊捷套牌，則取得了四戰全勝的佳績。其中純綠地落與瑟雷尼亞放豆兩場失利，我認為未必完全反映對局本身的優劣。幾場關鍵局都受到起手調度影響，加上長時間賽程後精神狀態下滑，導致決策品質有所下降，因此我傾向將這兩場視為比賽中的個別因素，而非套牌結構上的劣勢。

可以看出，這副套牌最擅長的就是與生物套牌周旋。無論是快攻還是中速，各種維度的解牌、穩定的回血能力、深度充足的抽濾，以及近乎無窮的後期資源，都讓它在長局中擁有極強的壓制力。

### 對生物套牌的優勢

環境內最主流的套牌仍以生物戰為主：伊捷靈技、純綠或瑟雷尼亞地落、瑪爾都棄牌，還有這次沒對到、但預期會出現的俄佐立 MoMo、俄佐立閃現，或是帶有 {% mtglink "Badgermole Cub" %} 的各種綠底生物套牌。靠著大量低費又高效率的解牌搭配穩定回血，這類對局我認為大多能維持在 7:3 左右的優勢。以伊捷靈技為例，只要成功交換掉前兩波威脅，後續不論是 {% mtglink "Professor Dellian Fel" %} 還是 {% mtglink "Together as One" %} ，都能迅速把血量與資源差距拉開，因此大部分長局都相當有利。

在這些對局中，只要 {% mtglink "Together as One" %} 一結算，遊戲幾乎就結束了——血量與資源的差距會被瞬間拉開，對快攻來說尤其致命；而 {% mtglink "Professor Dellian Fel" %} 每回合的回血能力，也讓靈技類套牌湊不出足夠的資源來斬殺。這兩張可以說是本套牌面對生物套牌時最重要的核心牌張，也是大多數勝局的關鍵來源。

### 對組合技套牌的劣勢

但相對地，蘇勒台雖然對「場面上」的各種威脅都有應對手段，面對組合技這類能不斷在手上累積資源的套牌，卻幾乎沒有好的預防辦法；這類問題本來就是白色較擅長處理的領域，也是蘇勒台色組天生較難補足的弱點。
在沒有生存壓力的情況下，對手能非常從容地慢慢湊出獲勝手段。以四色全知全能為例，對手往往只要透過大量抽濾找齊組件，再趁場上有靈魂洞窟時，於六費的回合接連拍出 {% mtglink "Voice of Victory" %} 與 {% mtglink "Kona, Rescue Beastie" %} 。面對這種無法被反擊、又能立即形成致勝威脅的展開，這副套牌幾乎沒有有效的應對手段。

抑或是對上底密爾惡魔時，對手會主動用大量手牌破壞，先把我用來反制的牌清掉；等確認我擋不住後，再直接拍出 {% mtglink "Doomsday Excruciator" %} ，往往讓我措手不及。此外，牌組中大量的解牌與回血資源在這類對局裡價值相對有限，也註定了這個體系面對組合技套牌時較為劣勢。

如果未來想改善對底密爾惡魔、全知全能等套牌的勝率，我會建議在備牌放入像 {% mtglink "Stoic Sphinx" %} 這類能快速獲勝的威脅。由於正編已經帶有各種維度的解牌，我認為可以適度減少部分解牌數量，改放入不同維度的威脅。尤其在 Spotlight 這類未公開牌表的賽事中，這樣的配置往往能帶來更好的效果。

## 結語
這不是我第一次參加大獎賽，卻是我第一次打進第二天的賽程，甚至還拿到第 64 名、站上獎金圈。身為一個把身心都奉獻給蘇勒台的玩家，我很清楚自己不會是職業選手，也不會是個總能拿到好名次的人。更多時候，套牌的強度非常仰賴近幾個系列給的牌夠不夠強、有沒有剛好能湊在一起的主題，而這些都不是穩定會發生的條件。

不過，現在的標準環境改為 3 年輪替，加上大量 UB（聯名）系列把可用牌張擴充到前所未有的豐富，蘇勒台的可能性已經不可同日而語。過去像白藍、潔斯凱、艾斯波這些控制強勢色組，總能在每個環境拿到合適的組件；而非傳統控制色組的蘇勒台，往往整個系列只拿得到一兩張能投入實戰的牌。如今隨著牌池擴張，這個劣勢正逐漸縮小。因此，假如你也是個有信仰的玩家，不妨在現在的牌池裡，試著堅持自己一直以來最喜歡的色組。

儘管我每次參賽的套牌都不盡相同——標準環境會輪替、賽場的 meta 也瞬息萬變，甚至不必等新系列推出，玩家們就會開發出新的套牌——或許我沒辦法每次都復刻出那套成功的牌，但對我而言，我與牌組之間的羈絆從未中斷。它就像是我的忒修斯之船：零件全都換過了，但它始終是那艘陪我度過無數挑戰的船。
