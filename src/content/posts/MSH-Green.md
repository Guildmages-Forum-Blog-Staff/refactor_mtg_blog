漫威超級英雄（Marvel Super Heroes, MSH）將於2026年6月19日舉行售前賽活動，而於隔一週2026年6月26日正式發行，想更了解在限制賽的單卡評分與建議嗎？那就來看看這一系列的MSH限制賽介紹吧！

- 機制介紹請看這篇：[漫威超級英雄機制解析](https://guildmagesforum.tw/MSH-mechanism/)


## 評分內容

 
 {% mtgpick "MSH" 161 %}
 分數：3.0
 評語：體質還算及格，ETB提供的食物衍生物可以用來維持血線健康，珍寶衍生物則是調色跟跳費都好用，很不錯的曲線生物。
        
 
 {% mtgpick "MSH" 162 %}
 分數：2.5
 評語：黑綠的主題是檢查墳場的生物數量，黑色的Villain們時籌謀也會棄牌進墳場，可以在中後期回收前期棄的牌、被解掉的強力單卡甚至撿地牌，選項很靈活但不能重複選稍嫌可惜。
        
 
 {% mtgpick "MSH" 163 %}
 分數：3.0
 評語：可以提供可觀的體質，解完任務給生物不滅更是強力的效果，本系列的找地咒語並不多，乖乖下地吧！
        
 
 {% mtgpick "MSH" 164 %}
 分數：3.0
 評語：體質在攻擊端毫無亮點，但6點的防禦在本系列非常夠用，作為功能性單卡還可以投身防守能減輕不少血量壓力。額外放豆的異能在藍綠色組是不可無視的威脅，在白綠色組也可以支援Hero主題。
        
 
 {% mtgpick "MSH" 165 %}
 分數：3.5
 評語：看牌庫頂八張非常地深，支付Teamwork後的效果更是極為強力，一張單卡就可以拉開場面的差距。但是橫置五攻在限制賽不算間單，並且還是有隨機成分，因此扣了一點分數。
        
 
 {% mtgpick "MSH" 166 %}
 分數：3.0
 評語：不可多得的強大解牌，選項不一定要選同一隻生物，相當靈活。後續喊打還可以逼對手面臨吃傷害或用生物進行交換的窘境。
        
 
 {% mtgpick "MSH" 167 %}
 分數：2.5
 評語：就是一張純加體質的戰鬥詭計，不過不失。本系列的體質普遍不大，+3/+3的差距更為顯著。
        
 
 {% mtgpick "MSH" 168 %}
 分數：2.5
 評語：純綠C卡位唯一解牌，Teamwork 3很容易達成，就算不做Teamwork也是張及格的互鬥。
        
 
 {% mtgpick "MSH" 169 %}
 分數：2.5
 評語：非常理想的曲線填充生物，本系列飛行生物數量不少，2/2的體質足夠嚇阻一部分空中威脅。起動式異能則可以干擾對手的武具主題甚至破壞對手的邪惡計劃（Plan）！
        
 
 {% mtgpick "MSH" 170 %}
 分數：3.0
 評語：效果很厲害，讓對手無法把場面解乾淨，但指定色重的缺點也明顯。
        
 
 {% mtgpick "MSH" 171 %}
 分數：3.0
 評語：準時三費出的話是張白板，五費出則是4/4警界不滅敏捷的中堅生物，可以視手牌和場面決定施放的時機。
        
 
 {% mtgpick "MSH" 172 %}
 分數：3.5
 評語：除了這張以外，本系列會生食物衍生物的牌只有[Ant-Man's Army](https://scryfall.com/card/msh/161/ant-mans-army)一張，不過會回血的牌不在少數（尤其有進場回血的多色C卡地）在合適的構築可以快速滾起雪球。
        
 
 {% mtgpick "MSH" 173 %}
 分數：3.0
 評語：照著曲線拍生物的話加個兩三顆豆並非難事，在這系列超過四攻/四防就很夠用。警戒也可以和Teamwork單卡進行搭配，在造成傷害的同時支援Teamwork的額外費用。
        
 
 {% mtgpick "MSH" 174 %}
 分數：3.5
 評語：集資源、鋪場和體質成長於一身的超強單卡，多看牌庫頂一張的額外資訊量也能讓你調整當下的戰略。
        
 
 {% mtgpick "MSH" 175 %}
 分數：2.5
 評語：同樣是會成長的優秀曲線生物，自帶的踐踏異能在中後期能給對手施加壓力。放豆異能很容易觸發，也因此被加上了一回合一次的限制，瑕不掩瑜。
        
 
 {% mtgpick "MSH" 176 %}
 分數：3.0
 評語：也是張有體質成長和資源的好牌，本系列的負面指示物僅有[Jessica Jones, Private Eye](https://scryfall.com/search?q=set%3Amsh+O%3Astun&unique=cards&as=grid&order=name)的暈眩指示物一張，雖說是兩張U卡但仍是值得稍微留意的小配合。

        
 
 {% mtgpick "MSH" 177 %}
 分數：2.5
 評語：沒有[成形野地](https://scryfall.com/card/msc/240/evolving-wilds)這種單卡配合導致一回合僅能生一隻衍生物，鋪得太慢了，體質也很不好。
        
 
 {% mtgpick "MSH" 178 %}
 分數：3.0
 評語：四攻四防正是甜蜜點，加上延勢可以擋下幾乎所有飛行生物了。
        
 
 {% mtgpick "MSH" 179 %}
 分數：2.5
 評語：在限制賽大部分情況就是幫上+1/+1指示物，但巫術時機加上需要橫置導致使用上不靈活，放豆跟攻防只能選一項做。
        
 
 {% mtgpick "MSH" 180 %}
 分數：3.0
 評語：瞬間時機就是讚，減費的門檻很容易達成，甚至就算不達成也是張好牌。
        
 
 {% mtgpick "MSH" 181 %}
 分數：2.5
 評語：可以協助達成黑綠的墳場生物牌數量，在這炸彈為尊的系列也能助你找到你的強力永久物單卡。
        
 
 {% mtgpick "MSH" 182 %}
 分數：3.0
 評語：優秀的魔法力水槽，第一段變身的5防可以頂下大部分生物的攻勢。
        
 
 {% mtgpick "MSH" 183 %}
 分數：3.0
 評語：這是個多色友善的環境，因此調色單卡相當重要，何況這張卡在跳費/調色的同時還能拉回一點血量跟場面，穩定血線跟場面。生物被回應去除並不會導致整張咒語落空，請放心。
        
 
 {% mtgpick "MSH" 184 %}
 分數：2.0
 評語：起動費用過高導致節奏不好，而且一次磨四張牌庫消耗很快，就算有費用有節奏也不敢起動太多次。
        
 
 {% mtgpick "MSH" 185 %}
 分數：3.0
 評語：前面講過很多次這系列體質偏小，這張已經算是數一數二大的生物了，除非真的沒地牌或是有辦法撿回來，不然我會想留在手上等六費施放。
        
 
 {% mtgpick "MSH" 186 %}
 分數：2.5
 評語：死觸保底一換一，起動Power-up後的體質不亮眼。
        
 
 {% mtgpick "MSH" 187 %}
 分數：3.0
 評語：提供的魔法力可以供Power-Up使用，或是讓高稀有度的雙面牌翻面，當然還可以用來支付基本地循環的費用。兩點法力可以讓生物的Power-up的效率大大增加。
        
 
 {% mtgpick "MSH" 188 %}
 分數：3.0
 評語：這系列神器生物的比例蠻高的，可以用一張U卡解掉對手的高稀有度炸彈的同時站一張5/5延勢踐踏生物在場上簡直太完美了。
        
 
 {% mtgpick "MSH" 189 %}
 分數：2.5
 評語：費用太笨重了，如果在施放時被回應去除的話相當於是空過一回合，節奏有可能直接崩掉。
        
 
 {% mtgpick "MSH" 190 %}
 分數：3.5
 評語：同樣是體質數一數二好的生物，而且還有觸發條件簡單、成長幅度巨大的異能。
        
 
 {% mtgpick "MSH" 191 %}
 分數：2.5
 評語：閃現帶來很高的的靈活性，放豆的觸發也不算困難，不錯的填充生物。
        
 
 {% mtgpick "MSH" 192 %}
 分數：3.0
 評語：除了穿透異能外還提供了重要的體質成長，在平局時可以打出破口。
        
 
 {% mtgpick "MSH" 193 %}
 分數：3.5
 評語：唯一的缺點就是指定色太重，起動式異能的強度是指數級成長的，一個人可以結束遊戲的強力單卡。
        
 
 {% mtgpick "MSH" 194 %}
 分數：3.0
 評語：前期跳費中後期變成足以投入攻防的體質，變成所有生物類別可以配合到一些Hero相關主題。
        
 
 {% mtgpick "MSH" 195 %}
 分數：2.5
 評語：保底是5/5的警戒生物，把+1/+1指示物放在其他Hero的話則相當於6/6的體質，很不錯的高費曲線。
        
 
 {% mtgpick "MSH" 196 %}
 分數：3.0
 評語：六費可以帶來總共7/7的體質，衍生物的異能讓對手在宣告阻擋時需要多做考慮。
        
 
 {% mtgpick "MSH" 197 %}
 分數：4.0
 評語：進場可以免費施放一張紅色或綠色生物，至少不會虧到場面的節奏；第二章節給三個+1/+1指示物非常可觀，如果配合到帶穿透的生物更厲害；最後一章節可以造成大量傷害或是逼對手用場面跟你進行交換。
 值得注意的是如果雙面牌的背面是紅色或綠色的話是可以靠第一章節來施放，用[浩克](https://scryfall.com/card/msh/197/world-war-hulk)施放[浩克](https://scryfall.com/card/msh/49/bruce-banner-the-incredible-hulk)吧！

 
 ## 結語
 一寸長一寸強，在這體質普遍偏小的系列數值就是王道！
 綠色生物的強度比其他顏色強了很多，成長性也是各色組之最，很令人期待！
