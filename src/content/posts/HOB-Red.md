哈比人（The Hobbit, HOB）將於2026年8月7日舉行售前賽活動，而於隔一週2026年8月14日正式發行，想更了解在限制賽的單卡評分與建議嗎？那就來看看這一系列的HOB限制賽介紹吧！

- 機制介紹請看這篇：[哈比人機制解析](https://guildmagesforum.tw/HOB-Mechanism/)

## 評分標準

5.0：無條件必拿，能帶來幾近勝利的優勢
4.5：色組正確無條件必拿，能帶來大幅的優勢
4.0：有首選價值，與色組主題的相性極佳，能成為混色／轉色或進入色組的決定性牌張
3.5：系列頂 U、C 與其他強度夠的單卡，與色組主題相性佳，能成為進入色組的關鍵牌張
3.0：色組主題的重要單卡，以及其他高於平均值的單卡，會希望進到最終牌組
2.5：平均水準，通常是不錯的曲線填充物
2.0～1.0：低於平均，基本傾向不放，必要時可用來填充，但不宜過多
0.5～0.0：不可用，基本上別放，放了只會幫你輸

{% mtgpick "hob" 94 %}

{% mtgpick "hob" 101 %}

{% mtgpick "hob" 107 %}

分數：3.0
評語：加攻幅度很大，能讓小生物變成足以投入攻防的體質，進場異能調整手牌也很好用。

{% mtgpick "hob" 109 %}

評語：解場跟威脅一體的好牌。

{% mtgpick "hob" 111 %}

## 結語

紅黑的鬼怪囤兵跟紅白的矮人武具都是很具侵略性的主題，快攻玩家有福了！
鑒於這系列解牌貧弱，用快攻向對手發起衝鋒吧！天下武功唯快不破！
