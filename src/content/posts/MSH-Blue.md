漫威超級英雄（Marvel Super Heroes, MSH）將於2026年6月19日舉行售前賽活動，而於隔一週2026年6月26日正式發行，想更了解在限制賽的單卡評分與建議嗎？那就來看看這一系列的MSH限制賽介紹吧！

- 機制介紹請看這篇：[漫威超級英雄機制解析](https://guildmagesforum.tw/MSH-mechanism/)


## 評分內容

 
 {% mtgpick "MSH" 43 %}
 分數：2.5
 評語：一費具有穿透力的前期曲線，後期還能成長為更大的威脅。後期抽到時能配合 Power-up 六費下個飛行 4/4 也很不錯。
        
 
 {% mtgpick "MSH" 44 %}
 分數：2.5
 評語：身材偏小只有3/3，但進場會 connive 還算可以。Basic landcycling 讓它可以找出任意的基本地，作為調色手段很優秀。
        
 
 {% mtgpick "MSH" 45 %}
 分數：2.5
 評語：初始的防禦力只有2實在是太小了，大概要觸發長大兩次才划算，套牌主題有搭配到才考慮使用。
        
 
 {% mtgpick "MSH" 46 %}
 分數：2.0
 評語：叫一隻辟邪6/5或是彈最多兩個永久物都還可以，Teamwork 4 兩個都做能對場面造成很大影響，缺點就是費用太大了。
        
 
 {% mtgpick "MSH" 47 %}
 分數：3.0
 評語：這系列除了它之外只有另外兩張 Merfolk，領主效果幾乎可以忽略。而且只要 Merfolk 喊打（包含它自己）就能抽一張。
        
 
 {% mtgpick "MSH" 48 %}
 分數：2.5
 評語：二費1/3作為前期曲線不錯，後期還能 Power-up 放一個+1/+1指示物和抽兩張牌。後期抽到的話六費叫個2/4加上抽兩張牌也挺好用的。
        
 
 ![](https://i.meee.com.tw/FxK7IHg.png)
 分數：帶藍套牌4.0 // 紅綠套牌5.0
 評語：正面在帶藍套牌中是超級賺牌引擎，多餘的費用就可以用來抽牌。背面則是紅綠色組的超級炸彈，拍下來打兩拳基本上能直接贏下對局。
        
 
 {% mtgpick "MSH" 50 %}
 分數：2.0
 評語：很靈活的戰鬥詭計，防守上幾乎等於一費回四滴血再抽一張牌。
        
 
 {% mtgpick "MSH" 51 %}
 分數：2.0
 評語：警戒1/4的身材算是還能接受，可以複製自己生物來源的起動式異能或是觸發式異能，複製到僅能起動一次的 Power-up 就會滿賺的。
        
 
 {% mtgpick "MSH" 52 %}
 分數：3.0
 評語：五費叫兩隻會飛的生物很不錯。加上1/1的 token 生物只要攻擊就能刺探一，能讓後期的抽牌變得更好。
        
 
 {% mtgpick "MSH" 53 %}
 分數：3.0
 評語：全方位的能力都給一點，有+1/+1變大、有飛行能穿透、還有 ward 保護，算是不錯的武具。
        
 
 {% mtgpick "MSH" 54 %}
 分數：2.5
 評語：藍色優質的去除，除非對手有結界去除或是回手，否則該生物幾乎就是廢了。
        
 
 {% mtgpick "MSH" 55 %}
 分數：3.0
 評語：兩費進場抽一，之後能四費犧牲掉抽二，作為賺牌手段還是挺不錯的，還是個神器有主題能搭配。
        
 
 {% mtgpick "MSH" 56 %}
 分數：2.5
 評語：身材實在是太爛，可能要配合重置另一隻生物聯合阻擋做生物交換，不過有閃現在靈活度上算是還可以。
        
 
 {% mtgpick "MSH" 57 %}
 分數：2.5
 評語：2/3的身材能很好地擔任前期阻擋者，又可以產費為神器加速。
        
 
 {% mtgpick "MSH" 58 %}
 分數：2.0
 評語：不虧牌的戰鬥詭計，能瞬間變出一隻4/4來參與攻防。
        
 
 {% mtgpick "MSH" 59 %}
 分數：2.5
 評語：有飛行和警戒異能，可以一邊進攻消耗對手血量，還能一邊把牌庫頂的神器抽上手，在神器密度高的套牌可以持續賺牌。
        
 
 {% mtgpick "MSH" 60 %}
 分數：2.5
 評語：在神器套牌中有機會提早登場，本體飛行3/4算是及格，還能幫自己的非生物咒語減費。
        
 
 {% mtgpick "MSH" 61 %}
 分數：3.0
 評語：進場送一發彈回手，在節奏上很舒服。之後如果彈自己的東西回手的話還會變大，本身又有飛行能作為穿透的打點。
        
 
 {% mtgpick "MSH" 62 %}
 分數：4.0
 評語：四費的飛行4/5是很好的身材，之後還可以 Power-up 變大並多一回合。後期抽到直接就是八費叫飛行5/6再多一回合。無論何時都能對對手造成很大的壓力。
        
 
 {% mtgpick "MSH" 63 %}
 分數：2.5
 評語：如果有瞬間放+1/+1指示物的手段，就能讓自己的生物很難被去除。每個回合抽第二張牌時，也能讓它持續長大。
        
 
 {% mtgpick "MSH" 64 %}
 分數：4.0
 評語：很會賺牌的炸彈，每次 connive 都能先多抽一張，自己的戰階開始時還會讓自己的一隻生物 connive ，每回合持續多抽牌再加上 connive 濾牌，不用過多久對手就會被它帶來的資源淹沒了。
        
 
 {% mtgpick "MSH" 65 %}
 分數：2.0
 評語：套牌需要特殊構築，才能作為賺牌引擎，而身材實在有夠爛。
        
 
 {% mtgpick "MSH" 66 %}
 分數：2.5
 評語：延勢2/4的身材作為阻擋者還能接受。自己有 token 進場就可以抽牌，算是堪用的填充物。
        
 
 {% mtgpick "MSH" 67 %}
 分數：2.5
 評語：用咒語指自己的生物就能抽牌，然後它這回合的攻擊力就會變成手牌數。配合上警戒以及延勢讓它能攻能守，還有機會可以突然爆發打出超大一拳。但若想以它作為遊戲計劃的話，需要在套牌內投入較多的戰鬥詭計或是綠色的互鬥效應等會指定目標的咒語。
        
 
 {% mtgpick "MSH" 68 %}
 分數：3.5
 評語：把自己除了 token 外的生物場面變成兩倍，簡單又暴力。
        
 
 {% mtgpick "MSH" 69 %}
 分數：4.0
 評語：下限是個三費飛行1/4。不過一旦施放藍色的非生物咒語，就會開始生出 Merfolk，它的攻擊力也會因此越變越大。
        
 
 {% mtgpick "MSH" 70 %}
 分數：2.5
 評語：給警戒又給無法被阻擋，能偷揍對手一拳，而且還不虧牌。
        
 
 {% mtgpick "MSH" 71 %}
 分數：2.0
 評語：三費出這東西對場面毫無幫助，總共可以做出四次的抽濾，之後要剛好墳場有巫術或瞬間才能撿回來用。
        
 
 {% mtgpick "MSH" 72 %}
 分數：3.5
 評語：能去除對手生物的同時，把自己的生物變成被放逐的生物，還有給 ward 更難被去除。
        
 
 {% mtgpick "MSH" 73 %}
 分數：2.5
 評語：三費的2/2進場帶一個1/1，是個挺萬用的填充物。
        
 
 {% mtgpick "MSH" 74 %}
 分數：3.0
 評語：能靈活進場雲移自己的生物，刷進場異能或是作為保牌。搭載費用也很低，飛行3/3還是很不錯的。
        
 
 {% mtgpick "MSH" 75 %}
 分數：3.0（神器主題） // 2.0（非神器主題）
 評語：幫神器咒語都減一費，在紅藍神器主題中非常強。至於複製神器異能則需要場面配合，上限還是很高的。不過主題沒搭配到的話幾乎就是個2/1白板。
        
 
 {% mtgpick "MSH" 76 %}
 分數：2.5
 評語：前期拍下來可以持續進攻消減對手血量，之後再找空檔 Power-up 打一拳大的。後期抽到也可以直接落地變成一隻大生物。
        
 
 {% mtgpick "MSH" 77 %}
 分數：4.0
 評語：只要一點藍就能每回合多抽一張牌。結附在不重要的小生物上，就能讓對手煩惱到底該不該浪費去除給它。
        
 
 {% mtgpick "MSH" 78 %}
 分數：2.0
 評語：差不多是個普普通通的戰鬥詭計，只加了身材沒給其他異能。
        
 
 {% mtgpick "MSH" 79 %}
 分數：2.5
評語：抽三棄二或是一神器，堪用的補牌手段。
        
 
 ![](https://i.meee.com.tw/l2lgFOs.png)
 分數：4.0
 評語：正面能持續濾出神器上手，為背面的異能做準備。背面在神器套牌中是極強的炸彈，可以把手上的神器直接放進戰場，如果是武具的話還會自動裝配，讓它的破壞力更上一層樓！如果不是神器套牌的話，正面幾乎就沒什麼用，但背面依舊是個六費飛行、敏捷的5/5，還是值得混色去放的終結手段。
        
 
 {% mtgpick "MSH" 81 %}
 分數：2.5
 評語：作為對生物的軟去除還可以，還送一個 connive 做抽濾，缺點它是巫術有點太笨重。
        
 
 {% mtgpick "MSH" 82 %}
 分數：2.0
 評語：雖說是軟康，但 Teamwork 2 後對手就要多付四費，成功康到對手咒語的機會滿高的。
        
 
 {% mtgpick "MSH" 83 %}
 分數：3.5
 評語：能對永久物做雲移，像是刷自己永久物的進場異能，或是暫時移除對手的阻擋者。本身飛行4/4作為後期威脅也非常不錯。
        
 
 {% mtgpick "MSH" 84 %}
 分數：3.0
 評語：可以把對手的生物變成白板，並減緩它一回合的攻勢，能處理掉一些麻煩的異能。
 
 ## 結語
 這系列的藍色有很多抽牌效果，甚至連許多戰鬥詭計自己都會抽一張不虧牌，感覺比起前幾個系列的賺牌能力又更上一層樓，在對局後期能持續滾出源源不斷的資源。只能說真不愧是漫威，賺、還要更賺。
