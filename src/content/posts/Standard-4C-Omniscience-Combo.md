## 簡介賽場 & 比賽戰績

2026 年的千葉 Spotlight ，是一場匯聚了各方頂尖玩家的大型國際賽事，總計有 893 名選手參戰，賽程為期兩天、總共會經歷共計Day1 9+1 輪，Day2 5 輪的對局。

這次我使用了一套 4C Omniscience Combo，最終以 **10 勝 4 敗 1 和 （10-4-1）** 的成績完賽，最後以第 **50 名** 結束賽事。

![image](https://i.meee.com.tw/qc9K2gt.jpg)
<p style="text-align: center;"><a class="small">用A4紙充當獎狀</a></p>

然而，這份戰報背後有一項極具分析價值的「對照組」：本次賽事中，我有 4 位同樣常使用 Combo 的朋友，使用了與我完全一模一樣的 75 張牌表參賽，也使用相同的備牌策略，但他們 4 人卻全數在 Day 1 遭到淘汰。

會產生如此巨大的戰績落差，除了源於練習量不足以外，更關鍵的原因大概是在於：這套牌的底層邏輯是由我一手打造。面對這套極度特化的專武，駕駛員必須對『調度』與『隱性知識』有著近乎直覺的掌握，才能在快攻與控制的夾縫中，硬生生撕開一條勝利通道。

## 套牌構築解析：捨棄防禦，最大化引擎密度
這邊提供的MIT#11套牌構築列表（可惡第9）:
[MIT#11 Bant Omniscience牌表](https://melee.gg/Decklist/View/57333d3e-0759-402b-9df0-b4050040d53e)

接著可以看到在PT使用藍綠全知全能取得6-4的套牌，由Lee Shi Tian所構築的牌表：
[PTSOS_Simic Omniscience](https://www.mtggoldfish.com/deck/7761360#paper)

其將白色的去除改為使用更加便宜的軟去除 {% mtglink "Bounce Off" %} 這點我很喜歡，同時又能夠將自己為了阻擋、或是找 {% mtglink "Kona, Rescue Beastie" %} 提前下的 {% mtglink "Formidable Speaker" %} 重複利用。

可以發現，在構築這套 75 張牌時，我選擇了一條極端但純粹的路徑：**將干擾與防禦降到最低，把正編空間全面讓給濾牌與加速。**
原本正編的7個去除（3 {% mtglink "Get lost" %}、2 {% mtglink "Seam Rip" %} 1 {% mtglink "Day of Judgment" %} 、1 {% mtglink "Pinnacle Starcage" %} ）減少為5個（3 {% mtglink "Bounce Off" %} 、1 {% mtglink "Prismari Charm" %} 、1 {% mtglink "Pyroclasm" %} ）

這套牌的核心運作，是在最少的回合內精準雕刻出手牌結構。

對於純 Combo 來說，速度與穩定性本身就是最強的防禦。在正編妥協放入過多的單體去除或掃場，只會大幅拉低 Combo 準時運轉的期望值。也因為去除變少，因此更難像以前走向偏控制的路線。

由於原本沾白色的目的就是為了去除，因此果斷捨去了白色；同時又因為將組合技的終端由無限施放 {% mtglink "Scrapshooter" %} ，改為使用 {% mtglink "North Wind Avatar" %} 進行收頭，因此改為沾紅色、並且混入兩個紅色的去除去進行防守。

至於抽濾的部分，由於Spotlight是關卡表的，因此我特別開一點藍給對手的威攝力比較低，因此我把 {% mtglink "Opt" %} 換成使用 {% mtglink "Roiling Dragonstorm" %} 了。題外話，有不少人問過為什麼不使用 {% mtglink "Consult the Star Charts" %} 而是使用 {% mtglink "Roiling Dragonstorm" %} ，前者不是看得比較深嗎？確實，大部分情況都會看得比較深；但本質上，我們這套組合技的所有組件基本上都只想看到1張，因此抽二棄一的效果很常會比看N拿一還要更好，可以以此調節手牌，把多的組件換成更有用的地、或是其他的組件。

另外，加入了新的SOS大招 {% mtglink "Improvisation Capstone" %} ，就是為了對付菜鳥版本的蘇勒台惡魔這類有大量棄牌的套牌，結算後對手就很難跟上你的資源量了。 ~~但我忘了寫進melee牌表哭啊~~

> **核心邏輯**：只要我不死，血量就是拿來換取濾牌時間的資源。
> **調度邏輯**：你的目標是找到組合技組件，而非大量濾牌，請不要接一張組件都沒有然後一大堆Stock Up的手牌，這樣就本末倒置了。
> **轉換路線**：請隨時考慮這個場面跟對局有沒有機會用各種龍兄弟打死對手，以及自己還有沒有下一個回合，需不需要這回合就跟對手拼命了，分別對應我看到的兩個隊友的失誤。

## 套牌小技巧
1. 因為涵蓋了四個顏色，所以 {% mtglink "Multiversal Passage" %} 要喊的類別要相當注意，很常需要未雨綢繆，有一些簡易的記法讓你判斷：
   - 通常綠只需要一點，紅也只需要一點，白也只需要一點，藍越多越好。
   - 在控制對局裡優先級通常白色 > 紅色，快攻對局裡優先級紅色 > 白色。
   -  {% mtglink "Cavern of Souls" alt="靈魂洞窟" %} 的類別也要相當小心，通常是**Dragon**（ {% mtglink "North Wind Avatar" %} 、 {% mtglink "Marang River Regent" %} ）、**Human**（ {% mtglink "Voice of Victory" %} ）、**Beast**（ {% mtglink "Kona, Rescue Beastie" %} ）視對局跟手牌決定。
3. 只有白色跟紅色的星球蓄勢（Station）到12+後有用，要station優先使用這兩種。
4. {% mtglink "Kona, Rescue Beastie" alt="Kona" %} 丟 {% mtglink "Marang River Regent" alt="藍龍侯" %} 可以重置戰場並且放一個6/7飛行下來。對於中速或快攻而言，壓力很大，是很常考慮的Plan B。
5. Kona丟 {% mtglink "North Wind Avatar" alt="北風聖者" %} 是拿不了備牌的，請注意。
6. Kona的觸發時機是主要階段二開始時，請不要主二再下。
7. 出藍龍侯可以同時彈對方的非地永久物、以及自己的 {% mtglink "Formidable Speaker" %} 或  {% mtglink "North Wind Avatar" alt="北風聖者" %} 去繼續洗資源（打靈技是不推薦彈他的水獺結界拉，我自己沒彈過）。
8. 場上有藍龍侯以及Kona，你可以透過藍龍侯以及Kona攻擊（或地面打不過去單純station kona）後觸發Kona的異能，回應使用 {% mtglink "Prismari Charm" %} 或 {% mtglink "Bounce Off" %} 彈回場上的藍龍侯，並透過Kona的異能再次放入戰場來重置戰場，同時獲得飛行的阻擋者。
9. 請注意 {% mtglink "Formidable Speaker" %} 的第二條異能並不限定單一玩家。對方的會把我們的Kona在戰階時站起來，從而讓Kona的異能無法在主階二觸發。這也是為什麼我一開始使用的是 {% mtglink "Grand Abolisher" %} 而不是 {% mtglink "Voice of Victory" alt="VoV" %} ，就是為了防止對面是Sultai Reanimator也有Formidable Speaker來阻止combo，但現在這套牌幾乎沒有了。
10. {% mtglink "Emeritus of Ideation" %} 面對藍黑惡魔、菜鳥組的蘇勒台惡魔很強，除了較難去除以及額外資源外，同時又能夠在對手做完 {% mtglink "Doomsday Excruciator" %} 後讓對手抽三張輸去。
11. {% mtglink "Spider-Sense" %} 可以透過支付一點藍以及移回一個橫置的生物來施放，記得要提前station你的生物去得到更多資源。
12. 即便場上有 {% mtglink "Omniscience" %} 你還是可以轉法力使用手上的牌張，常見情況是你希望那東西不能被康，所以你還是要轉靈魂洞窟施放。另外Omniscience只會讓手上的牌張可以免費施放，墳場的 {% mtglink "Winternight Stories" %} 以及 {% mtglink "Emeritus of Ideation" %} 備法的 {% mtglink "Ancestral Recall" %} 都還是要乖乖付費的。

## 實戰數據總結

這 15 輪的對戰標定了套牌的邊界：

* **vs. 快攻：** 4 勝 2敗。靈技正編沒有太好去除可以應對kona所以整體而言還算好打。
* **vs. 控制：** 4 勝 0 敗。6 費路線對付控制非常強力。
* **套牌的絕對死穴（vs. Mardu Discard）：** 面對 Mardu Discard 的 0 勝 2 敗，這個套牌幾乎無法防禦第 3 回合致死打擊、或是對面不靠生物的直傷。
